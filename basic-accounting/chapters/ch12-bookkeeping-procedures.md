# 第12章 账务处理程序（书页 266–287）

## 本章地位
"证→账→表"的组织学：同一套分录，三种**登记总账的路径**（逐笔/汇总记账凭证/科目汇总表），本质是手工记账下会计部门内**人员分工**的设计。三程序的区别只有一个：**登记总分类账的依据和方法不同**。

## 章节结构（节 · 书页）
1. 概述 p267　2. 记账凭证账务处理程序 p268　3. 汇总记账凭证账务处理程序 p269　4. 科目汇总表账务处理程序 p282

## 关键定义
- **账务处理程序**（bookkeeping procedures，又称会计核算组织程序/核算形式）：会计凭证、账簿、报表相结合的方式 = **账簿组织**（凭证账簿种类格式及联系方式）＋**记账程序**（从凭证到报表的流程）。通俗说=手工记账下财务部门的**分工合作方式**。
- 程序一经确定必须严格执行，否则工作混乱。

## 三种程序对比（总账登记依据是分水岭）
| | 记账凭证程序 | 汇总记账凭证程序 | 科目汇总表程序 |
|---|---|---|---|
| 登总账依据 | 记账凭证**逐笔** | 定期编制的**汇总收/付/转凭证** | 定期编制的**科目汇总表** |
| 地位 | **最基本**，其余皆由它演变 | | 我国手工实务最常用 |
| 优点 | 简单明了、便于追溯、总账信息量大反映全貌 | 减轻总账工作量；**保留科目对应关系**，便于查对分析 | 大幅减轻总账工作量；编制时可**顺带试算平衡** |
| 缺点 | 总账登记量大 | 转账凭证多时汇总工作量大；按**贷方科目**编制汇总转账凭证（须一借一贷/多借一贷），**不利于日常分工**；总工作量未减只是转移给下属 | **不反映对应关系**，科目间来踪去迹不可见，不便于查对分析 |
| 适用 | 规模小、业务少、凭证少 | 规模较大、业务多、**大量重复使用某些科目** | 业务量较多的单位 |

## 汇总记账凭证编制规则
- **汇总收款凭证**：按"库存现金/银行存款"的**借方**设置，列贷方科目合计 → 总账：现金/银行存款记借方，对应科目按合计记贷方。
- **汇总付款凭证**：按"库存现金/银行存款"的**贷方**设置，列借方科目合计。
- **汇总转账凭证**：按每一**贷方**科目设置（贷方必须唯一）→ "一借一贷/多借一贷"；实务中除非某贷方科目高频如现金银行，否则**直接用转账凭证登记总账更可取**。
- 记账凭证必须收/付/转分设，不能用通用凭证。

## 科目汇总表编制规则
- 定期（按旬/按月）将全部记账凭证按科目归类，只列各账户**借方发生额/贷方发生额**；现金银行也可取自日记账收支合计。
- **只反映发生额、不反映对应关系**；每月一张按旬汇总或每旬一张。
- "账页"栏记录该科目在订本总账中的页数。
- 现金/银行日记账、明细账的登记在三种程序下**完全相同**（逐笔）。

## 共同流程骨架（七步）
原始凭证→（汇总原始凭证）→记账凭证→{现金/银行日记账（逐笔）＋明细账（逐笔）}→【此处三程序分岔：登记总账】→期末对账（日记账、明细账余额 vs 总账余额）→编报表。

## Worked Example（例12-1起，12笔业务的两种走法）
发行股份600万股（面值1元）收到3400万：
- 记账凭证程序：银行存款收款凭证（银收字第1号）直接逐笔过入"银行存款""实收资本""资本公积"总账。
- 科目汇总表程序：12笔凭证按旬汇总，"银行存款"行借方合计3400万…各科目借贷发生额各汇一行，合计借贷相等（顺带完成试算平衡），再按各行金额登记总账。

## 要点回顾
1. 三程序只有"总账怎么登"不同；日记账、明细账永远逐笔。
2. 选型逻辑：业务量↑ → 汇总层级↑；要求可追溯性 → 保对应关系（汇总凭证程序）。
3. 科目汇总表是"发生额体检表"：平衡好查、对应关系丢。
4. 汇总转账凭证按贷方设置的约束导致其性价比有限。
5. 电算化下这些程序已内置化，但其分工思想仍适用于内控岗位设置。
