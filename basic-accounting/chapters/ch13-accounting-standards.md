# 第13章 会计管理相关工作规范（书页 288–306）

## 我国会计法规体系四层（效力递减）
| 层级 | 制定者 | 代表文件 |
|---|---|---|
| **法律** | 全国人大及常委会 | **《会计法》**（会计工作根本大法）、税收征管法、公司法、刑法 |
| **行政法规** | 国务院 | 《企业财务会计报告条例》、总会计师条例 |
| **部门规章** | 财政部等（部长令） | **《企业会计准则——基本准则》**（具体准则的制定依据，概念框架角色）、《企业财务通则》 |
| **部门规范性文件** | 财政部（文件形式） | 42项具体准则、《小企业会计准则》、《会计基础工作规范》、《会计档案管理办法》、应用指南 |

- 企业会计准则体系（2006建立，与IFRS**实质趋同**）= 1项基本准则＋**42项**具体准则＋应用指南＋解释公告；大中型企业执行企业会计准则，小微企业执行《小企业会计准则》。
- 2014年7月修订基本准则，重新表述公允价值定义。

## 会计职业发展（考试路径）
- **会计专业技术资格**（水平评价类）：初级（会计员/助理会计师；科目：初级会计实务＋经济法基础）→ 中级（会计师；科目：中级会计实务＋财务管理＋经济法；本科学历需工作满4年）→ 高级（考试＋评审结合）；部分省试点正高级。
- **注册会计师 CPA**（准入类）：《注册会计师法》；专业阶段6科（会计、审计、财务成本管理、公司战略与风险管理、经济法、税法，单科合格**5年有效**）＋综合阶段；全科合格＋**从事审计业务2年**→ 省级注协申请注册；**必须在会计师事务所执业**（不是"独立职业"）。
- "会计师"（企业内部会计管理人员）≠"注册会计师"（面向不特定客户的中介执业人员）。
- 单位财务负责人称谓：总会计师（"三总师"之一）/ 财务总监（CFO）；上市公司财务负责人通常为财务总监。

## 会计基础工作规范（财政部1996印发）
- **会计机构**：根据业务需要设置；不设机构的须在有关机构中配专职人员并指定会计主管人员。
- **岗位设置**：机构负责人/主管、出纳、财产物资核算、工资核算、成本费用核算、财务成果核算、资金核算、往来结算、总账报表、稽核、档案管理等；可一人一岗/一人多岗/一岗多人，**应有计划轮岗**。
- **内控红线：出纳不得兼管审核、会计档案保管和收入、费用、债权债务账目的登记**（内部牵制）。
- **会计监督**：对原始凭证——不真实不合法的不接受、记载不明确不完整的退回更正补充；对账簿——制止伪造变造账外设账；对财务收支——审批不全退回、违规收支不予办理、制止纠正无效的报告单位领导并越级上报；同时接受财政/审计/税务监督和注册会计师审计，不得拒绝隐匿谎报。
- **交接制度**（划分会计责任）：移交前填完凭证、登完账、编移交清册；**监交**——一般会计员交接由会计机构负责人监交，机构负责人交接由**单位领导人**监交；现金有价证券按账簿点交必须一致；电算化数据在实际操作状态下交接；接替人**不得另立新账**；移交人对移交资料的合法性真实性承担法律责任。

## 会计档案管理办法（财政部/国家档案局令第79号，2015修订）
- **归档范围四类**：会计凭证（原始/记账）；会计账簿（总账、明细账、日记账、固定资产卡片及辅助账簿）；财务会计报告（月/季/半年/年度）；其他（银行存款余额调节表、银行对账单、纳税申报表、移交/保管/销毁清册、鉴定意见书）。
- **保管期限**（自**会计年度终了后第一天**算起，为最低期限）：定期分 **10年/30年** 两档：
  | 档案 | 期限 |
  |---|---|
  | 原始凭证、记账凭证 | **30年** |
  | 总账、明细账、日记账 | **30年** |
  | 固定资产卡片 | 报废清理后保管**5年** |
  | 月/季/半年度财务报告 | **10年** |
  | **年度财务会计报告** | **永久** |
  | 银行存款余额调节表、银行对账单、纳税申报表 | **10年** |
- 移交节奏：当年档案在会计年度终了后可由会计机构**临时保管1年**（最长不超过**3年**），再移交档案机构；**出纳不得兼管会计档案**。
- **电子会计档案**：满足来源真实有效、系统可准确完整读取、防篡改、有备份、非永久保存价值等条件可仅以电子形式保存；外部接收的附合规电子签名即可电子归档（财会〔2020〕6号规范电子凭证报销入账归档）。

## 要点回顾
1. 四层法规效力递减：会计法是根本，基本准则统驭具体准则。
2. 初/中级职称全国统考，高级考试+评审，CPA准入且须在事务所执业。
3. 出纳的"三不兼"：不兼审核、不兼档案、不兼收入费用债权债务账目。
4. 保管期限速记：凭证账簿30年、年度报告永久、对账单调节表纳税表10年。
5. 档案临时保管1年最长3年后移交，出纳永远不碰档案。
