# 第7章 会计账簿（书页 166–187）

## 本章地位
会计循环"账"环节：账簿是连接凭证与报表的**桥梁**（凭证信息汇总浓缩于此）。核心操作技能章——登记、对账、结账、查错、改错五套手上功夫。

## 章节结构（节 · 书页）
1. 会计账簿概述 p167　2. 启用与登记要求 p174　3. 格式与登记方法 p175　4. 对账与结账 p178　5. 错账查找与更正 p180　6. 更换与保管 p185

## 关键定义
- **会计账簿**：由一定格式账页组成、以审核无误的凭证为依据、全面系统连续记录经济业务的簿籍。**账簿与账户=形式与内容**：账页是账户的载体。
- 四大作用：记载存储、分类汇总、检查校正、编报输出会计信息。
- **不得私设账簿**（两套账违法）；不记账不报税→税务稽查、罚款、影响法人征信。

## 账簿三维度分类（图7-2）
| 口径 | 类别 | 用途/适用 |
|---|---|---|
| **按用途** | **序时账簿**（日记账）：普通日记账（分录簿=记账凭证誊写本，两栏式）；特种日记账（我国普遍只设**库存现金/银行存款日记账**） | 逐日逐笔顺序登记 |
| | **分类账簿**：总分类账（统驭）＋明细分类账（补充） | 编报表主要依据 |
| | **备查账簿**：应收票据备查簿、委托加工物资备查簿等 | 补充登记，无固定格式，与主账无勾稽关系 |
| **按账页格式** | 两栏式（少用）；**三栏式**（借贷余——日记账、总账、债权债务资本明细账）；**多栏式**（收入费用利润明细账）；**数量金额式**（存货明细账：数量/单价/金额×借贷余）；**横线登记式**（材料采购/在途物资/应收票据/备用金——一行跟踪一笔业务） | |
| **按外形** | **订本式**（防抽换：总账、现金/银行存款日记账**必须订本**）；活页式（明细账，年终结账后装订编号）；卡片式（**固定资产明细核算**） | |

## 对账（每年至少一次）——三相符
1. **账证相符**：账簿 vs 原始/记账凭证（时间、字号、内容、金额、方向）。
2. **账账相符**：总账之间（借贷平衡）；总账↔所属明细账；总账↔日记账；明细账之间。
3. **账实相符**：现金日记账余额↔实存现金（**每日**）；银行存款日记账↔**银行对账单**（定期）；财产物资明细账↔实存数；债权债务↔对方账面记录。

## 结账（closing）——两件事
①结清损益类账户（转"本年利润"）算出本期利润；②结出实账户本期发生额与期末余额结转下期。
程序：全部业务入账→**按权责发生制调整账项**（衔接ch10）→损益结转→实账户结余额→试算平衡。
划线规则：月末最后一笔下单红线；"本月合计"下单红线；"本年累计"下双红线（12月末全年累计=双红线）；年结"本年合计"通栏双红线；余额结转下年注"结转下年"，新账注"上年结转"。

## 错账查找四法（试算不平衡时）
| 方法 | 适用差错 | 操作 |
|---|---|---|
| **差数法** | 单边漏记 | 差额=漏记金额，检索含该金额的凭证 |
| **尾数法** | 尾数差错 | 只查末位数，提高效率 |
| **除2法** | **方向记反** | 差额÷2=错记金额（如应贷记1533万误借记→差3066万） |
| **除9法** | **数字错位/邻数颠倒** | 写小10倍：差额÷9=错误额，×10=正确额；写大10倍：差额÷9=正确额；邻数颠倒（369→639，差27万÷9=3万→万位/十万位差3） |

## 错账更正三法（《会计基础工作规范》：不准涂改挖补刮擦药水、不准重抄）
1. **划线更正法**：**结账前**、账错凭证没错→红线划销全部错误数字（数字不能只改个别位），上方蓝黑字写正确，更正处盖章。
2. **红字更正法**（两种情形）：①科目用错：红字填一张与原凭证**完全相同**的凭证冲销＋蓝字填正确凭证（更正凭证不附原始凭证）；②科目对但**金额多记**：按多记金额红字冲销。
3. **补充登记法**：科目对但**金额少记**→按少记差额蓝字补记。
- 涉及**以前年度**的错误：蓝字更正（见ch4）。

## Worked Example：除9法定位邻数颠倒（书页182）
凭证借/贷"管理费用/银行存款"369 000，过账时借方误写639 000。试算差 270 000。270 000÷9=30 000 → 颠倒发生在**十万位与万位**且两数字差=3（3↔6差3、6↔9差3）→锁定检查万位十万位相邻差3的凭证→找到369 000误记639 000，用划线更正法改正。

## 要点回顾
1. 记账依据只能是审核无误的凭证；日记账与总账订本、明细账活页、固定资产卡片。
2. 对账三相符是报表可信的前提；现金日清、银行对单。
3. 结账先调账（权责发生制）再结转损益——ch10 的预告。
4. 查错先算差额：÷2 查方向、÷9 查错位/颠倒、差额本身查漏记。
5. 更正方法的选择由"账对不对 vs 凭证对不对 + 大记还是小记"决定。
