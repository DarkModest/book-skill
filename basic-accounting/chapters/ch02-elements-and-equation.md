# 第2章 会计要素与会计等式（书页 28–55）

## 本章地位
把"资金运动"具体化为**六个会计要素**，并给出全学科第一定律——**会计恒等式**。任何经济业务都不会破坏等式平衡，这是复试记账（ch3）、试算平衡（ch7）、编报表（ch11）的理论根基。

## 章节结构（节 · 书页）
1. 会计对象 p29　2. 会计要素 p30　3. 会计等式 p43　4. 会计要素的确认与计量 p46

## 会计对象：资金运动
会计对象=核算和监督的客体=**资金运动**，分三类活动：
- **筹资活动**：股权融资（卖股份）/ 债务融资（借款、发债）。
- **投资活动**：直接（对内：设备、厂房）/ 间接（对外：买股票债券）。
- **经营活动**：除上述外的日常业务（采购、生产、销售）。

## 六大会计要素（静态3个→资产负债表；动态3个→利润表）
| 要素 | 定义要点 | 分类 |
|---|---|---|
| **资产** | 过去交易/事项形成、企业**拥有或控制**、预期带来经济利益的资源 | 流动（现金/银行存款/交易性金融资产/预付账款/应收票据/应收账款/存货）vs 非流动（长期股权投资/固定资产/无形资产） |
| **负债** | 过去交易形成、预期导致经济利益流出的**现时义务** | 流动（短期借款/应付票据/应付账款/预收账款/应付职工薪酬/应交税费）vs 非流动（长期借款/应付债券/租赁负债/预计负债） |
| **所有者权益** | 资产扣除负债后的**剩余权益**；金额不能单独计量 | 实收资本（股本）＋资本公积（**投入资本**）；盈余公积＋未分配利润（=留存收益，**赚的钱**） |
| **收入** | 日常活动、导致所有者权益增加、与投入资本无关的经济利益**总流入** | 主营/其他业务收入 |
| **费用** | 日常活动、导致所有者权益减少、与向所有者分配无关的经济利益**总流出** | 营业成本（主营/其他）＋税金及附加＋**期间费用**（销售/管理/财务）＋营业外支出＋所得税费用 |
| **利润** | 一定期间的经营成果 | 利润=收入−费用＋直接计入当期利润的利得−损失（营业外收支） |

- 资产三特征反例：横穿工厂的市政道路（不能控制）✗；弃之不用的机器（不带来利益）✗；明年才签合同要买的流水线（非过去事项）✗。
- 股本溢价例：发行1亿股、面值1元、发行价10元→1亿计**股本**，9亿计**资本公积**；赚5000万→按10%提500万**法定盈余公积**，余4500万为**未分配利润**。
- 资本与收益的划分意义重大：涉及分利、业绩考核、税收。
- **期间费用**记法：销售费用（推销+销售机构）、管理费用（组织管理）、财务费用（筹资：利息、汇兑）。

## 会计恒等式
- **基本式：资产 = 负债 + 所有者权益**（资金占用 = 资金来源；同一资金两个侧面）。
- 扩展式：**资产 = 负债 + 所有者权益 + (收入 − 费用)**；利润归所有者承担/分享。
- 债权人权益优先于所有者权益：破产清算先偿债，股东是**最终风险承担者**（剩余权益）。

## 确认与计量
- **初始确认→后续计量→终止确认**三环节；列报时合并（存货）与抵减（减值）。
- **资产确认两条件**：经济利益**很可能**流入＋成本/价值**可靠计量**。反例：客户破产的应收款应注销为坏账；机场广告费利益不确定→费用化。
- **负债确认两条件**：利益很可能流出＋金额可靠计量。反例：股票股利（10转10）不导致利益流出→不是负债。
- **收入确认（准则14号，2017修订）**：客户**取得相关商品控制权**时确认。**五步法**：①辨认合同（商业实质、对价很可能收回）→②辨认履约义务（可明确区分；如卖手机送话费=两项）→③确定交易价格（折扣/退货/融资成分）→④按**单独售价**分摊→⑤履约时确认（时点 vs 期间：建造合同按投入法/产出法）。
- **五种计量属性**：
  | 属性 | 定义 | 典型应用 |
  |---|---|---|
  | 历史成本 | 取得时实际支付 | 初始计量默认；固定资产 |
  | 重置成本 | 现在重新取得的金额 | **盘盈资产** |
  | 可变现净值 | 预计售价−进一步加工成本−销售费用税费 | **存货跌价准备**（成本与市价孰低） |
  | 现值 | 未来现金流折现 | 坏账准备、摊余成本 |
  | 公允价值 | 计量日有序交易中市场价格 | 交易性金融资产 |
- **两种计量模式**（后续计量分野）：历史成本模式只确认**减值**不确认升值（固定资产）；公允价值模式**双向确认**（交易性金融资产涨跌都进损益；投资性房地产公允模式：100万购入市价涨到130万→+30万进当期损益）。目标选择决定模式：重决策相关→公允；重可靠→历史成本。

## Worked Example：兰香鲜花店——七笔业务验证恒等式（例2-1~2-7，书页44-47）
阿兰投资10万开店（不考虑增值税）：
1. 投入10万：银行存款+10万｜实收资本+10万 → 资产10万=权益10万
2. 购花1万付讫：库存商品+1万、银行存款−1万（**资产内部一增一减**）→总额不变
3. 购花1.5万未付：库存商品+1.5万｜应付账款+1.5万（**资产与负债同增**）→11.5万=1.5万+10万
4. 全部售出收4万存行，结转成本2.5万：银行存款+4万｜收入+4万；库存商品−2.5万｜费用+2.5万 →13万=1.5万+11.5万
5. 付店面租金1.2万：银行存款−1.2万｜费用+1.2万 →11.8万=1.5万+10.3万
6. 偿还货款1.5万：银行存款−1.5万｜应付账款−1.5万（**资产与负债同减**）→10.3万=0+10.3万
7. 阿兰工资5000/月未付：费用+5000｜应付职工薪酬+5000（**负债增、权益减**）
**规律**：每笔业务只让等式**两边同时增减**或**一边内部一增一减**，恒等式永不破坏。

## 要点回顾
1. 六要素两组：资产负债所有者权益（存量、时点）↔ 收入费用利润（流量、期间）。
2. 所有者权益=投入资本+留存收益，是剩余权益，不能单独计量。
3. 收入的判据是"控制权转移"，不是"发货"也不是"收款"。
4. 五种计量属性中，历史成本是默认，其余各有机型（盘盈→重置；存货跌价→可变现净值）。
5. 任何业务不破坏恒等式——这是试算平衡（ch7）能查错的理论基础。
