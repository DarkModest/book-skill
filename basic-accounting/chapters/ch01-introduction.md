## 关键定义（按教材表述）
- **会计**：以提高企业经济效益为目标，采用一系列程序与方法，对企业的经济活动进行**核算**和**监督**，为会计信息使用者提供决策所需信息的经济管理活动。
- **核算职能**（反映职能）：以货币为主要计量单位，对特定主体经济活动进行**确认（recognition）→计量（measurement）→记录（recording）→报告（reporting）**，具有完整性、连续性、系统性。
- **监督职能**（控制职能）：对经济活动的**真实性、合法性、合理性**进行检查，贯穿事前（预算/合同）、事中（成本费用计算）、事后（支付环节报销审核）。
- **会计目标（双重）**：《企业会计准则——基本准则》——向使用者提供财务状况、经营成果、现金流量信息，**反映管理层受托责任履行情况**（受托责任观），**有助于使用者做出经济决策**（决策有用观）。
- **会计循环（accounting cycle）**：将经济信息转化为会计信息的程序，三大核心环节=**证→账→表**。

## 四大会计假设（记账的前提，先于一切核算）
| 假设 | 回答的问题 | 要点 |
|---|---|---|
| **会计主体** | 为谁记账（空间范围） | 划清企业之间、企业与所有者个人之间界限；主体≠法人（分公司非法人但可是会计主体；合并报表主体是多个主体集合） |
| **持续经营** | 能否按现状继续（时间前提） | 无反证即假定不清算不破产；固定资产成本才能分期分摊 |
| **会计分期** | 何时结账报账 | 持续经营的人为切分；我国《会计法》采用历年制；分年度与中期（季报、半年报） |
| **货币计量** | 用什么尺度 | 进入核算系统的必须可货币计量；隐含**币值稳定**假设；确定记账本位币（我国为人民币） |

## 八项会计信息质量要求（背）
可靠性、相关性、清晰性、可比性、**实质重于形式**、重要性、**谨慎性**、及时性。
- 归类：谨慎性、重要性 = **偏好性原则**；实质重于形式 = **修订性原则**；运用需职业判断。
- **实质重于形式**经典例：融资租赁租入资产，法律形式所有权未转移，但风险报酬已归承租人→列入承租方**使用权资产**。
- **谨慎性**：多种方法可选时，不高估资产/收益、不低估负债/费用（如期末计提资产减值准备）。

## 三项会计核算原则
1. **权责发生制**（应收应付制）：按**权利义务归属期**确认收入费用，不看现金收付时点。例：每月负担的借款利息计入当月财务费用，无论何时支付。
2. **配比原则**：收入与费用配比计算损益——因果关系配比（卖手机的收入配卖手机的成本）＋期间配比（广告费配当期收入）。
3. **划分收益性支出与资本性支出**：受益期仅当期→费用（打印纸）；受益期超一年→资产、分期分摊（电脑计固定资产）。

## 八种会计核算方法（方法体系，图1-1）
设置账户、复式记账、填制和审核凭证、登记会计账簿、成本计算、财产清查、账项调整、编制财务会计报告。
- **账项调整**：按权责发生制调整已入账的资产负债项目及未入账事项。例：一次收三年房租30万，不能一次计收入，每年确认10万。
- 会计循环八步骤：审核原始凭证→填制记账凭证→登记账簿→**编制调整分录**→对账（证账/账账/账表/账实相符）→结账（结平虚账户）→试算平衡→编报表。

## 会计目标两大观点对比
| | 受托责任观 | 决策有用观 |
|---|---|---|
| 前提 | 所有权与经营权分离、委托代理 | 资本市场发达、股权分散 |
| 信息取向 | 面向历史、可靠、稳健 | 面向未来、相关、公允价值 |
| 服务对象 | 股东（委托人） | 现在和潜在的投资者、债权人 |

## Worked Example：差旅费报销中的会计监督（书页11-12）
销售李丽持住宿/交通/餐饮发票报销差旅费，会计流程五步：①审查出差是否公司业务安排（否→全部不报）；②**辨认单据真伪**；③合计合格凭证金额；④比对公司差旅费标准，核准金额（超标自担）；⑤出纳付款、计入**销售费用**。全程签名盖章+填写时间，保证可追溯。——体现监督的事后环节与真实性、合理性审查。

## 要点回顾
1. 核算与监督是两大基本职能："离开核算无所谓会计，离开监督会计失去生命"。
2. 会计目标是双重的：受托责任 + 决策有用；前者重历史可靠，后者重未来相关。
3. 四大假设是核算前提；其中会计分期+持续经营共同引出账项调整（ch10）。
4. 八项质量要求中谨慎性是贯穿一切业务的职业思维方式。
5. 证→账→表是会计循环主线，对应 ch4 凭证、ch7 账簿、ch11 报告。
