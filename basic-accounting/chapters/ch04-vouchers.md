# 第4章 会计凭证（书页 78–93）

## 本章地位
会计循环"证"环节：一切账簿记录必须以凭证为据（**凭证是登记账簿的合法依据**）。凭证体系 = **原始凭证**（业务证据）→ **记账凭证**（翻译成分录）。也是内部控制与经济责任制度的载体。

## 章节结构（节 · 书页）
1. 会计凭证概述 p79　2. 原始凭证 p80　3. 记账凭证 p87　4. 会计凭证的传递与保管 p91

## 关键定义（按教材表述）
- **会计凭证**：记录经济业务发生或完成情况、登记账簿依据的书面证明。《会计法》第9条：必须根据实际发生的经济业务核算，**不得以虚假业务或资料核算**。
- **原始凭证**（source document）：业务发生或完成时取得或填制的、记录业务原始信息的凭据——记载**法律事实**，是确认计量与编制记账凭证的依据。
- **记账凭证**（entry document）：会计人员根据**审核无误的原始凭证**，归类确定会计分录后填制的凭证，是**登记账簿的直接依据**。

## 原始凭证分类（三种口径）
| 口径 | 类别 | 例 |
|---|---|---|
| 按来源 | **自制** / **外来** | 借款借据、差旅费报销单 / 发票、财政票据、完税凭证、机票火车票、点菜单 |
| 按格式 | 通用 / 专用 | 统一印制的发票 / 单位自印的领料单、借据 |
| 按填制手续 | **一次 / 累计 / 汇总** | 入库单、提货单 / **限额领料单**（有效期内连续使用、按限额控制、期末按实际发生额记账）/ **发料凭证汇总表**（按旬汇总同类业务） |

- 原始凭证**基本内容七项**：名称；日期；单位名称/填制人；经办人签章；接受单位；业务内容；数量单价金额。
- **填制基本要求**：记录真实、内容完整、手续完备、书写清楚规范、连续编号、**不得涂改刮擦挖补**、填制及时。
- 金额书写规范（会计基础工作规范）：阿拉伯数字逐个写不连笔；币种符号与数字间不留空；大写用壹贰叁…写到"整/正"。
- 外来原始凭证需加盖出具单位公章方有效（电子发票可以电子签名代替）；一式多联用复写纸套写。

## 记账凭证分类
- **按用途**：**收款凭证**（左上角借方科目=库存现金/银行存款）、**付款凭证**（左上角**贷方科目**=库存现金/银行存款）、**转账凭证**（不涉收付）。小型企业可用**通用记账凭证**（格式同转账凭证）。
- **按填列方式**：单式（借项/贷项凭证）、复式（一笔业务全部科目在同一张）。
- **必备内容七项**：日期、编号、摘要、科目、金额、所附原始凭证张数、相关人员签章（收付款凭证还须出纳签章）。

## 决策规则（填制中的 if/then）
- **现金↔银行存款相互划转：只填付款凭证**，不填收款凭证（避免重复记账）。出纳收付后在原始凭证加盖"收讫/付讫"戳记防重收重付。
- 连续编号；一笔业务多张凭证用**分数编号法**（5⅓ = 第5笔业务第1张/共3张）。
- **除结账和更正错误外，记账凭证必须附原始凭证**；不同内容类别的原始凭证不得汇总在一张记账凭证上。
- 一张原始凭证涉及多张记账凭证→附在主要凭证后，其余注明编号；多单位共同负担→开**原始凭证分割单**。
- 凭证错误更正：**未入账**→重新填制；**当年已入账**→红字注销＋蓝字订正（科目没错仅金额错→按正确数红/蓝字调整）；**以前年度**错误→蓝字更正。

## 原始凭证审核（先审原始，再编记账）
真实性（是否真实发生、有无伪造）、合法性（是否符合法规）、合理性（是否符合预算与内控）、完整性（要素齐全）、正确性（计算书写无误）、及时性。
记账凭证审核六查：①附件齐全真实？②摘要与原始凭证相符？③发票及抬头？④账务处理（含明细科目）正确？⑤金额与书写？⑥签章齐全？

## 传递与保管
- **传递** = 取得/填制→归档全过程在部门人员间的传送程序与时间——内部控制流程的生动体现。
- **保管**：定期装订成册＋封签签章；封面注明单位/种类/张数/起止号/年月；**原始凭证不得外借**（经批准可复制并登记）；原始凭证过多可单独装订（注明"附件另订"）；年终可由会计机构暂管**1年**后移交档案机构；**出纳不得兼管会计档案**；保管期内不得擅自销毁（期限见ch13会计档案管理办法）。
- 外来凭证遗失补救：取得原签发单位盖章证明（注明号码金额内容）＋会计负责人和单位负责人批准后代用；无法取得（如车票丢失）→当事人写明情况＋同样两级批准。

## Worked Example（练习题E4-1~E4-3 的模式）
- 收款凭证：销售商品70000元、增值税13%已收妥 → 借方科目"银行存款"，贷方"主营业务收入70000＋应交税费——应交增值税（销项税额）9100"。
- 付款凭证：验收入库后付货款2260（价2000＋税260）→ 贷方科目"银行存款"，借方"原材料2000＋应交税费——应交增值税（进项税额）260"。
- 转账凭证：结转销售成本900万 → 借"主营业务成本"、贷"库存商品"，不涉收付款。

## 要点回顾
1. 原始凭证管"证据"，记账凭证管"分录"——审核顺序不可颠倒。
2. 现金↔银行划转只编付款凭证，是防重复记账的关键规则。
3. 红字注销＋蓝字订正 vs 蓝字更正（跨年度）——分清错账的时间和深度。
4. 凭证张数、编号、签章都是内控可追溯性的组成部分。
