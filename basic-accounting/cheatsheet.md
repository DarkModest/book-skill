# 速查决策表

## 借贷方向判定（一切分录的起点）
```
拿到一笔业务 → 找科目 → 问类别
├─ 资产 / 费用（含成本类）→ 增加=借，减少=贷
├─ 负债 / 所有者权益 / 收入 → 增加=贷，减少=借
└─ 记住镜像规则：资产费用同边，负债权益收入同边
```

## 一笔业务写分录的验证链
等式两侧同增同减？→ 合法（总资产↑负债权益↑）
只动左侧内部一增一减？→ 合法（总额不变）
只动右侧内部？→ 合法
借方合计≠贷方合计？→ 分录错误，重写

## 试算不平衡查错决策树
```
差额 X
├─ X 可被 2 整除 → 查方向记反：X÷2 = 错记金额
├─ X 可被 9 整除
│   ├─ X÷9 = 某凭证金额 → 写大10倍错（正确额=X÷9）
│   └─ X÷9 = "整齐数" → 写小10倍错（错误额=X÷9，正确额×10）
│       └─ 或邻数颠倒：X÷9=位差，定位相邻两位
├─ X 恰等于某凭证某科目金额 → 单边漏记（差数法）
└─ 只有末位错 → 尾数法
⚠ 平衡≠正确：整笔重记/漏记、串户、整笔反方向查不出
```

## 错账更正选型
| 情形 | 方法 |
|---|---|
| 结账前，账错凭证没错 | 划线更正（红线划全部数字，上方写正确，盖章） |
| 科目用错（已入账） | 红字凭证冲销＋蓝字正确凭证 |
| 科目对、金额多记 | 红字冲多记部分 |
| 科目对、金额少记 | 蓝字补记差额 |
| 以前年度错误 | 蓝字更正 |

## 账项调整四型速判（结账前必做）
| 现金时点 vs 确认时点 | 项目 | 调整分录 |
|---|---|---|
| 付钱在前（已入资产） | 预付费用 | 借：费用　贷：长期待摊费用 |
| 收钱在前（已入负债） | 预收收入 | 借：预收账款　贷：收入 |
| 付钱在后（未入账） | 应计费用 | 借：费用　贷：应付利息/应付职工薪酬 |
| 收钱在后（未入账） | 应计收入 | 借：应收利息　贷：收入 |

## 存货计价方法选择
| 需求 | 选 | 后果 |
|---|---|---|
| 随时掌握账面价值 | FIFO / 移动加权平均 | 物价涨：FIFO利润最高、存货接近市价 |
| 手工省力 | 月末一次加权平均 | 平时不记金额，不能随时结账面价值 |
| 客观精确 | 个别计价法 | 贵重/不可替代/专门定制存货 |
| （已废止） | LIFO | 准则第1号取消，仅理论 |

## 盘盈盘亏去向速查（批准后）
| | 盘盈 | 盘亏 |
|---|---|---|
| 现金 | 原因不明→营业外收入；应退→其他应付款 | 责任赔→其他应收款；不明→管理制度定（出纳赔/管理费用/营业外支出） |
| 存货 | **冲减管理费用** | 定额内→管理费用；责任/保险赔→其他应收款；**非常损失→营业外支出** |
| 固定资产 | 走"以前年度损益调整"（不是待处理） | 净损失→营业外支出 |

## 增值税速判
- 专票进项可抵扣；普票税额进成本；小规模（≤500万/年）简易计税不抵扣。
- 应纳税额 = 销项 − 进项；运费9%、货物13%。
- 转让金融商品按卖出价6%交增值税，冲减投资收益。

## 利润计算与分配链
```
营业利润 = 收入 − 成本 − 税金及附加 − 销售/管理/研发/财务费用 + 投资收益等
利润总额 = 营业利润 + 营业外收入 − 营业外支出
净利润   = 利润总额 − 利润总额×25%（本教材简化，不纳税调整）
分配     = 提10%法定盈余公积 → 分股东 → 明细全对冲入"未分配利润"
```

## 会计档案保管期限（2015令79号，自年度终了后第一天起）
30年：原始凭证、记账凭证、总账、明细账、日记账、会计移交清册
10年：月/季/半年报、银行余额调节表、银行对账单、纳税申报表
永久：**年度财务会计报告**、保管清册、销毁清册、鉴定意见书
特殊：固定资产卡片报废清理后5年；会计机构临时保管1年（最长3年）后移交
