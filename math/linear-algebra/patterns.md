# 方法与算法库

## 行化简（Row Reduction）
**何时用**：解方程组、判相容性、求逆、求秩/主元列、求特征空间。
**做法**：向前阶段造阶梯形 → （需要时）向后阶段化 RREF。
**权衡**：判相容到阶梯形即可停；数值计算选部分主元。
（ch01, ch06）

## 求逆 [A|I] 算法
**何时用**：需要 A⁻¹ 本身（理论/小矩阵）；解方程组不用它。
**做法**：[A|I] → RREF → [I|A⁻¹]；化不出 I ⟺ 不可逆。
**权衡**：2×2 用 ad−bc 公式更快；大矩阵用 LU。
（ch05, ch06）

## LU 分解与三角形求解
**何时用**：同一 A 解多个 b；含逆幂法的迭代。
**做法**：倍加消元记乘数入 L、结果入 U；Ly=b 前代，Ux=y 回代。需行交换时 PA=LU。
**权衡**：一次分解摊销多次求解；不对称/不需要时不强求。
（ch06）

## 行列式快速计算
**何时用**：判可逆、特征方程、体积。
**做法**：小阵余因子展开（选 0 多的行/列）；大阵倍加化三角 × 对角元（数交换定符号）。
**权衡**：克拉默/伴随只用于结构与证明，不用于数值。
（ch08）

## 特征值流水线
**何时用**：对角化、动力系统、马尔可夫稳态。
**做法**：det(A−λI)=0 求 λ → 每个 λ 解 Nul(A−λI) 得特征向量 → 重数配平判可对角化 → A=PDP⁻¹。
**权衡**：三角阵直接读对角；2×2 用迹与行列式；大阵用幂法。
（ch12, ch13, ch14）

## 幂法 / 逆幂法
**何时用**：只要最大（或某个）特征值。
**做法**：x_{k+1}=Axₖ 归一化迭代，分量比值/Rayleigh 商估 λ；逆幂法换 (A−αI)⁻¹，α 取近似位移。
**权衡**：只算一个，代价远小于全分解；α 恰为特征值会奇异。
（ch14）

## Gram-Schmidt 正交化 → QR
**何时用**：需要正交基、QR 分解、数值稳定 LS。
**做法**：vₖ = xₖ − Σ(xₖ·vⱼ/vⱼ·vⱼ)vⱼ；单位化得 Q，系数进 R。
**权衡**：经典法易误差累积，数值实现用修正 Gram-Schmidt 或 Householder。
（ch16）

## 最小二乘三路线
**何时用**：不相容 Ax=b 求近似解；回归拟合。
**做法**：① 正规方程 x̂=(AᵀA)⁻¹Aᵀb（手算）② QR：x̂=R⁻¹Qᵀb（数值）③ 伪逆 x̂=A⁺b（SVD，最稳）。
**权衡**：正规方程条件数平方；生产用 ②③。
（ch16, ch19）

## 投影系数法
**何时用**：正交基下求坐标/投影/最佳逼近。
**做法**：cᵢ = y·uᵢ/uᵢ·uᵢ；ŷ=Σcᵢuᵢ；z=y−ŷ∈W⊥ 验证。
**权衡**：先正交化再投影，永远比解方程便宜。
（ch15）

## 基变换流水线
**何时用**：坐标换基、相似对角化。
**做法**：P_B=[b₁…bₙ]；[x]_B=P_B⁻¹x（解增广阵）；[T]_C=P⁻¹[T]_B P。
**权衡**：方向绕不清就写 x=P_B[x]_B 验算。
（ch10, ch12）

## 马尔可夫稳态
**何时用**：随机矩阵长程行为。
**做法**：解 (P−I)q=0 + Σqᵢ=1；regular 矩阵保证唯一且收敛。
**权衡**：非 regular（有 0/周期）需另行分析。
（ch14）

## 谱定理应用
**何时用**：对称阵对角化、二次型、条件优化。
**做法**：求特征对 → 特征向量单位正交化得 Q → A=QΛQᵀ；max/min xᵀAx（‖x‖=1）= λmax/λmin。
**权衡**：对称阵永远可正交对角化，放心用。
（ch18）

## SVD 构造与截断
**何时用**：伪逆、低秩近似、PCA、压缩。
**做法**：AᵀA 特征分解得 vᵢ、σᵢ → uᵢ=Avᵢ/σᵢ → A=UΣVᵀ；截断前 k 项误差=σ_{k+1}。
**权衡**：构造昂贵但信息最全；PCA 前必须中心化。
（ch19）

## 仿射判定（加高法）
**何时用**：仿射无关、重心坐标、凸包问题。
**做法**：ṽᵢ=[vᵢ;1] 后按线性问题处理；重心坐标解出后验 Σ=1。
**权衡**：多一维行化简换"平移无关"，稳赚。
（ch20）

## 单纯形法循环
**何时用**：规范 max 线性规划。
**做法**：松弛变量入表 → 底行最负列入基 → 最小比值行作主元 → 行变换 → 底行全非负即最优；对偶解读自底行。
**权衡**：顶点跳跃保证收敛；对偶/影子价格免费附带。
（ch23）

## 矩阵博弈求解
**何时用**：两人零和博弈。
**做法**：查鞍点（max-min=min-max）→ 有则纯策略；无则删占优劣行/列 → 解等期望方程（小博弈）或归约为 LP（大博弈，9.4）。
**权衡**：先删减后求解；混合策略值=对偶 LP 公共值。
（ch22, ch23）
