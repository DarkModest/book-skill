## 决策树：解 Ax=b

- 有解吗？→ 无 [0|k≠0] 行：有
  - 唯一还是无穷？→ 有自由变量：无穷（p + Σxᵢvᵢ）；无：唯一
- 无解 → 最小二乘（ch16）：x̂=(AᵀA)⁻¹Aᵀb，几何=投影到 Col A

## 决策树：求特征值

- 三角阵 → 读对角线
- 2×2 → λ²−(tr)λ+det=0
- 小整数阵 → det(A−λI)=0 展开
- 大阵只要最大 → 幂法；要最近的 → 逆幂法
- 对称阵 → 谱定理保证实根+正交基

## 决策树：向量组问题

- 判相关 → p>n 必相关；否则行化简看自由变量
- 求基 → 生成向量排矩阵，主元列（Col）/ 参数化向量（Nul）/ 阶梯形非零行（Row）
- 要正交基 → Gram-Schmidt
- 换基 → P_B 列放新基，x=P_B[x]_B 定方向

## 决策树：最小化 / 拟合类问题

- 均方最小 → 投影/最小二乘（ch16）
- 数据压缩/降秩 → 截断 SVD（误差=σ_{k+1}，ch19）
- 降维找方向 → PCA=协方差 SVD（先中心化！ch19）
- 带约束 ‖x‖=1 优化二次型 → λmax/λmin + 特征向量（ch18）
- 不等式约束+线性目标 → LP：图解（2 维）或单纯形法（ch22/23）
- 对抗性决策 → 博弈：鞍点？否则混合策略/LP 对偶（ch22/23）

## 阈值与默认

- 行化简：判相容到阶梯形即可停，RREF 只在需要通解/求逆时化
- 数值解 LS：QR 或 SVD，不用 (AᵀA)⁻¹（条件数平方）
- LU：需行交换就上 PA=LU（部分主元）
- 幂法：每步归一化；位移 α 别取到特征值本身
- PCA：先中心化；截断看奇异值"肘部"
- 马尔可夫：regular（严格正）才保证收敛唯一稳态
- 单纯形：底行全非负=最优；选行用最小比值防不可行

## 高频错误信号

- (AB)⁻¹ 写成 A⁻¹B⁻¹ → 反序！
- 用 RREF 的列当 Col A 的基 → 用原矩阵主元列
- 非齐次解集当子空间 → 差一个平移
- P_B 方向搞反 → 锚点 x=P_B[x]_B
- 奇异值当特征值 → σᵢ=√λᵢ(AᵀA)
- 复数内积用转置 → 用共轭转置 Āᵀ
- PCA 忘中心化 → 第一成分被均值污染
- 对偶约束方向写反 → ≤↔≥、A↔Aᵀ、b↔c
