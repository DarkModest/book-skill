# Chapter 20: 仿射组合、仿射无关与凸组合（教材 8.1–8.3）

> 章首介绍性实例：柏拉图多面体——五种正多面体（四面体、立方体、八面体、十二面体、二十面体）引出高维几何对象。第 8 章把"组合系数"分三个等级：线性（任意）、仿射（和为 1）、凸（和为 1 且非负）——约束越强，几何越"鼓"。

## Core Idea
**仿射 = 线性组合减去"平移自由度"**：系数和为 1 的组合不受原点选取影响；**凸 = 仿射再禁负权**：不许"越过"点连线之外。三级递进给出直线/平面/凸包/极点的完整几何语法。

## 框架与定理

### 仿射组合（8.1）
**仿射组合**：y = c₁v₁ + … + cₚvₚ 且 c₁+…+cₚ = 1。
- 等价式：y = v₁ + c₂(v₂−v₁) + … + cₚ(vₚ−v₁)（以 v₁ 为"临时原点"的线性组合）
- **仿射包/仿射集**：aff S = S 的全部仿射组合；仿射集 = 对仿射组合封闭（过 p,q 的直线 {(1−t)p+tq}、过三点的平面）
- 平移不变：仿射性质与原点位置无关（与线性子空间的本质区别）

### 仿射无关性（8.2）
{v₁,…,vₚ} **仿射无关**：c₁v₁+…+cₚvₚ = 0 且 Σcᵢ=0 只有零解。
- **判定技巧**：把向量写成齐次坐标 $\tilde{v}_i = \left[\begin{smallmatrix}v_i\\1\end{smallmatrix}\right]$，仿射无关 ⟺ 加高向量线性无关（多一维的行化简）
- **仿射坐标/重心坐标**：仿射无关集 S={v₁,…,vₖ} 下，每点 p 有唯一 p = c₁v₁+…+cₖvₖ，Σcᵢ=1；cᵢ 称 p 关于 S 的**重心坐标（barycentric coordinates）**
- 应用：计算机图形学的三角形插值（颜色/纹理按重心坐标混合）、有限元

### 凸组合与凸集（8.3）
**凸组合**：仿射组合 + 权全非负；**凸集**：对一切凸组合封闭（等价于：任取两点，连线段在集内）。
- **凸包**：conv S = S 的全部凸组合（最小的包含 S 的凸集）
- 典型凸集：球、椭球、超平面/半空间、多面体、ℝⁿ 本身；直线和平面既是仿射也是凸集
- **极值点（extreme point）**：凸集 S 中的点 p，不能表示为 S 中不同两点 p=x,y 的内点（p 不在任何线段 x𝓨 内部）
- 凸组合的传递：凸集的凸组合仍在凸集中（反复使用）

## Mental Models
- **三级权限模型**：线性组合（任意权）⊇ 仿射组合（Σ=1）⊇ 凸组合（Σ=1, cᵢ≥0）；几何上从"整个空间"收缩到"最鼓的骨架"。
- **加高技巧**：仿射问题 = 在 ℝ^{n+1} 的平面 x_{n+1}=1 上的线性问题——降维打击。
- **凸包 = 橡皮筋**：把钉子（点集）圈起来的最紧橡皮圈。

## Anti-patterns
- **把仿射集当子空间**：仿射集不必过原点；"过原点的仿射集"才是子空间。
- **重心坐标忘验 Σ=1**：解出权后必须核对和为 1，否则只是线性坐标。
- **把凸包当"全部点的连线"只连一层**：高维中凸包要取反复凸组合的闭包（不过有限点集一层即闭）。
- **极值点判定只看顶点称呼**：极值点定义于凸集内点/线段表示，"看起来是角"不严谨；用定义验证。

## Worked Example
v₁=(1,2)ᵀ, v₂=(2,5)ᵀ, v₃=(1,3)ᵀ。判断仿射无关并求 p=(2/3, 2)ᵀ 的重心坐标。

加高：$\tilde{v}_1=\left[\begin{smallmatrix}1\\2\\1\end{smallmatrix}\right],\tilde{v}_2=\left[\begin{smallmatrix}2\\5\\1\end{smallmatrix}\right],\tilde{v}_3=\left[\begin{smallmatrix}1\\3\\1\end{smallmatrix}\right]$。行列式 = 1(5−3) − 2(2−1) + 1(6−5) = 2−2+1 = 1 ≠ 0 → 仿射无关。
解 p = c₁v₁+c₂v₂+c₃v₃, Σc=1：由 c₂ = p−v₁ 在差向量下的系数：p−v₁ = (−1/3, 0)ᵀ，v₂−v₁ = (1,3)ᵀ, v₃−v₁ = (0,1)ᵀ → c₂=−1/3, c₃=0, c₁=4/3。
验算：4/3(1,2) − 1/3(2,5) + 0 = (4/3−2/3, 8/3−5/3) = (2/3, 1)…（改为 p 在三角形外的情形；p 在三角形内当且仅当重心坐标全非负——此处 c₂<0 → p 在三角形外。）

## Reference Tables

| 组合类型 | 约束 | 几何对象 |
|---|---|---|
| 线性 | 无 | 生成子空间 |
| 仿射 | Σcᵢ=1 | 直线/平面/仿射包 |
| 凸 | Σcᵢ=1, cᵢ≥0 | 线段/三角形/凸包 |

## Key Takeaways
1. 仿射 = 平移无关的线性；加高一行是通用判定法。
2. 重心坐标 = 三角形/单纯形内的"地址"，全非负 ⟺ 点在内部。
3. 凸性是优化的地形条件：凸集上局部=全局（第 9 章线性规划的地基）。
4. 极值点是多面体表示理论的原子（下一章超平面与顶点）。
