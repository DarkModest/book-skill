# Chapter 12: 特征向量、特征方程与对角化（教材 5.1–5.3）

> 章首介绍性实例：动力系统与斑点猫头鹰——Lamberson 阶段矩阵模型 x_{k+1} = A xₖ（幼年/半成年/成年三个生命阶段），种群存亡由 A 的最大特征值决定（详见 ch14）。特征值是"变换的内在频率"。

## Core Idea
**Ax = λx：x 是只被拉伸不被转向的方向，λ 是该方向的拉伸率**。找到足够多的特征方向 → 换到特征基 → 矩阵退化为对角阵 A = PDP⁻¹ → 幂运算一步到位：Aᵏ = PDᵏP⁻¹。

## 框架与定理

### 特征向量与特征值（5.1）
定义：A n×n，非零 x 满足 Ax=λx；x 属于 λ 的**特征空间** Eig(A,λ) = Nul(A−λI)。
- **定理 1**：三角矩阵的特征值 = 主对角线元素
- **定理 2**：对应相异特征值的特征向量必线性无关
- 求法：解特征方程得 λ → 对每个 λ 解 (A−λI)x=0 得特征空间
- 应用伏笔：λ=0 ⟺ 不可逆；列昂惕夫交换模型的均衡价格 = 正特征向量

### 特征方程（5.2）
- **定理 3**：λ 是 A 的特征值 ⟺ det(A−λI) = 0（**特征方程**）
- det(A−λI) 是 λ 的 n 次多项式（**特征多项式**）；2×2 时：λ² − (trace)λ + det A = 0（**迹 = 特征值之和，det = 特征值之积**，一般成立）
- **定理 4**：A 与 B 相似（B=P⁻¹AP）⟹ 有相同的特征多项式（从而相同的特征值及重数；反之不对）
- Aᵏx 的行为：若 Ax=λx，则 Aᵏx = λᵏx——幂的渐近方向由 |λ| 最大的特征值主导
- 代数重数（特征多项式中根的重数）vs 几何重数（特征空间维数）：**几何 ≤ 代数**

### 对角化（5.3）
A **可对角化** ⟺ 存在可逆 P、对角 D：A = PDP⁻¹ ⟺ P 的列（特征向量）无关、D 的对角元（特征值）与列一一对应。
- **定理 5（对角化定理）**：A 可对角化 ⟺ A 有 n 个线性无关的特征向量
- **定理 6（充分条件）**：有 n 个**相异**特征值 ⟹ 可对角化（充分不必要）
- **定理 7**：相异特征值 λ₁,…,λₚ 的各特征空间取基，所有向量的合集线性无关；(b) A 可对角化 ⟺ 各特征空间的维数之和为 n（即"几何重数配平"）
- 算法：(1) 解特征方程得 λᵢ 与重数 (2) 每个特征空间求基 (3) 合并若凑满 n 个无关向量 → P（定理7）；否则不可对角化
- **定理 8（对角矩阵表示）**：A=PDP⁻¹ 时，取 𝓑 为 P 的列向量组，则 D 是 x↦Ax 的 𝓑-矩阵——对角化 = 换到特征基
- 对角化威力：Aᵏ = PDᵏP⁻¹（动力系统、斐波那契、图上的随机游走）

## Mental Models
- **特征向量 = 变换的"不动方向"**：换到特征基后，A 只是在每个方向上缩放 λ 倍。
- **对角化 = 找到好坐标系**：P⁻¹AP = D 即"在新基下记录的同一变换"最简形态。
- **幂的赢家通吃**：反复作用后，最大 |λ| 的分量胜出（迭代估计 5.8 的原理）。

## Anti-patterns
- **用列行化简找特征向量**：必须解 (A−λI)x=0，特征向量不在列里。
- **重数凑不齐硬对角化**：几何重数不足 → 不可对角化，只能若尔当形（超出本书范围）。
- **以为相似矩阵特征向量也相同**：特征值相同（含代数重数），特征向量由各自的 P 决定。
- **P 的列与 D 的对角元错位**：第 j 列特征向量对应第 j 个对角元，一一锁定。

## Worked Example
A = $\left[\begin{smallmatrix}3&-2\\1&0\end{smallmatrix}\right]$。
特征方程：det$\left[\begin{smallmatrix}3-\lambda&-2\\1&-\lambda\end{smallmatrix}\right]$ = λ² − 3λ + 2 = 0 → λ = 1, 2。
λ=1：A−I = $\left[\begin{smallmatrix}2&-2\\1&-1\end{smallmatrix}\right]$ → x₁ = x₂ → v₁ = (1,1)ᵀ。
λ=2：A−2I = $\left[\begin{smallmatrix}1&-2\\1&-2\end{smallmatrix}\right]$ → x₁ = 2x₂ → v₂ = (2,1)ᵀ。
P = [v₁ v₂] = $\left[\begin{smallmatrix}1&2\\1&1\end{smallmatrix}\right]$，D = diag(1,2)，A = PDP⁻¹。
幂：Aᵏ = P diag(1, 2ᵏ) P⁻¹ → 渐近方向 v₂（|λ|max = 2 胜出）。

## Key Takeaways
1. "特征方向 + 拉伸率"是矩阵除"逐元素运算"外最重要的结构化视角。
2. 判对角化看重数配平，不是只看特征值个数。
3. 相似矩阵共享特征多项式——不变量思想（trace、det、秩同理）。
4. Aᵏx = PDᵏP⁻¹x 是一切动力系统长程行为分析的引擎（下一章全面展开）。
