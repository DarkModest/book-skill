# Chapter 4 (下): 线性变换与线性模型（教材 1.8–1.10）

> 1.8–1.9 用动态、几何的观点重新解释矩阵乘法（线性变换是 Lay 全书主线之一）；1.10 是第 6 版强化的应用节：减肥食谱（线性规划原型）、电网络、线性差分方程模型。

## Core Idea
**线性变换 T: ℝⁿ→ℝᵐ 就是矩阵变换**——每个线性变换恰有一个标准矩阵 A 使 T(x)=Ax；"T 的性质"完全翻译成"A 的列的性质"（单射 ⟺ 列无关，满射 ⟺ 每行有主元）。

## 框架与定理

### 线性变换（1.8）
变换（函数/映射）T: ℝⁿ→ℝᵐ，定义域 ℝⁿ、余域 ℝᵐ、像 T(x)。
**线性**的条件：
$$T(\boldsymbol{u}+\boldsymbol{v}) = T(\boldsymbol{u})+T(\boldsymbol{v}), \qquad T(c\boldsymbol{u}) = cT(\boldsymbol{u})$$
推论：T(0)=0；T(cu+dv)=cT(u)+dT(v)；反之线性条件成立即 T 线性。
- **反例**：平移 T(x)=x+b（b≠0）不是线性变换（T(0)≠0）；T(x)=‖x‖、T(x)=x₁² 也不是

### 标准矩阵（1.9）
**定理 10**：T: ℝⁿ→ℝᵐ 线性 ⟺ 存在**唯一**矩阵 A 使 T(x)=Ax，且
$$A = [\,T(\boldsymbol{e}_1)\ T(\boldsymbol{e}_2)\ \cdots\ T(\boldsymbol{e}_n)\,]$$
（标准基的像按列排开——求标准矩阵只需看基向量去哪了；由此每个线性变换都是矩阵变换）

另：**定理 5**（1.8）给出 T(x)=Ax 的基本性质：T(0)=0、T(cu+dv)=cT(u)+dT(v)。
常用变换的标准矩阵：旋转角 θ：$\left[\begin{smallmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{smallmatrix}\right]$；关于 y 轴对称、剪切（shear）$\left[\begin{smallmatrix}1&k\\0&1\end{smallmatrix}\right]$、投影/伸缩等。

### 单射与满射的矩阵判定（1.9 定理 11、12）
对线性变换 T(x)=Ax（A 为 m×n）：
- **T 满射（onto）⟺ 余域每个 b 都被打到 ⟺ Ax=b 对一切 b 相容 ⟺ A 每行有主元** ⟹ 需要 m≤n
- **T 单射（one-to-one）⟺ T(u)=T(v)⟹u=v ⟺ 列线性无关 ⟺ 每列有主元** ⟹ 需要 n≤m
- **定理 12** 汇总：m×n 矩阵：(a) 满射 ⟺ 每行有主元；(b) 单射 ⟺ 每列有主元
- 推论：n>m 时不可能单射（p>n 向量必相关）；n<m 时不可能满射

### 线性模型（1.10）
- **构造有营养的减肥食谱**（剑桥食谱，Howard 博士）：食物营养含量矩阵 × 食用量向量 = 营养需求向量；含不等式约束时是**线性规划**的雏形
- **电网络分析**：回路电流方程组（欧姆定律 + 基尔霍夫电压定律）
- **线性差分方程**：x_{k+1} = A x_k 模型（人口迁移、滤波），是动力系统（ch14）与马尔可夫链（ch14/ch05§5.9）的入口

## Mental Models
- **把矩阵看成"动作"**：T(x)=Ax 是把向量送进机器 A；复合动作=矩阵乘法（2.1、3.2 展开）。
- **看基向量去哪，就知道变换去哪**：标准矩阵的两列 = e₁、e₂ 的像（画图时先追 e₁、e₂）。
- **单射满射都是主元判据**：与"解的存在唯一"（定理 3/4）完全同构，只是语言换成了变换。

## Anti-patterns
- **以为所有映射都线性**：平移、取范数、非线性坐标变换都不线性；检验必做 T(0)。
- **标准矩阵列的顺序放错**：第 j 列是 T(e_j)，不是第 j 行。
- **把"满射"误认为"单射"**：满射看行主元（余域 ℝᵐ 的覆盖），单射看列主元（定义域 ℝⁿ 的不粘连）。
- **差分方程只列式不建模方向**：注意 M 的列写"从哪迁到哪"（5.9 的迁移矩阵例子：列是概率向量）。

## Worked Example
T: ℝ²→ℝ³，T(x₁,x₂) = (x₁+2x₂, −x₁, 3x₁+x₂)。求标准矩阵并判定单射/满射。

A = [T(e₁) T(e₂)] = $\left[\begin{smallmatrix}1&2\\-1&0\\3&1\end{smallmatrix}\right]$。3 行 2 列，行化简后只有 2 个主元 < 3 行 → 不满射；2 列都有主元 → 列无关 → 单射。
几何解读：平面 ℝ² 被单射地嵌入 ℝ³（像是一张过原点的平面）。

## Key Takeaways
1. 求标准矩阵的口诀：追标准基——A 的列是 e_j 的像。
2. 单射/满射判据与解的存在唯一性是同一套主元几何，两套语言要能互译。
3. 维数不等式：单射需 n≤m，满射需 n≥m；方形矩阵才可能既单又满（可逆的伏笔）。
4. 1.10 的差分方程 x_{k+1}=Ax_k 是第 5 章"动力系统"的直通车。
