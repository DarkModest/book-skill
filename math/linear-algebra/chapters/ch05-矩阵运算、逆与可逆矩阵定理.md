# Chapter 5: 矩阵运算、逆与可逆矩阵定理（教材 2.1–2.3）

> 章首介绍性实例：波音幻影工作室用三维 CFD 研究飞机气流，Ax=b 达 200 万变量——需要分块与分解（本章 2.4/2.5）才能求解。

## Core Idea
**矩阵代数大部分像实数运算，但乘法不可交换、没有消去律**——可逆矩阵定理（IMT）把"什么时候矩阵表现得像非零实数"总结成一张 12 条目清单，是全书最重要的一张网。

## 框架与定理

### 矩阵运算（2.1）
- 加法/标量乘法逐元素；**乘法**：$(AB)\boldsymbol{x} = A(B\boldsymbol{x})$，(AB)_{ij} = 第 i 行·第 j 列
- 有定义条件：A_{m×n} B_{n×p} = C_{m×p}（内维相等）
- **不成立的律**：一般 AB≠BA；AB=0 推不出 A=0 或 B=0；AC=BC 推不出 A=B（无消去律）
- **转置**：$(A^T)_{ij}=A_{ji}$；性质 $(AB)^T = B^TA^T$（顺序反）
- 数值观点：内积/点积 = 行·列；矩阵乘法的"列观点"（AB 的每列是 A 乘 B 的对应列）

### 矩阵的逆（2.2）
n×n 矩阵 A **可逆**：存在 AC=CA=I 的 C（记 A⁻¹）。可逆 ⟺ 双射线性变换。
- **唯一性**：逆若存在必唯一
- 2×2 公式：$A=\left[\begin{smallmatrix}a&b\\c&d\end{smallmatrix}\right]$ 可逆 ⟺ ad−bc≠0；$A^{-1}=\tfrac{1}{ad-bc}\left[\begin{smallmatrix}d&-b\\-c&a\end{smallmatrix}\right]$
- **解 Ax=b**：若 A 可逆，x=A⁻¹b（**理论工具**；实际数值计算用行化简，见 2.5 的 LU）
- 求逆算法：[A | I] → 行化简 → [I | A⁻¹]；若化不到 I 则不可逆
- 性质：$(A^{-1})^{-1}=A$，$(AB)^{-1}=B^{-1}A^{-1}$（顺序反），$(A^T)^{-1}=(A^{-1})^T$

### 可逆矩阵的特征（2.3）——初等矩阵与 IMT
**初等矩阵**：单位矩阵经一次初等行变换得到的矩阵；左乘初等矩阵 = 做一次对应行变换；初等矩阵必可逆（逆=逆变换）。

**定理（AB=I 的推论）**：方阵 A、B 满足 AB=I ⟹ A、B 都可逆且 B=A⁻¹——验证逆只需单侧乘积。

**可逆矩阵定理（Invertible Matrix Theorem, IMT；2.3）**——设 A 为 n×n 方阵，以下 **12 条命题**等价（同真同假）：
(a) A 是可逆矩阵
(b) A 行等价于 n×n 单位矩阵
(c) A 有 n 个主元位置
(d) Ax=0 仅有平凡解
(e) A 的各列线性无关
(f) 线性变换 x↦Ax 是一对一的
(g) 对 ℝⁿ 中任意 b，Ax=b 至少有一个解
(h) A 的各列生成 ℝⁿ
(i) 线性变换 x↦Ax 把 ℝⁿ 映到 ℝⁿ 上（满射）
(j) 存在 n×n 矩阵 C 使 CA=I
(k) 存在 n×n 矩阵 D 使 AD=I
(l) Aᵀ 是可逆矩阵
后续章节会向这张网追加条目：det A ≠ 0（3.2 定理4）、0 不是特征值（第5章）等。
**用法**：证明"某条件 ⟹ 另一条件"时直接引用等价性，不必重新构造证明。IMT 只对**方阵**成立；把矩阵分为可逆（非奇异）与不可逆（奇异）两大不相交类。

**消去律**：CA=CB 且 A 可逆 ⟹ C=B。

## Mental Models
- **可逆 = "信息无损"**：x 可从 Ax 唯一还原；不可逆 = 有方向被压扁（有自由变量）。
- **IMT 是一张连通网**：任一条件破了，全体皆破；考试与证明中最常用的"免费桥梁"。
- **逆的算法用行变换，不用伴随式**：2×2 公式只适合手算小矩阵。

## Anti-patterns
- **把 (AB)⁻¹ 写成 A⁻¹B⁻¹**：顺序必须反。
- **对非方阵谈逆**：只有方阵才可能双向可逆；长方阵只有广义逆（7.4 的伪逆）。
- **数值计算中用 A⁻¹b 解方程**：舍入误差与计算量都不划算，用行化简/LU/QR。
- **把 IMT 用于长方阵**：等价链只对方阵闭合。

## Worked Example
求 $A=\left[\begin{smallmatrix}0&1&2\\1&0&3\\4&-3&8\end{smallmatrix}\right]$ 的逆。

[A | I] = $\left[\begin{smallmatrix}0&1&2&|&1&0&0\\1&0&3&|&0&1&0\\4&-3&8&|&0&0&1\end{smallmatrix}\right]$ → 交换 r1,r2 → 消去 → 得 RREF $[I|A^{-1}]$：
$$A^{-1}=\left[\begin{smallmatrix}-9&14&-3\\-4&8&-2\\3&-4&1\end{smallmatrix}\right]$$
验证：A·A⁻¹=I。（若某行化为 0|k，k≠0，则不可逆——IMT 的 (j) 断掉。）

## Key Takeaways
1. 矩阵代数三条"不"：不交换、无消去、无零因子——所有代数变形前先检查。
2. IMT 是方阵的"体检表"：n 个主元是中心，det 与特征值都挂在网上。
3. 求逆用 [A|I] 行化简；解方程不用逆。
4. 初等矩阵把"行变换"代数化，使"A 可逆 ⟺ 初等矩阵之积"成为可能。
