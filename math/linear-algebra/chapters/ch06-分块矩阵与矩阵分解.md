# Chapter 6: 分块矩阵与矩阵分解（教材 2.4–2.5）

> 章首实例的落点：波音气流问题 200 万变量的稀疏方程组，靠分块 + LU 分解才能在合理时间内反复求解。本节给出全书的口号："**矩阵乘法是数据的综合，矩阵分解是数据的分解**"。

## Core Idea
**分块是把矩阵当"以矩阵为元素"的对象**——正确分块后乘法/逆的规则与数完全一样；**分解（A=LU 等）是把一次昂贵的行化简摊销到多次求解**：一次分解，任意多个 b 都快速解。

## 框架与定理

### 分块矩阵（2.4）
把 A 用水平/竖直线切成子块，可当作元素进行加法与乘法（分块尺寸匹配时）。**分块转置**：先转置块阵，再把每块转置：
$$\left[\begin{smallmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{smallmatrix}\right]^T=\left[\begin{smallmatrix}A_{11}^T&A_{21}^T\\A_{12}^T&A_{22}^T\end{smallmatrix}\right]$$

**分块三角阵的逆**（2.4 节）：若 $A=\left[\begin{smallmatrix}A_{11}&0\\A_{21}&A_{22}\end{smallmatrix}\right]$（A₁₁、A₂₂ 可逆），则
$$A^{-1}=\left[\begin{smallmatrix}A_{11}^{-1}&0\\-A_{22}^{-1}A_{21}A_{11}^{-1}&A_{22}^{-1}\end{smallmatrix}\right]$$
**列分块的乘法**：AB 的每列 = A·(B 的对应列)——并行计算与"逐步构造解"的基础。$X^TX$ 的分块形式常用于统计算法（如 7.5 协方差）。

### LU 分解（2.5）
设 A 可行化简为阶梯形且**无需行交换**：
$$A = LU$$
L = m×m **单位下三角**（对角线全 1），U = m×n 阶梯形。
- **用途**：解一系列 Ax=b₁,…,bₚ（同系数矩阵）——逆幂法（5.8）、投入-产出等场景
- **算法**：向前阶段用倍加行变换 E₁…E_p 化 A 为 U；则 $A=E_p^{-1}\cdots E_1^{-1}U$，所有乘数（multiplier）填入 L 的对应下三角位置
- **求解 Ax=b**：Ly=b（前代，forward substitution）→ Ux=y（回代，backward substitution）
- **行交换的情形**：先做 PA=LU（部分主元法，数值稳定）；处理"局部"交换的代数版本用排列矩阵 P
- **计算量**：n×n 一般矩阵 LU ≈ (2/3)n³ flops（消去），两三角形求解各 ~n² flops——一次分解多次摊销

### 其他分解的线索（习题引入）
- 对称正定阵的 Cholesky 型分解（A=LLᵀ，习题）
- QR 分解（6.4 正规登场）；对角化（ch12）；谱分解与 SVD（ch18/ch19）
- 1.9 提到：复合变换 = 矩阵乘积 = 变换的"分解综合"

## Mental Models
- **分块 = 城市街区地图**：把细粒度数据打包成粗粒度单元处理，规则不变。
- **LU = 一次装修多次入住**：行化简的昂贵部分只做一次，后续每个 b 只花两个三角形求解的钱。
- **U 是阶梯形结果，L 是"操作日志"**：L 的 (i,j) 元记录第 j 行乘以多少加到第 i 行。

## Anti-patterns
- **分块尺寸不匹配就相乘**：行的块数=左因子行块数；列的块数=右因子列块数，且相邻维数相等。
- **忘转置子块**：分块转置要双重转置。
- **需要行交换时硬用 A=LU**：会得到错误的 L；应使用 PA=LU。
- **对每个新 b 重新行化简**：经典浪费——先 LU。

## Worked Example
$L\boldsymbol{y}=\boldsymbol{b}$ 前代 + $U\boldsymbol{x}=\boldsymbol{y}$ 回代：设
$$L=\left[\begin{smallmatrix}1&0&0\\3&1&0\\-4&2&1\end{smallmatrix}\right],\quad U=\left[\begin{smallmatrix}2&-2&4\\0&-1&3\\0&0&5\end{smallmatrix}\right],\quad \boldsymbol{b}=\left[\begin{smallmatrix}6\\19\\-2\end{smallmatrix}\right]$$
前代：y₁=6；3·6+y₂=19→y₂=1；−4·6+2·1+y₃=−2→y₃=22。
回代：5x₃=22→x₃=4.4；−x₂+3(4.4)=1→x₂=14.2；2x₁−2(14.2)+4(4.4)=6→x₁=17。
共 2·(1+2+3)=12 次乘加，远少于重新消元的 2n³/3 量级。

## Key Takeaways
1. 分块矩阵的全部规则 = 把子块当元素，双重转置别忘。
2. LU 分解的价值在"多次求解"场景；乘数日志进 L，阶梯结果进 U。
3. 行交换不可省：实践中用 PA=LU（部分主元）保数值稳定。
4. "分解视角"贯穿全书：LU→正交化 QR→特征对角化→SVD，工具越来越几何。
