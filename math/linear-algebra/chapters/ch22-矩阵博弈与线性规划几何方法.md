# Chapter 22: 矩阵博弈与线性规划几何方法（教材 9.1–9.2）

> 章首介绍性实例：柏林空运（1948 Operation Vittles）——精密规划催生线性规划理论与丹齐格（George Dantzig）单纯形法。9.1 从两人零和博弈开始，9.2 用几何解小规模线性规划。

## Core Idea
**矩阵博弈 = 支付矩阵上的"最优 worst-case"**：R 想最大化保底收益，C 想最小化上限损失；有鞍点时纯策略定胜负，无鞍点时**混合策略 + 期望支付**把博弈变成线性代数问题。线性规划 = 不等式约束 + 线性目标，二维情形画图即可读出最优。

## 框架与定理

### 矩阵博弈（9.1）
**支付矩阵** A=[aᵢⱼ]：行玩家 R 出策略 i、列玩家 C 出策略 j 时，R 从 C 处赢得 aᵢⱼ（负值=R 付款）；两人所得代数和为零 → **两人零和博弈**。
- **纯策略与鞍点**：若存在位置 (i*,j*) 使
$$\max_i \min_j a_{ij} = \min_j \max_i a_{ij} = v$$
则 (i*,j*) 是**鞍点**，v 是博弈的**值**，对应为最优纯策略——"双方都守住各自 worst-case"
- **混合策略**：x∈ℝᵐ（R 的概率分布）、y∈ℝⁿ；**期望支付** E(x,y) = xᵀAy
- R 的最优问题：max_x min_y xᵀAy（对一切 C 的策略最大化保底）；C 反向；**混合策略下博弈总有值**（minimax 定理，冯·诺依曼；9.4 用对偶证明）
- **占优策略删减**：某行恒劣于另一行 → 删除（化简支付矩阵）；逐步删减常使大博弈变小博弈
- 例：硬币游戏（1分/5分/10分，同币值规则）构建 3×3 支付矩阵，逐一填 aᵢⱼ

### 线性规划——几何方法（9.2）
**线性规划问题** = 变量不等式约束组 + 线性目标函数 f(x)，求 max/min。
- **可行集 F**：所有约束的交集 = 凸多面体（ch21 的几何）
- Shady-Lane 草种公司例：EverGreen/QuickGreen 混合种子受羊茅/黑麦/早熟禾库存约束，max 2x₁+3x₂
- **图解法**：画可行域 → 等值线 f=c 平移 → 最优点
- **定理（线性规划基本定理）**：目标在可行集上取得最优时，**至少一个最优点是 F 的极值点（顶点）**——搜索范围从无限集缩到有限顶点集
- 特殊情形：可行集无界时目标可能无界（无最优）；不可行时无解
- 几何直觉是理解 9.3 单纯形法"沿顶点走"的前提

## Mental Models
- **零和博弈 = 保底竞赛**：R 找"最坏情况下最好"的行，C 找"最坏情况下最好"的列；两边最坏值相遇处就是鞍点。
- **无鞍点 = 要摇骰子**：纯策略被猜透就输；按最优混合策略随机出招锁定期望值。
- **线性规划 = 山坡上找最高点**：可行域是凸的，等值线是平的——最高点必在角上。

## Anti-patterns
- **先验认为博弈总在纯策略有解**：多数博弈无鞍点（如猜硬币），必须混合策略；max-min 不等时别硬找。
- **支付矩阵符号约定混乱**：aᵢⱼ 是 R 赢的金额（C 付给 R）；构造矩阵时行=R 的选择、列=C 的选择。
- **图解法忽略可行域边界**：最优点可能在约束"交角"处而非肉眼直观的"中间"；逐顶点验算保险。
- **把无界可行域当有最优**：等值线能无限平移 → 目标无界（max +∞），报告"无有限最优"。

## Worked Example
猜硬币博弈：支付矩阵 A = $\left[\begin{smallmatrix}1&-1\\-1&1\end{smallmatrix}\right]$（R 出正面/反面，同面 R 赢）。
- 无鞍点：max min = −1 < min max = 1 → 纯策略无值
- 混合策略：R 以概率 p 出正面。E(p, 正面) = 2p−1，E(p, 反面) = 1−2p。令相等：2p−1 = 1−2p → p = 1/2
- 博弈值 v = 0：双方各按 (1/2, 1/2) 出招，期望打平——这正是"随机化保证不被剥削"

## Key Takeaways
1. 鞍点判定一条式：max-min 与 min-max 相等即纯策略可解。
2. 混合策略的核心恒等式：最优混合使对手**所有**纯策略期望相等（无差异原理）。
3. 线性规划基本定理把无限搜索压缩到顶点——单纯形法的理论执照。
4. 占优删减是博弈论的"预消化"，先删后算。
