# Chapter 17: 内积空间及其应用（教材 6.7–6.8）

> 把"长度/角度"从 ℝⁿ 推广到任何函数/多项式/信号空间（6.7），然后收获两大应用：加权最小二乘与趋势分析、**傅里叶逼近**（6.8）——机器学习中的正交基思想源头。

## Core Idea
**内积是个"接口"**：只要集合上定义了满足公理的内积，就自动拥有长度、距离、正交、投影、Gram-Schmidt 全套几何。函数空间 C[0,2π] 配上 ∫fg 就能谈"最佳逼近"——傅里叶级数是正交投影在连续世界的化身。

## 框架与定理

### 内积空间（6.7）
**内积公理**（对任意 u,v,w∈V，标量 c）：
1. u·v = v·u 2. (u+v)·w = u·w + v·w 3. c(u·v) = (cu)·v 4. v·v ≥ 0，=0 ⟺ v=0
- 由此自动导出：‖v‖=√(v·v)；**柯西-施瓦茨不等式** |u·v| ≤ ‖u‖‖v‖；**三角不等式** ‖u+v‖ ≤ ‖u‖+‖v‖
- **加权内积**（ℝⁿ 上）：Σcᵢuᵢvᵢ（cᵢ>0）——各坐标重要性不同时的"尺子"
- **多项式空间内积**：⟨p,q⟩ = ∫₀¹ p(t)q(t)dt；**函数空间 C[0,2π]**：⟨f,g⟩ = ∫₀^{2π} f g dt
- 内积空间的子空间同样有正交基与投影；Gram-Schmidt 原样可用

### 内积空间的应用（6.8）
- **加权/相对最小二乘**：残差重要性不同 → 加权设计矩阵（把每行除以权重 √cᵢ 再走标准 LS）
- **趋势分析**：时间序列 = 线性趋势 + 周期项 + 噪声；用正交多项式列（如切比雪夫型正交多项式 X₀=1, X₁=2t−1, X₂=6t²−6t+1…）分解
- **傅里叶级数（wave-form 拟合）**：在 C[0,2π] 中用正交集
$$\{1, \cos t, \sin t, \cos 2t, \sin 2t, \ldots\}$$
逼近 f：**n 阶傅里叶逼近** = f 到三角多项式子空间的正交投影
- **傅里叶系数**（投影系数，内积算出）：
$$a_k = \frac{1}{\pi}\int_0^{2\pi} f(t)\cos kt\,dt,\qquad b_k = \frac{1}{\pi}\int_0^{2\pi} f(t)\sin kt\,dt,\qquad a_0=\frac{1}{2\pi}\int f$$
- **傅里叶级数**：无穷和 a₀ + Σ(aₖcos kt + bₖsin kt)，在内积收敛意义下代表 f
- 应用：信号频谱、滤波（去高频=去 sin/cos 高阶项）、偏微分方程分离变量

## Mental Models
- **内积 = 自定义尺子 + 量角器**：换内积不换定理——整套正交理论是"内积无关"的。
- **投影 = 最佳逼近的连续版**：傅里叶系数就是"y·uᵢ/uᵢ·uᵢ"换积分号。
- **正交多项式列 = 趋势的"频率分解"**：低阶=长期趋势，高阶=细节/噪声。

## Anti-patterns
- **把内积当"任意双线性式"**：必须满足四公理（尤其正定性 v·v≥0）；违反则"长度"不是长度。
- **忘除以基的范数**：三角函数集 {1, cos kt, sin kt} 正交但非标准正交；系数公式含 1/π 因子，漏了就错。
- **傅里叶级数逐点收敛误解**：内积意义下收敛（均方收敛），逐点/一致收敛有额外条件（超出本书）。
- **趋势分析中把噪声列当趋势**：阶数过高=拟合噪声（过拟合的线性代数面孔）。

## Worked Example
f(t) = t on [0, 2π]，求一阶傅里叶逼近。

a₀ = (1/2π)∫₀^{2π} t dt = π。
a₁ = (1/π)∫₀^{2π} t·cos t dt = 0（分部积分，全周期积分为 0）。
b₁ = (1/π)∫₀^{2π} t·sin t dt = (1/π)(−2π) = −2。
**f ≈ π − 2sin t**（一阶逼近）。残差 ⊥ {1, cos t, sin t}——最佳逼近定理的连续版。

## Key Takeaways
1. 四条公理撑起全部几何：换空间只需换内积。
2. 柯西-施瓦茨与三角不等式是内积空间的通用安全带。
3. 傅里叶系数 = 正交投影系数的积分版；逼近 = 投影 = 最佳。
4. 加权 LS/趋势分析把"哪些误差更贵"编进内积——测量学的线性代数。
