# Chapter 3 (下): 解集、应用与线性相关性（教材 1.5–1.7）

> 三节合看：1.5 给出解集的统一结构（齐次解+特解），1.6 展示真实应用建模，1.7 定义贯穿全书的"线性无关"。

## Core Idea
**齐次方程的解集是过原点的子空间（用自由变量参数化），非齐次解集 = 一个特解平移齐次解集**。线性无关性回答"配方是否唯一"，是维数概念的种子。

## 框架与定理

### 齐次方程组 Ax=0（1.5）
- 永远相容（x=0 是平凡解）
- **非平凡解存在 ⟺ 有自由变量 ⟺ 至少一个非主元列**
- 解集参数式：$\boldsymbol{x} = x_2\boldsymbol{v} + x_4\boldsymbol{w} + \cdots$（每个自由变量配一个生成向量），几何上是一张过原点的"平面"（子空间）
- 参数式即**显式描述**；"满足 x₁+2x₂=0 的全体"是**隐式描述**（implicit description）

### 非齐次方程组 Ax=b（b≠0）
**叠加原理**：若 x₁,x₂ 是 Ax=0 的解，则 x₁+x₂、cx₁ 也是。
**解集结构定理**：Ax=b 的解集 = **特解 p + 齐次解集全体**：
$$\boldsymbol{x} = \boldsymbol{p} + x_2\boldsymbol{v} + x_4\boldsymbol{w} + \cdots$$
几何：过 p 平行于齐次解空间的不过原点的"平面"（不是子空间）。

### 应用建模（1.6）
- **配平化学方程式**：原子守恒 → 齐次方程组，求正整数解
- **网络流/交通流量**：节点流入=流出 → 非齐次方程组 + 非负约束
- **电路分析（欧姆/基尔霍夫定律）**：回路电流方程
- **经济/工程线性模型**：承接列昂惕夫章首实例（详见 2.6 的投入-产出模型）

### 线性相关性（1.7）
 indexed 集 {v₁,…,vₚ} **线性无关**：x₁v₁+…+xₚvₚ=0 只有平凡解；**线性相关**：存在不全为零的权。等价说法：某个向量是其余向量的组合 / 权不唯一。

**定理（两个向量的情形）**：{v₁,v₂} 线性相关 ⟺ 其中一个是另一个的倍数。

**线性相关集的刻画**：
(a) 含零向量的集合线性相关
(b) 若某向量是其它向量的组合，则整个集合线性相关

**定理（向量个数上限）**：ℝⁿ 中向量个数 p > n 时必线性相关。（n 个未知数 p 个方程的齐次组必有自由变量）

## Mental Models
- **齐次解 = 骨架，特解 = 平移量**：先解 Ax=0 搭骨架，再找一个特解定位置。
- **线性无关 = "没有冗余向量"**：任何向量都不能由其余向量拼出，配方方式才唯一。
- **p>n 必相关**是"空间维度上限"的第一次显现：ℝ² 里三个向量必然多余一个。

## Anti-patterns
- **忘记平凡解**：齐次组永远相容；"无解"对 Ax=0 不可能。
- **把 Ax=b 的解集当子空间**：b≠0 时解集不过原点，不是子空间（平移集）。
- **用"个数≤维数"判断无关**：p≤n 不保证无关（如 [1 0] 与 [2 0]），还要行化简验证。
- **判断相关性时只看相邻对**：相关可以是"某个向量是其它若干个的组合"，不只是两两成比例。

## Worked Example
求 Ax=0 的参数化解，$A=\left[\begin{smallmatrix}-3&6&-1&1&-7\\1&-2&2&3&-1\\2&-4&5&8&-4\end{smallmatrix}\right]$。

行化简 RREF：$\left[\begin{smallmatrix}1&-2&0&-3&2\\0&0&1&2&-1\\0&0&0&0&0\end{smallmatrix}\right]$。
基本变量 x₁,x₃；自由变量 x₂,x₄,x₅：
$$\boldsymbol{x}=x_2\left[\begin{smallmatrix}2\\1\\0\\0\\0\end{smallmatrix}\right]+x_4\left[\begin{smallmatrix}3\\0\\-2\\1\\0\end{smallmatrix}\right]+x_5\left[\begin{smallmatrix}-2\\0\\1\\0\\1\end{smallmatrix}\right]$$
三个生成向量恰好给出解集的一组基（4.3 节确认）；非齐次版本再加一个特解 p 即可。

## Reference Tables

| 命题 | 判定方法 |
|---|---|
| Ax=0 有非平凡解？ | 有自由变量（非主元列） |

## Key Takeaways
1. 解集结构定理把所有线性方程组的答案统一为"一个点 + 一组方向"。
2. 线性无关用齐次方程定义，判定靠行化简——后续基、坐标、可逆性都依赖它。
3. 应用建模套路：守恒律/平衡律 → 线性方程组 → 解集 → 结合实际约束解读。
4. p>n 立即得相关；p≤n 才需要计算。
