# Chapter 13: 特征向量与线性变换、复特征值（教材 5.4–5.5）

> 5.4 用坐标语言把"特征基"讲透：相似矩阵 = 同一变换的不同基表示；5.5 处理特征方程解出复根的情形——旋转出现在了特征值里。

## Core Idea
**A = PDP⁻¹ 的完整含义：在基 𝓑 下，T 只做坐标缩放（D 的对角元）**。实矩阵的复特征值必成共轭对，对应"旋转+缩放"平面动作——用 2×2 实块 P_j 可以把 D 换成实分块对角形，避免复数运算。

## 框架与定理

### 矩阵表示与特征基（5.4）
- T: V→V 线性，𝓑 基：T 的 **𝓑-矩阵** [T]_𝓑 列 = [T(b_j)]_𝓑
- **特征向量在坐标下就是 D 的列**：若 T(b_j) = λ_j b_j，则 [T]_𝓑 = D（对角）——特征基让矩阵表示最简
- 换基公式：[T]_𝓒 = P⁻¹[T]_𝓑 P（ch10）；A = PDP⁻¹ 的 P⁻¹ 是"标准坐标→特征坐标"，P 是回程
- **投影/反射等变换的特征分解**：对 y 轴投影的特征值 {1, 0}；反射特征值 {1, −1}——"动作类型"编码在特征值里
- 判断动力系统行为：xₖ = P Dᵏ P⁻¹ x₀，看各方向 λᵏ 的增长/衰减/振荡

### 复特征值（5.5）
实方阵 A 的复根 λ = a − bi 必与其共轭 λ̄ = a + bi 成对出现，特征向量亦共轭。
- 2×2 旋转-缩放原型：$C(a,b)=\left[\begin{smallmatrix}a&-b\\b&a\end{smallmatrix}\right]$，特征值 a±bi，作用 = 旋转角 θ（cosθ = a/r）+ 缩放 r=|λ|=√(a²+b²)
- **实分块对角化**：复特征对 (λ, v) 及其共轭可换成一实 2×2 块 P_j = [Re v, Im v]，A = P Ĉ P⁻¹，Ĉ 分块对角、块为 C(a,b) 型——**全程实数运算**
- 复特征向量计算：把 (A−λI) 当复矩阵行化简（复数算术）
- 判据补充：A 可（实）对角化 ⟺ 复情形几何重数 = 代数重数且可实化

## Mental Models
- **特征基 = 变换的"频谱"**：一般基下 T 糅合各方向，特征基下 T 纯缩放——信号处理里频域的线性代数原型。
- **复特征值 = 隐藏的旋转**：|λ|>1 螺旋发散，<1 螺旋收缩，=1 纯旋转——捕食-被捕食系统的振荡就来自复根（ch14）。
- **P_j 的两列 = 旋转平面**：Re v、Im v 张开的平面就是复对所"居住"的不变平面。

## Anti-patterns
- **对复根只报 λ 不算动作参数**：应报 r=|λ| 与角 θ；数值上 r 决定发散/收敛。
- **忘了共轭成对**：实矩阵特征多项式是实系数多项式，复根必成对；单独出现说明算错。
- **把 [T]_𝓑 的列写成 T(b_j) 标准坐标**：必须写成 B-坐标；先求 [T(b_j)]_𝓑 再排列。
- **实化时用错 P_j**：P_j = [Re v  Im v] 的顺序决定块的符号约定，验证 A P_j = P_j C(a,b)。

## Worked Example
A = $\left[\begin{smallmatrix}0&-1\\1&0\end{smallmatrix}\right]$（90° 逆时针旋转）。
特征方程 λ² + 1 = 0 → λ = ±i。
λ = i：A − iI = $\left[\begin{smallmatrix}-i&-1\\1&-i\end{smallmatrix}\right]$，v = (i, 1)ᵀ（检验：A v = (−1, i)ᵀ = i·(i,1)ᵀ ✓）。
实化：Re v = (0,1)ᵀ，Im v = (1,0)ᵀ，P_j = $\left[\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\right]$，块 C(0,1) = $\left[\begin{smallmatrix}0&-1\\1&0\end{smallmatrix}\right]$ = A 本身。
解读：r = 1、θ = π/2——纯旋转，与几何一致；|λ|=1 说明不发散不收敛（临界情形）。

## Reference Tables

| 特征值 | 几何动作（2D） |
|---|---|
| λ>1 / 0<λ<1 | 拉伸 / 压缩 |
| λ=−1 | 反射 |
| λ=0 | 投影（压扁到子空间） |
| a±bi, r>1 / <1 / =1 | 螺旋发散 / 收缩 / 旋转 |

## Key Takeaways
1. [T]_𝓑 的列是 T(b_j) 的 **B-坐标**——特征基下自动成对角，这是 D 的来源。
2. 复特征值成共轭对，每个对对应一个不变平面上的旋转-缩放（r, θ）。
3. 实分块对角化让"复数问题"落地为 2×2 实块，动力系统仿真不用复数。
4. 特征值的模与辐角完全编码二维动作：先看 r 定性，再看 θ 定形状。
