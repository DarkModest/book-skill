# Chapter 10: 坐标系、维数、基变换（教材 4.4–4.6）

> 基选定后，抽象向量获得数字地址（坐标）；换基就是换"测量单位"。基变换矩阵 P_B 把新旧地址互译，本章为特征对角化（ch12）与 SVD（ch19）储备语言。

## Core Idea
**坐标 = 在给定基下的展开系数**；同一向量在不同基下地址不同，翻译器是基变换矩阵。维数定理保证任意两基"等长"——维数是空间的内在属性，与基的选取无关。

## 框架与定理

### 坐标系（4.4）
设 B = {b₁,…,bₙ} 是 V 的基。任意 x∈V **唯一**分解（**定理 8，唯一表示定理**）：
$$\boldsymbol{x} = c_1\boldsymbol{b}_1 + \cdots + c_n\boldsymbol{b}_n$$
**坐标向量** $[\boldsymbol{x}]_{\mathcal{B}} = (c_1,\ldots,c_n)$。
- **定理 9**：坐标映射 x ↦ [x]_B 是线性**同构** V → ℝⁿ（同构思想的正式化）
- 标准基 E 下 [x]_E = x 本身
- **实际求坐标**：解 [b₁ … bₙ | x] 行化简（= 解方程）

### 维数（4.5）
- **定理 10**：n 个向量的基 ⟹ 线性无关集至多 n 个向量、生成集至少 n 个
- **定理 11（维数定理）**：V 的任意两基所含向量个数相同 → dim V 良定义
- **定理 12**：线性无关集可扩充为基（子空间同理）
- **基定理重述**：dim V 个线性无关向量（或 dim V 个生成向量）必是基
- **秩定理（定理 14）**：rank A + dim Nul A = n；dim Col A = rank A = 主元个数，dim Nul A = 自由变量数
- ℝⁿ 子空间维数 ≤ n；{0} 维数为 0

### 基变换（4.6）
**定理 15**：设 P_B = [b₁ … bₙ]（新基向量按列排开），则
$$[\boldsymbol{x}]_{\mathcal{B}} = P_{\mathcal{B}}^{-1}\boldsymbol{x}, \qquad \boldsymbol{x} = P_{\mathcal{B}}[\boldsymbol{x}]_{\mathcal{B}}$$
- 双向翻译：标准地址 → 新地址要乘 **P_B⁻¹**（先解方程 [b₁…bₙ | x]）
- **两非标准基之间的变换**：$[\boldsymbol{x}]_{\mathcal{C}} = P_{\mathcal{C}}^{-1}P_{\mathcal{B}}[\boldsymbol{x}]_{\mathcal{B}}$（P_C⁻¹P_B 称坐标变换矩阵）
- **线性映射的基变换（矩阵表示的换基）**：若 T 的 B-矩阵为 M（列 = [T(b_j)]_B），且 C 也给定，则
$$[T]_{\mathcal{C}} = P^{-1} M P$$
相似矩阵的定义（P⁻¹AP）在此诞生——特征对角化 A = PDP⁻¹ 就是"挑个好基让变换变成纯拉伸"。

## Mental Models
- **基 = 度量衡，坐标 = 数值读数**：换基=换单位制，向量本身（几何对象）不变。
- **P_B 列放基向量**：谁换基谁写列；方向想不清就写 x = P_B [x]_B 验算。
- **相似 = 同一变换的两套语言**：P⁻¹AP 的 A 与 M 是同一个动作在不同基下的记录。

## Anti-patterns
- **P_B 与 P_B⁻¹ 方向搞反**：记忆锚点——标准坐标 x = P_B[x]_B"重建向量"，所以标准→新坐标要再乘一次逆。
- **认为坐标依赖向量本身而不依赖基**：[x]_B 的下标不是装饰，同一向量不同基坐标不同。
- **把任意可逆矩阵当基变换**：P_B 必须以某组基的向量为列；任意可逆阵都可（其列自动是基），但语义要清。
- **维数记成向量个数**：dim H = 基大小，不是生成集大小（生成集可能冗余）。

## Worked Example
B = {b₁, b₂} = $\left\{\left[\begin{smallmatrix}1\\-2\end{smallmatrix}\right],\left[\begin{smallmatrix}-3\\4\end{smallmatrix}\right]\right\}$，求 x=(2,0) 的 B 坐标。

解 [b₁ b₂ | x] = $\left[\begin{smallmatrix}1&-3&|&2\\-2&4&|&0\end{smallmatrix}\right]$ → r1+r2 → $\left[\begin{smallmatrix}1&-3&|&2\\0&-2&|&4\end{smallmatrix}\right]$ → c₂=−2, c₁=−4。
[x]_B = (−4, −2)。验算：−4b₁ − 2b₂ = (−4+6, 8−8) = (2,0) ✓
P_B = [b₁ b₂]，det P_B = 4−6 = −2 ≠ 0 → 确实是基。

## Key Takeaways
1. 坐标唯一性是基的"去冗余"性质；求坐标就是解线性方程组。
2. 维数定理：维数是空间的内在指纹；无关集与生成集的个数界限由它给出。
3. 换基公式围绕 x = P_B[x]_B 一个等式展开，其余全靠逆推。
4. 相似矩阵 P⁻¹AP 在此定义——第 5 章对角化、第 7 章正交对角化的语言底座。
