# Chapter 14: 离散动力系统、微分方程、迭代估计与马尔可夫链（教材 5.6–5.9）

> 第 5 章应用收尾：x_{k+1}=Axₖ 的一切长程行为都由特征值谱决定。5.6 离散动力系统（斑点猫头鹰主场）、5.7 连续动力系统（微分方程）、5.8 数值求特征值（幂法）、5.9 马尔可夫链（第 6 版从第 10 章位置移来，紧跟特征向量之后讲稳态）。

## Core Idea
**动力系统的宿命写在特征值里**：xₖ = PDᵏP⁻¹x₀，|λ|>1 的方向发散、<1 消失、=1 幸存。所有节都在同一句话上变奏——猫头鹰存亡、电路暂态、幂法收敛、随机过程稳态，全是"谱 + 幂"。

## 框架与定理

### 离散动力系统（5.6）
x_{k+1} = A xₖ，x₀ 给定。特征分解后每条轨迹 = 各特征方向的 λᵏ 加权。
- **吸引子（attractor）**：所有特征值 |λ|<1 → 一切轨迹 → 0（原点吸引）
- **排斥子（repeller）**：所有 |λ|>1 → 轨迹远离原点
- **鞍点（saddle）**：既有 >1 又有 <1 → 沿稳定方向进、不稳定方向出
- **捕食-被捕食（predator-prey）模型**：x_{k+1}=Axₖ 出现复特征值 → 振荡（猫头鹰-田鼠、蜘蛛-甲虫例子）；|λ| 与 1 比较定爆发/灭绝
- 斑点猫头鹰阶段矩阵：$\left[\begin{smallmatrix}0&0&0.33\\0.18&0&0\\0&0.71&0.94\end{smallmatrix}\right]$，λ≈0.98 略小于 1 → 缓慢衰退；移去猫头鹰生命的"关键期"（幼鸟定居失败）敏感性最高

### 微分方程应用（5.7）
x'(t) = A x(t)（一阶线性 ODE 组），初值 x₀。
- **解**：x(t) = c₁e^{λ₁t}v₁ + … + cₙe^{λₙt}vₙ（特征基解耦）
- **特征向量解耦法**：换基 y=P⁻¹x → y' = Dy（独立方程）；标准温度/混合/电路模型
- 衰减-耗散分类同 5.6：λ 全负→衰减；复 λ→振荡；有正 λ→发散
- 教材例：两个串联水箱溶质浓度、RC 电路

### 特征值的迭代估计（5.8）
- **幂法（power method）**：取 x₀（λ₁ 方向分量非零），迭代 x_{k+1}=Axₖ，归一化；收敛到占优特征向量（|λ₁| 最大且严格大于其余）；λ₁ 估计 = 相邻迭代分量的比值（Rayleigh 商 Ax·x/x·x 更稳）
- 用途：PageRank 类排序、结构振动主模态、猫头鹰 λ 估计
- **逆幂法（inverse power method）**：对接近某 α 的特征值，用 (A−αI)⁻¹ 反复作用（LU 摊销，见 ch06），收敛到离 α 最近的特征值——配合幂法精化任意单个特征值；位移 α 取 Rayleigh 商二次收敛

### 马尔可夫链（5.9）
- **概率向量**：非负且分量和为 1；**随机矩阵 P**：列都是概率向量
- **马尔可夫链**：x_{k+1} = P xₖ（一阶差分）；xₖ = 状态向量（如城市/郊区人口比例，迁移矩阵 M=[0.95 0.03; 0.05 0.97]）
- **稳态向量 q**：Pq = q（特征值 1 的概率特征向量）；**定理 10（随机矩阵）**：1 必是随机矩阵的特征值（列和为 1 ⟹ Pᵀ 的全 1 向量是特征向量），且 1 是最大特征值
- **定理 11（正则随机矩阵）**：P 各项严格正（regular）→ 存在唯一稳态 q，且对任何初值 x₀，xₖ → q（不论起点）
- 求稳态：解 (P−I)q=0 加归一化 Σqᵢ=1（自由变量配平）

## Mental Models
- **轨迹 = 特征方向按 λᵏ 投票**：k→∞ 时只剩 |λ| 最大者（幂法）或所有 <1 者归零（吸引子）。
- **稳态 = 特征值 1 的概率化**：马尔可夫链把"幂法收敛"讲成"历史遗忘"。
- **逆幂法 = 把想要的特征值拉到 0 附近**：位移让它成为 (A−αI) 的最小模特征值。

## Anti-patterns
- **幂法不归一化**：数值溢出/下溢；每步除以最大分量或范数。
- **α 恰好取到特征值**：(A−αI) 奇异无法求解；取近似位移。
- **忘记稳态要归一化**：解 (P−I)q=0 得的是方向，必须按"和为 1"缩放。
- **对非常规随机矩阵断言收敛**：有 0 元或周期链可能不收敛到唯一稳态（regular 条件不可省）。

## Worked Example
迁移矩阵 M = $\left[\begin{smallmatrix}0.95&0.03\\0.05&0.97\end{smallmatrix}\right]$（列：从城市/郊区出发），求稳态。

解 (M−I)q=0：$\left[\begin{smallmatrix}-0.05&0.03\\0.05&-0.03\end{smallmatrix}\right]$q=0 → 5q₁ = 3q₂。归一化 q₁+q₂=1 → **q = (0.375, 0.625)**。
特征值：λ=1 与 λ=0.92；|0.92|<1 且矩阵正规 → 无论 2020 年人口分布如何，长跑必收敛到 37.5%/62.5%。Mᵏx₀ 快速逼近 q（每步误差乘 0.92）。

## Reference Tables

| 谱型 | 长程行为 |
|---|---|
| 全部 \|λ\|<1 | 吸引子 → 0 |
| 全部 \|λ\|>1 | 排斥子 → ∞ |
| 混合 | 鞍点 |
| 最大 \|λ\| 复数 | 振荡（可能爆发） |
| 随机阵 \|λ\|≤1, λ=1 存在 | 收敛稳态 q |

## Key Takeaways
1. 五节一个定理：长程行为 = 特征值谱 + 幂。会读谱就会读未来。
2. 幂法/逆幂法是特征值的"实验仪器"：只算最大/最近的一个，代价远小于全分解。
3. 马尔可夫稳态 = 特征值 1 + 概率归一化；regular 条件保证"历史遗忘"。
4. 猫头鹰案例的方法论：建阶段矩阵 → 算 λ → 敏感性分析 → 政策建议。
