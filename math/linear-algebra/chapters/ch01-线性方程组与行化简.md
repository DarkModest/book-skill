# Chapter 1 (上): 线性方程组与行化简（教材 1.1–1.2）

> 对应教材第1章《线性代数中的线性方程组》前两节。章首介绍性实例：列昂惕夫（Leontief）1949 年把美国经济分解为 500 个部门、写出 500 个方程（受 Mark II 计算机所限化为 42×42），运算 56 小时求解——由此开启经济数学建模与诺奖工作。

## Core Idea
线性方程组的全部理论从一件事出发：**用行变换把增广矩阵化为阶梯形，解的结构就完全暴露了**。主元（pivot）位置是后续一切判定的核心不变量。

## 框架与定理

### 线性方程（1.1）
形如 $a_1x_1 + a_2x_2 + \cdots + a_nx_n = b$，系数与 b 为实数或复数。判别法：变量只以一次幂出现、不与其它变量相乘。解、解集、等价（equivalent，同解集）是三个基本术语。

### 解的三种可能（1.1 几何结论）
- **无解**：不存在解（不相容 inconsistent）
- **唯一解**：恰有一个
- **无穷多解**：至少一个自由变量
两方程两变量时对应两直线：平行（无解）、相交（唯一）、重合（无穷多）。

### 矩阵记号与增广矩阵（1.1 末）
系数矩阵 $A$、未知向量 $\boldsymbol{x}$、常数向量 $\boldsymbol{b}$；增广矩阵 = [A | b]。矩阵规模记为 $m \times n$（m 行 n 列）。

### 行化简算法（1.2）
**三种初等行变换**：(1) 替换（倍加）(2) 交换两行 (3) 倍乘（非零倍数）。

**两类阶梯形**：
- **阶梯形（echelon form）**：非零行在零行之上；主元下方（同列）全为零；主元随行递增右移。
- **简化阶梯形（reduced echelon form, RREF）**：再要求主元为 1 且是其列的唯一非零元。

**行化简算法两阶段**：
1. **向前阶段（forward phase）**：从最左列选主元→行交换→倍加消去下方→对剩余子矩阵重复
2. **向后阶段（backward phase）**：从最右主元开始，倍加消去主元上方，再把主元归一化为 1

**存在性与唯一性定理（1.2 定理2）**：增广矩阵行化简为阶梯形后，
- 若有行形如 [0 … 0 | b]（b≠0）→ **不相容**
- 否则相容；若无自由变量 → 唯一解；若有自由变量 → 无穷多解

**主元列（pivot column）**：含主元位置的列。主元位置是矩阵中某个 1（阶梯形化后）的位置；主元列对应**基本变量**，非主元列对应**自由变量**。

## Anti-patterns（常见错误）
- **把 RREF 化简提前停止**：向后阶段不做完，回代时代价更大；RREF 直接读解。
- **在行变换中把两列交换**：列交换会改变变量顺序对应关系（除非同时换变量名），行变换才是合法操作。
- **数值计算用 RREF 强行除尽**：实际数值计算用部分主元法（选最大元素作主元）控制舍入误差，见 1.10 及数值线性代数讨论。
- **认为"解集写法唯一"**：通解中自由变量的参数化方式不唯一，解集本身才唯一（RREF 唯一性 = 1.2 定理1，证明在附录A）。

## Worked Example
解 $\begin{cases} x_1 - 2x_2 = -1 \\ -x_1 + 3x_2 = 3 \end{cases}$

增广矩阵 $\left[\begin{smallmatrix}1&-2&|&-1\\-1&3&|&3\end{smallmatrix}\right]$ → r1+r2 替换 → $\left[\begin{smallmatrix}1&-2&|&-1\\0&1&|&2\end{smallmatrix}\right]$ → 倍加回代 → $\left[\begin{smallmatrix}1&0&|&3\\0&1&|&2\end{smallmatrix}\right]$。
无自由变量 → 唯一解 $(x_1,x_2)=(3,2)$。

带自由变量的通解（形状）：设 RREF 为 $\left[\begin{smallmatrix}1&5&-2&|&-3\\0&0&1&|&4\end{smallmatrix}\right]$，则 $x_2$ 自由：$x_1=-3-5x_2+2x_3$，写成向量参数式 $\boldsymbol{x} = \left[\begin{smallmatrix}-3\\0\\4\end{smallmatrix}\right] + x_2\left[\begin{smallmatrix}-5\\1\\0\end{smallmatrix}\right] + x_3\left[\begin{smallmatrix}2\\0\\1\end{smallmatrix}\right]$（这种"点+方向"写法在 1.5 节正式化为齐次解+特解）。

## Key Takeaways
1. 行化简是全书所有计算的引擎：解方程组、求逆、求秩、求特征向量都要用。
2. 判断相容性只看 RREF 中有没有 [0…0|b] 行——先看解是否存在，再谈个数。
3. 主元列/自由变量的区分把"唯一解 vs 无穷解"变成机械判定。
4. 向前阶段只产生阶梯形；向后阶段才产生 RREF——多数问题（如判相容性）到阶梯形即可停。
