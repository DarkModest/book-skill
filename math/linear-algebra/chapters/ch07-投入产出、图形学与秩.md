# Chapter 7: 应用与 ℝⁿ 子空间、维数与秩（教材 2.6–2.9）

> 2.6/2.7 是两大经典应用（列昂惕夫经济模型、计算机图形学），2.8/2.9 完成从"解方程"到"空间结构"的关键一跃：子空间、维数、秩——理论枢纽。

## Core Idea
**ℝⁿ 的子空间 = 过原点且封闭于加法/数乘的集合**；矩阵的三个子空间（Nul A、Col A、Row A）把解方程的各部分各归其位。**秩定理 rank A + dim Nul A = n** 是"信息守恒律"：输入维数 = 被压扁的维数 + 幸存的维数。

## 框架与定理

### 列昂惕夫投入-产出模型（2.6）
经济分 n 个部门，**消耗矩阵 C**（列 j：部门 j 单位产出的消耗）。
- **产出方程**：$\boldsymbol{x} = C\boldsymbol{x} + \boldsymbol{d}$，d = 最终需求向量（消费、出口等）
- 解：$(I-C)\boldsymbol{x}=\boldsymbol{d}$，即 $\boldsymbol{x} = (I-C)^{-1}\boldsymbol{d}$
- **列昂惕夫逆** $(I-C)^{-1}$ 的 (i,j) 元 = 部门 j 每单位最终需求需要部门 i 的总产出；**定理 11**：若 C、d 非负且 C 每列的和小于 1，则 (I−C)⁻¹ 存在且产出向量 x=(I−C)⁻¹d 非负（经济可行）
- 实例：美国经济 1947/1958/1963 年 81 部门表；**交换模型**（习题）：各经济体的等价交换，封闭模型求"均衡价格"（正特征向量的方向，ch12 回看）

### 计算机图形学（2.7）
ℝ³ 中物体的**线形轮廓（wireframe）模型**：顶点集 + 边集。变换作用于齐次坐标下的顶点矩阵：
- 平移：用 4×4 齐次坐标矩阵 $\left[\begin{smallmatrix}1&0&0&p\\0&1&0&q\\0&0&1&r\\0&0&0&1\end{smallmatrix}\right]$
- 旋转（绕 x/y/z 轴的 3×3 标准矩阵）、缩放、以及**复合**（矩阵连乘，顺序敏感）
- 透视投影用"分而治之"：非奇异变换化简后再归一化（4×4 阵尾行影响）

### ℝⁿ 的子空间（2.8）
**子空间**定义：非空、对加法封闭、对标量乘封闭（必然含 0）。
- 过原点直线/平面都是子空间；不过原点的不是
- **Col A**：Ax 的全部取值（=列的生成集）——"b 落在哪里才有解"
- **Nul A**：Ax=0 的解集——"哪些方向被压成 0"；验证子空间的标准三步（0 在其中、u+v 在、cu 在）

### 基、维数与秩（2.8–2.9）
- **基（basis）**：线性无关的生成集。基 = 空间的"最小完备描述"
- Nul A 的基：解集参数式中自由变量对应的生成向量（个数 = 自由变量数）
- Col A 的基：**A 的主元列**（注意：是原 A 的列，不是 RREF 的列！）
- **维数 dim** = 基的向量个数；**秩 rank A** = dim Col A = 主元个数
- **秩定理**：$\operatorname{rank}A + \dim\operatorname{Nul}A = n$（n = 列数 = 变量个数）
- 可逆时：rank A = n，Nul A = {0}（IMT 的空间版重述）

## Mental Models
- **秩定理 = 信息守恒**：输入 n 维，rank 维"有输出"，自由变量维"丢失/被压扁"。
- **Col A 与 Nul A 互为正反**：Col A 管"哪些 b 能被命中"，Nul A 管"哪些差异不可见"；4.2 会看到 Row A⊥ Nul A。
- **列昂惕夫逆是"乘数效应表"**：一个部门的订单经供应链放大成全经济的总产出。

## Anti-patterns
- **用 RREF 的列当 Col A 的基**：列空间在行变换下会改变！必须取原矩阵的主元列。
- **给 Col A 报错维数**：rank A = 主元数 ≤ min(m,n)；dim Nul A = 自由变量数；两者之和才等于 n。
- **把不过原点的集合当子空间**：非齐次解集、仿射集都不是（ch20 区分 affine）。
- **图形学复合变换顺序写反**：先缩放后旋转 vs 先旋转后缩放结果不同；矩阵从右往左作用。

## Worked Example
$A=\left[\begin{smallmatrix}2&4&-2&2\\-2&-4&3&1\\-4&-8&1&-3\end{smallmatrix}\right]$：RREF 主元在列 1、3。
- rank A = 2；dim Nul A = 4−2 = 2（秩定理验算 2+2=4 ✓）
- Col A 的基：$\left[\begin{smallmatrix}2\\-2\\-4\end{smallmatrix}\right],\left[\begin{smallmatrix}-2\\3\\1\end{smallmatrix}\right]$（原矩阵列 1、3）
- Nul A 的基：解 Ax=0 得 x₂,x₄ 自由 → $\boldsymbol{x}=x_2\left[\begin{smallmatrix}-2\\1\\0\\0\end{smallmatrix}\right]+x_4\left[\begin{smallmatrix}0\\0\\-1/2\\1\end{smallmatrix}\right]$

列昂惕夫快算：C=0.5（各部门互耗一半），d=(10,20) → x=(I−C)⁻¹d = 2d = (20,40)：乘数效应翻倍。

## Key Takeaways
1. 子空间三查：含 0、加法封闭、数乘封闭；Nul/Col/Row 都是子空间。
2. Col A 的基取原矩阵主元列——行变换改变列空间是高频错误。
3. 秩定理把 4 个数（秩、零度、主元数、自由变量数）串成一条等式。
4. 列昂惕夫与图形学是"矩阵=线性系统/动作"两大应用范式，后续章节反复回收。
