# Chapter 2 (上): 向量方程与矩阵方程（教材 1.3–1.4）

> 这是 Lay 教材最具特色的段落：用**列的组合**观点统一"解方程组"——Ax 的现代观点。矩阵向量乘积 Ax 定义为 A 的列以 x 的分量为权的线性组合。

## Core Idea
三种语言说同一件事：**线性方程组 ⟺ 向量方程（线性组合）⟺ 矩阵方程 Ax=b**。掌握这三者的等价转换，"向量是否在生成集中""b 是否在 Span{v₁,…,vₚ} 中"等几何问题都化为行化简。

## 框架与定理

### 向量基本运算（1.3）
ℝⁿ 中向量：加法（对应分量相加）、标量乘法。八条运算律（交换、结合、分配、零向量、负向量等）。**线性组合**：$\boldsymbol{y} = c_1\boldsymbol{v}_1 + \cdots + c_p\boldsymbol{v}_p$；权（weights）为标量。

**Span{v₁,…,vₚ}**：这些向量的全部线性组合的集合（生成子空间）。
- b ∈ Span{v₁,…,vₚ} ⟺ 增广矩阵 [v₁ … vₚ | b] 相容
- Span{v₁} 是过原点的直线；Span{u,v}（不共线）是过原点的平面；Span 含 0 当且仅当权全为 0

### 矩阵方程 Ax（1.4）
**列观点定义**：$A\boldsymbol{x} = x_1\boldsymbol{a}_1 + \cdots + x_n\boldsymbol{a}_n$（A 的列的线性组合）。
- Ax 有定义 ⟺ A 的列数 = x 的维数
- 等价性（定理 3）：Ax=b 的解集 = 向量方程 x₁a₁+…+xₙaₙ=b 的解集 = 增广矩阵 [A | b] 的解集——线性方程组从此有三种等价观点

**行观点计算**：Ax 的第 i 个分量 = A 的第 i 行与 x 的点积。两种观点：列观点用于**理论与证明**（Lay 全书主线），行观点用于**数值计算**。

### 相容性与生成（定理 4）
"本章最有用的定理之一"——对 m×n 矩阵 A，以下命题等价：
(a) 对每个 b∈ℝᵐ，Ax=b 都相容
(b) A 的每一行都有主元位置
(c) A 的列生成 ℝᵐ
(d) 对每个 b，Ax=b 恰有一解
（警告：定理针对**系数矩阵** A，不是增广矩阵——[A|b] 每行有主元推不出相容）

### 解的唯一性
Ax=b 对每个 b 恰有唯一解 ⟺ A 的列**线性无关**（定理 4(d) 与 1.7 正式定义相连）。

## Mental Models
- **把 Ax 看成"A 的列的配方"**：x 是配方表（各取多少），Ax 是配方结果。
- **解 Ax=b = 问"A 的列能否调配出 b"**：能（相容）→ b 在列空间中。
- **矩阵乘向量是变换的雏形**：x ↦ Ax 把 ℝⁿ 映到 ℝᵐ（1.8 节正式化）。

## Anti-patterns
- **只在行观点里打转**：只算分量积会丢失"解=b 的组合系数"这一核心理解；习题中"求表示 b 的组合系数"就是解方程。
- **混淆"有解"与"对一切 b 有解"**：某个 b 相容只需该增广矩阵行化简相容；"对一切 b 相容"才要求每行有主元。
- **把 Ax 当 A 乘以标量**：维数不匹配时 Ax 无定义；列数必须等于 x 的分量数。

## Worked Example
问 $\boldsymbol{b}=\left[\begin{smallmatrix}8\\-4\end{smallmatrix}\right]$ 能否写成 $\boldsymbol{a}_1=\left[\begin{smallmatrix}3\\9\end{smallmatrix}\right], \boldsymbol{a}_2=\left[\begin{smallmatrix}0\\28\end{smallmatrix}\right], \boldsymbol{a}_3=\left[\begin{smallmatrix}-3\\-65\end{smallmatrix}\right]$ 的线性组合？

解 $x_1\boldsymbol{a}_1+x_2\boldsymbol{a}_2+x_3\boldsymbol{a}_3=\boldsymbol{b}$，行化简 $\left[\begin{smallmatrix}3&0&-3&|&8\\9&28&-65&|&-4\end{smallmatrix}\right]$ → $\left[\begin{smallmatrix}1&0&-1&|&8/3\\0&28&-56&|&-28\end{smallmatrix}\right]$ → $x_2=1$、$x_3$ 自由、$x_1 = \tfrac{8}{3}+x_3$。
相容且无穷多解 → b 能表示，且表示方式无穷多（列线性相关时表示不唯一）。

## Key Takeaways
1. Ax 的列定义是全书"现代观点"的基石：定义与证明都基于列，而不是元素。
2. 三个等价形式（方程组/向量方程/矩阵方程）可以自由切换，哪个方便用哪个。
3. "每行有主元"一条同时控制相容性与生成性——这是行列数不对称的第一个信号。
4. 表示不唯一 ⟺ 列线性相关（1.7 节展开）。
