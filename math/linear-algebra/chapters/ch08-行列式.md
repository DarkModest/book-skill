# Chapter 8: 行列式（教材 3.1–3.3）

> 章首介绍性实例"称钻石"：用双盘天平设计称重方案，设计矩阵 D 满足 |DᵀD| 最大时精度最高——行列式第一次出场就是"信息量"的度量。

## Core Idea
**行列式是方阵的单一数值指纹**：判可逆、算体积、给克拉默法则、生成特征多项式。计算靠**余因子展开**化到低阶，性质靠**行变换效应**快速化简——两条路线都要会。

## 框架与定理

### 定义与 2×2/3×3（3.1）
- 2×2：$\det\left[\begin{smallmatrix}a&b\\c&d\end{smallmatrix}\right] = ad-bc$
- **余因子展开（cofactor expansion）**：沿任一行/列，$\det A = \sum (-1)^{i+j}a_{ij}\det A_{ij}$；选 0 最多的行/列最省算力
- n×n 递归定义即沿第一行展开；3×3 可用"沙氏法则"（Sarrus，仅 3×3）

### 行变换效应（3.2 定理3）
1. **倍加（替换）**：det 不变 ←—— 化简主力
2. **交换两行**：det 变号
3. **倍乘某行 k 倍**：det 变 k 倍（定理3(c) 也是"提公因子"的依据）
- 阶梯形 U 是上三角：det A = (−1)ˢ（U 的对角元之积），s 为交换次数
- **定理4**：**A 可逆 ⟺ det A ≠ 0**（可向 IMT 追加的等价条目）；三角阵 det = 对角元之积
- **定理5**：**转置不变** det Aᵀ = det A（行/列地位对称，定理3 的行效应自动变列效应）
- **定理6（乘法的性质）**：$\det(AB) = \det A \cdot \det B$；推论 $\det(A^{-1})=1/\det A$、$\det(kA)=k^n\det A$
- 注意 det(A+B) ≠ det A + det B（行列式对矩阵不是线性的）

### 克拉默法则、体积与线性变换（3.3）
- **克拉默法则**：A 可逆时 Ax=b 的第 i 个分量 $x_i = \dfrac{\det A_i(\boldsymbol{b})}{\det A}$，A_i(b) 是把 A 的第 i 列换成 b。只适用于方阵且计算量大——教学/符号价值大于数值价值
- **伴随矩阵（adjugate）**：$\operatorname{adj}A$ = 代数余子式矩阵的转置；$A^{-1} = \dfrac{1}{\det A}\operatorname{adj}A$（理论公式，数值不用）
- **2×2 行列式 = 平行四边形面积**；**3×3 = 平行六面体体积**；一般 |det A| = 线性变换下单位体的体积缩放因子
- 线性变换的面积/体积效应：T(x)=Ax 把 S 映成 T(S)，vol(T(S)) = |det A|·vol(S)（推导用可逆情形+行列式的行变换性质）

## Mental Models
- **det = 体积缩放率**：|det|>1 放大体积，<1 压缩，=0 压扁（不可逆、退化）。
- **倍加不动 det**：就像"给一行加上别的行"只是换基不换体积。
- **克拉默法则 = 换列试探**：把 b 换进第 i 列，看"占比"。

## Anti-patterns
- **把 det(AB) 写成 det A + det B 或 det A·det B 之外的任何形式**：只有乘积式成立；det(A+B) ≠ det A + det B。
- **数乘矩阵与数乘 det 混淆**：det(kA) = kⁿ det A（n 阶），不是 k 倍。
- **数值上用克拉默法则解方程**：误差与开销都劣于消元法；教科书如此安排只为展示结构。
- **沿 0 少的行硬展开**：先用倍加造出尽量多的 0 再展开。

## Worked Example
$A=\left[\begin{smallmatrix}1&5&-6\\-1&0&3\\4&5&2\end{smallmatrix}\right]$：沿第 2 行展开（有 0）：
det A = −(−1)·det[5 −6; 5 2] + 0 − 3·det[1 5; 4 5] = 1·(10+30) − 3·(5−20) = 40+45 = 85 ≠ 0 → A 可逆。
体积解读：A 把单位立方体体积放大 85 倍。

## Key Takeaways
1. 计算策略：小阵直接展开，大阵先倍加成三角再乘对角（注意符号）。
2. det≠0 是可逆性的行列式判据（3.2 定理4），也是特征方程 det(A−λI)=0 的基础。
3. |det A| 是线性变换的体积缩放因子——几何意义优先记忆。
4. 克拉默/伴随是"存在性与结构"工具，不是数值工具。
