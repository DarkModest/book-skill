# Chapter 18: 对称矩阵、二次型与条件优化（教材 7.1–7.3）

> 章首介绍性实例：多波段图像处理（Landsat 卫星 7 波段图像，主成分分析把 3 波段信息压到一张图解释 93.5% 差异——7.5 展开）。本章核心是**谱定理**：对称矩阵永远可以正交对角化。

## Core Idea
**对称矩阵是"最像实数"的矩阵**：特征值全实、特征向量可取正交、A=QΛQᵀ。二次型 Q(x)=xᵀAx 的定号性由特征值符号读出——于是**条件优化 max/min xᵀAx（带约束 ‖x‖=1）= 看最大/最小特征值**。

## 框架与定理

### 对称矩阵的对角化（7.1）
**谱定理（定理 3）**：对称 A 有 (a) n 个实特征值（计重数）(b) 每个特征空间的维数 = 该特征值的重数 (c) 不同特征值的特征空间相互正交 (d) A 可正交对角化：
$$A = QDQ^T$$
（Q 正交，D 实对角；反之可正交对角化 ⟹ 对称。）
- 对称 ⟹ (i) 特征值全实 (ii) 特征空间有正交基 (iii) 可正交对角化
- 反向：可正交对角化（实 D）⟹ 对称
- **谱分解**：A = λ₁q₁q₁ᵀ + … + λₙqₙqₙᵀ（秩 1 项加权和）；A 的谱 = 特征值集合
- 谱定理的威力：正交变换 = 旋转/反射系（无剪切），对称变换 = "沿主轴的缩放"

### 二次型（7.2）
**二次型**：Q(x) = xᵀAx = Σaᵢᵢxᵢ² + 2Σ_{i<j}aᵢⱼxᵢxⱼ（A 对称，交叉项分一半到 (i,j) 与 (j,i)）。
- **主轴定理（principal axes theorem）**：换正交坐标 x=Qy → Q(x) = λ₁y₁² + … + λₙyₙ²（无交叉项；主轴 = 特征向量方向）
- **定号分类**（按特征值符号）：全正→正定；全负→负定；含 0 但同号→半正定/半负定；异号→不定
- 应用：圆锥曲线/二次曲面分类（椭圆、双曲、抛物线由定号性+退化程度决定）

### 条件优化（7.3）
在单位球 ‖x‖=1 上优化 Q(x)=xᵀAx（A 对称）：
- **max Q = λ₁（最大特征值），在 q₁ 取得；min Q = 最小特征值，在对应特征向量取得**
- 换元 x=Qy：Q=Σλᵢyᵢ²，约束 Σyᵢ²=1 → 平凡地被最大 λ 主导
- 次大值：在与 q₁ 正交的子空间内继续 max → 第二大特征值（递归/瑞利商验证）
- **约束优化一般形式**：max xᵀAx s.t. xᵀx=1 与拉格朗日乘子法连通（μ 乘子 ⟺ 特征值）

## Mental Models
- **谱定理 = 对称阵的"体检保证"**：永远有实特征值 + 正交特征基，无复数、无缺陷。
- **二次型 = 能量面**：主轴方向=能量等值面的对称轴；特征值=沿主轴的曲率。
- **约束优化 = 球面上找最高点**：最高点必在"最陡主轴"上。

## Anti-patterns
- **非对称矩阵也指望正交对角化**：一般只有相似对角化（P 未必正交）；非对称"近似对称"时谱分解只算近似。
- **交叉项系数抄错**：xᵀAx 中 2a₁₂x₁x₂ 的 2 来自对称化——从二次型写 A 时对角项原样、非对角项除 2。
- **定号性只看主对角**：必须看全部特征值（或顺序主子式 Sylvester 判据：正定 ⟺ 各阶顺序主子式 >0）。
- **条件优化忘了归一化约束**：无 ‖x‖=1 约束时 max xᵀAx = ∞（正定时）；约束是问题的一部分。

## Worked Example
Q(x) = 5x₁² − 4x₁x₂ + 5x₂²。A = $\left[\begin{smallmatrix}5&-2\\-2&5\end{smallmatrix}\right]$。
特征值：λ = 3, 7；特征向量 q₁=(1,1)ᵀ/√2（λ=3），q₂=(1,−1)ᵀ/√2（λ=7）。
主轴形式：Q = 3y₁² + 7y₂² → **正定**；曲线 5x₁²−4x₁x₂+5x₂²=44 是长轴沿 q₁ 的椭圆（半轴 √(44/7), √(44/3)）。
条件优化：‖x‖=1 上 max Q = 7（在 q₂），min Q = 3（在 q₁）。

## Key Takeaways
1. 谱定理三连：实特征值、正交特征基、A=QΛQᵀ——对称阵的"完整体检单"。
2. 主轴定理把二次型的交叉项全部消掉：几何分类看特征值符号。
3. 球面约束优化 = 最大/最小特征值问题；第二极值在正交补里找。
4. 瑞利商 xᵀAx/xᵀx 是特征值的"滑动估计器"（联系 5.8 幂法）。
