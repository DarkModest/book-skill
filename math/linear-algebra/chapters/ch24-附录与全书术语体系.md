# Chapter 24: 附录 A/B 与全书术语体系

> 附录 A：简化阶梯形唯一性的证明（1.2 的"RREF 唯一"承诺在此兑现）；附录 B：复数运算速成（第 5、7 章复特征值的算术基础）。书末 559–573 页附双语术语表（English term [中文] — 定义），本技能 glossary.md 的权威参照。

## Core Idea
两个附录补两块地基：**RREF 唯一性**让"解集"作为对象有意义（不依赖消元路径），**复数运算**让复特征值/复对角化可操作。术语表则把全书 500+ 术语的英中对照固定下来——读英文文献的接口。

## 框架与定理

### 附录 A：简化阶梯形矩阵的唯一性
命题（1.2 的定理1，证明推迟到附录A）：任何矩阵行等价于**唯一**的简化阶梯形矩阵。
- 证明思路（归纳法）：先证阶梯形主元位置唯一（主元位置 = 行空间的不变量），再从最后一个主元列向前归纳：主元列之外各列在 RREF 中的值由主元位置与行空间唯一决定
- 意义：解集、秩、主元列都是**良定义的矩阵不变量**——不同人做行化简得到同一个答案
- 良定义链条：RREF 唯一 → 主元列唯一 → 秩唯一 → dim Nul 唯一 → 解集结构唯一

### 附录 B：复数
- z = a+bi，**共轭** z̄ = a−bi，**模** |z| = √(a²+b²)；极形式 z = re^{iθ} = r(cosθ + i sinθ)
- 运算：乘法 = 模相乘、角相加；除法用共轭有理化；**共轭根定理**：实系数多项式复根成对（λ 与 λ̄ 同时是特征值）
- 复内积要点：Āᵀ（共轭转置）才是正交性的正确推广（Hermitian），‖z‖² = z·z̄
- 用途：5.5 复特征值/旋转、特征方程求根、（超出本书的）酉对角化

### 全书术语体系（书末双语术语表）
术语表的编排：**English term [中文译名] — 中文定义**，按字母序。高频核心术语样例：
- affine combination 仿射组合；adjugate 伴随矩阵；attractor 吸引子；augmented matrix 增广矩阵
- eigenvalue 特征值 / eigenspace 特征空间 / eigenvector 特征向量分解
- elementary matrix 初等矩阵；equilibrium prices 均衡价格；existence question 存在性问题
- factorization 分解；final demand vector 最终需求向量；Fourier coefficients 傅里叶系数
- extreme point 极值点；floating point arithmetic 浮点运算；forward/backward phase 向前/向后阶段
- barycentric coordinates 重心坐标；basic variable 基本变量；band matrix 带形矩阵

## Mental Models
- **唯一性 = 语言的合法性证明**：RREF 唯一之后，"矩阵的秩"这类短语才指同一事物。
- **复数 = 平面动作的代数**：乘 e^{iθ} 就是转 θ 角；复特征值 = 变换中隐藏的旋转。
- **双语术语表 = 文献接口**：中文教材 ↔ 英文文献的术语映射表，查文献先查这里。

## Anti-patterns
- **认为行化简路径不同会得到不同 RREF**：唯一性定理保证不会；得到不同结果必是算错。
- **复数除法忘共轭**：(a+bi)/(c+di) 要乘 (c−di)/(c²+d²)。
- **复向量内积用普通转置**：涉及复系数时应用共轭转置 Āᵀ，否则"长度"可能是虚数。
- **中英术语混译**：如"秩"↔rank、"零空间"↔null space / kernel（核）混用需注明；查书末术语表为准。

## Worked Example
复数除法：(3+4i)/(1−2i) = (3+4i)(1+2i)/((1−2i)(1+2i)) = (3+6i+4i+8i²)/(1+4) = (−5+10i)/5 = −1+2i。
极形式检验：分子模 5、角 53.1°；分母模 √5、角 −63.4° → 商模 √5、角 116.6° = −1+2i ✓。
与特征值联动：旋转-缩放矩阵 C(a,b) 的特征值 a±bi，其模 r 与辐角 θ 直接给出动作参数（ch13）。

## Key Takeaways
1. RREF 唯一性是全书记号系统的合法性证书：秩、主元列、维数皆不变量。
2. 复数三件套（共轭、模、极形式）是 5.5/7.x 复特征值的算术通行证。
3. 书末双语术语表是中英文文献切换的权威地图。
4. 不变量思维：路径可以不同，主元位置/秩/RREF 必相同。
