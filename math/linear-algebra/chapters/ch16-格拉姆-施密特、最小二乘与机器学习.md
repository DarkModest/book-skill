# Chapter 16: Gram-Schmidt、最小二乘与机器学习（教材 6.4–6.6）

> 6.4 造正交基并顺手产出 QR；6.5 用法源（最佳逼近定理）解决不相容方程组；6.6 是第 6 版新节：**机器学习和线性模型**——用统计记号 Xβ=y 讲回归，把最小二乘正式接入 ML 叙事。

## Core Idea
**Gram-Schmidt 把任意基变成正交基**（副产品 QR 分解）；**最小二乘 = 把 b 投影到 Col A**：正规方程 AᵀAx̂=Aᵀb 一行写尽。机器学习的"从数据学关系"= 拟合线性模型 = 解最小二乘。

## 框架与定理

### Gram-Schmidt 过程（6.4）
对无关集 x₁,…,xₚ 递归：vₖ = xₖ − Σ_{j<k} (xₖ·vⱼ/vⱼ·vⱼ)vⱼ（逐个减去在已有方向上的投影）。
- Span 保持不变；v₁,…,vₚ 正交；除以范数得标准正交
- **QR 分解**：A = QR，Q 标准正交列（= 正交化的 A），R 上三角（= 原坐标在正交基下的系数）
- QR 的用途：数值稳定的最小二乘（6.5 定理：x̂ = R⁻¹Qᵀb）、特征值算法（QR 算法背景）

### 最小二乘问题（6.5）
不相容 Ax=b（b ∉ Col A）时求"残差最小"解：
- **一般最小二乘解**（定理13）：x̂ 使 ‖b−Ax̂‖ 最小 ⟺ x̂ 是**正规方程**的解：
$$A^TA\hat{\boldsymbol{x}} = A^T\boldsymbol{b}$$
- 唯一性：A 列无关 ⟹ AᵀA 可逆（定理14，最小二乘版 IMT）⟹ x̂ = (AᵀA)⁻¹Aᵀb
- **最小残差 ‖b−Ax̂‖** 与 ŷ=Ax̂=proj_Col A b；b̂=b−Ax̂⊥Col A
- 多解情形：AᵀA 奇异时正规方程解集 = 一维平移集（自由变量方向）
- 数值算法排序：QR（稳定）> 正规方程（快但平方条件数）；**定理15**：x̂ = R⁻¹Qᵀb

### 机器学习和线性模型（6.6，第 6 版新节）
机器学习：给训练数据（自变量/因变量已知），拟合关系，用于预测。记号升级：
$$X\boldsymbol{\beta} = \boldsymbol{y},\quad X=\text{设计矩阵（design matrix）},\ \boldsymbol{\beta}=\text{参数向量},\ \boldsymbol{y}=\text{观测向量}$$
- **最小二乘直线（回归直线）**：y = β₀ + β₁x；设计矩阵 X = [1 x]（第一列全 1，第二列 x 值）；
$$\boldsymbol{\beta} = \left[\begin{smallmatrix}\beta_0\\\beta_1\end{smallmatrix}\right] = (X^TX)^{-1}X^T\boldsymbol{y}$$
- **残差**：观测 y_j 与预测 β₀+β₁x_j 之差；最小二乘直线 = 残差平方和最小（= ‖y−Xβ‖ 最小），又称 y 对 x 的**回归直线**，β₀,β₁ 为（线性）**回归系数**
- 假设：误差只在 y 方向；若 x 也有误差→改用正交距离（总最小二乘，习题）
- 推广：多项式拟合（X 列 = 1, x, x²,…）、多元线性回归（多列特征）——同一套 Xβ=y + 正规方程；机器学习"训练"= 解 β，"预测"= 新 x 代入
- 6.6 末/6.8 联动：加权最小二乘、正则化思想可在习题中窥见（ridge 类思想超出本书正文）

## Mental Models
- **最小二乘 = 找不到就投影**：b 不在 Col A 里，就打最近的目标（ŷ=Ax̂）。
- **正规方程是"正交条件"的代数化**：Aᵀ(b−Ax̂)=0 ⟺ 残差⊥列空间。
- **设计矩阵 X 是"数据升维的模具"**：直线、抛物线、多元模型只是往 X 里塞不同的列。

## Anti-patterns
- **数值上用 (AᵀA)⁻¹ 硬解**：条件数平方放大误差；生产环境用 QR/SVD。
- **Gram-Schmidt 漏掉减投影后的重正交化**：病态时经典算法误差累积；数值实现用修正版/两次正交化。
- **回归直线记成"误差只在 x"**：课本假设误差在 y；x 有误差时最小二乘斜率有偏。
- **把投影 ŷ 当解 x̂**：x̂ 是系数（输入侧），ŷ=Ax̂ 是拟合值（输出侧），报告时区分。

## Worked Example
数据点 (2,1), (5,2), (7,3), (8,3)，求最小二乘直线。

X = $\left[\begin{smallmatrix}1&2\\1&5\\1&7\\1&8\end{smallmatrix}\right]$, y = $\left[\begin{smallmatrix}1\\2\\3\\3\end{smallmatrix}\right]$。
XᵀX = $\left[\begin{smallmatrix}4&22\\22&142\end{smallmatrix}\right]$, Xᵀy = $\left[\begin{smallmatrix}9\\59\end{smallmatrix}\right]$。
解正规方程：det = 4·142−22² = 84；XᵀX 逆 = (1/84)$\left[\begin{smallmatrix}142&-22\\-22&4\end{smallmatrix}\right]$ → β = (1/84)(142·9−22·59, −22·9+4·59) = (44/84, 38/84) ≈ (0.524, 0.452)。
回归直线 ŷ ≈ 0.524 + 0.452x；预测 x=6 → ŷ≈3.24。

## Key Takeaways
1. Gram-Schmidt 三句：减投影、保生成、除长度；QR 是它的记账表。
2. 正规方程一行解最小二乘，但数值上首选 QR——条件数平方是坑。
3. 机器学习的线性回归 = Xβ=y + 正规方程；"训练"就是解 β。
4. 设计矩阵思维：换模型 = 换列，不用改算法。
