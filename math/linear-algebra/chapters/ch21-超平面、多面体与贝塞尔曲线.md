# Chapter 21: 超平面、多面体、曲线与曲面（教材 8.4–8.6）

> 第 8 章收尾：8.4 超平面（线性规划的约束几何）、8.5 多面体（顶点表示理论）、8.6 Bézier 曲线与曲面（计算机图形学/CAD 的数学骨架）。

## Core Idea
**超平面 = n 维空间中的"平面" f(x)=b**（法向量 n·x=b）；半空间切出的多面体的本质由**极小表示**刻画：哪些约束"真的在切"。Bézier 曲线用伯恩斯坦多项式的凸组合性质保证曲线"乖乖待在控制点凸包里"。

## 框架与定理

### 超平面（8.4）
**超平面** H = {x : n·x = b}（n≠0 法向量）；平行半空间 {x : n·x ≥ b}（正侧）与 {x : n·x ≤ b}（负侧）。
- H 是仿射集；过原点时（b=0）是 n−1 维子空间
- **两个超平面的平行性** ⟺ 法向量平行；法向量求法：由两点差得 H 内方向 → 法向量与之正交
- 应用：线性规划约束 aᵢ·x ≤ bᵢ 的边界；分类器（机器学习的感知机边界 n·x=b）

### 多面体（8.5）
- **多面形（polytope 相关概念）**：有限个半空间之交 = 多面体（有界时称多胞形）
- **顶点表示 vs 半空间表示**：顶点集的凸包 ⟺ 约束的交集（两种"账本"）
- **极小表示**：删去冗余约束后剩下"每个都真的切出面"的表示；**极小表示的顶点/集 characterization**：顶点 = 极值点；面 = 使某约束取等的点集
- 二维例子（五边形）：5 个约束中每个都对应一条边 → 极小；多一个约束则冗余
- 算法线索：极小表示的检验 = 看每个约束是否在某顶点处"紧"（bind）

### 曲线与曲面（8.6）
- **二次贝塞尔曲线**（8.3 习题引入，8.6 展开）：x(t) = (1−t)²p₀ + 2t(1−t)p₁ + t²p₂
- **三次贝塞尔曲线**：x(t) = (1−t)³p₀ + 3t(1−t)²p₁ + 3t²(1−t)p₂ + t³p₃，t∈[0,1]，由 3–4 个**控制点**确定（可为 ℝ²/ℝ³ 点或齐次形式）
  - 性质：通常只过起始与最终控制点；**曲线总位于控制点的凸包内**；混合多项式 (1−t)³, 3t(1−t)², 3t²(1−t), t³ 构成多项式空间 P₃ 的**基**（权 = 几何矩阵的行）
- **矩阵形式与埃尔米特曲线**：x(t) = u(t)·M·𝓖（u(t) 为混合多项式行向量，M 变换矩阵，𝓖 几何向量/控制点矩阵）；选不同 M 得**埃尔米特三次曲线**（几何矩阵的列 = 端点与端点切向量）
- **贝塞尔曲面**：把贝塞尔曲线的分解形式用于曲面讨论（控制网格）
- 应用：计算机图形设计（8.3 习题给出构造高次贝塞尔曲线的方法）、CAD

## Mental Models
- **超平面 = 刀，半空间 = 半边世界**：线性规划就是用一堆刀切出可行域（ch22/23）。
- **两种账本**：多面体可以记"约束清单"或"顶点清单"；单纯形法在顶点账本上行走，对偶理论在约束账本上推理。
- **Bézier = 加权平均的几何学**：伯恩斯坦权全非负、和为 1（凸组合！）→ 曲线不可能跑出凸包。

## Anti-patterns
- **法向量取成两点连线方向**：n 必须与面内方向正交；取差向量当法向量是常见错误。
- **以为所有约束都切出真实的面**：冗余约束只是"背景板"；极小表示才是多面体的本质描述。
- **Bézier 控制点顺序搞反**：b₀ 起点依次到 bₙ 终点；交换端点改变方向但同曲线（对称性）。
- **把凸包性质当"曲线过每个控制点"**：只过首尾；中间控制点只是"牵引"。

## Worked Example
三次 Bézier 曲线：b₀=(0,0), b₁=(1,2), b₂=(3,3), b₃=(4,0)。
x(t) = (1−t)³b₀ + 3t(1−t)²b₁ + 3t²(1−t)b₂ + t³b₃。
t=1/2：权 = (1/8, 3/8, 3/8, 1/8) → x = (0+3/8+9/8+4/8, 0+6/8+9/8+0) = (2, 15/8)。
凸包性质：曲线必在四边形 b₀b₁b₂b₃ 内；t=0、1 时分别过 b₀、b₃；曲线在 b₀ 处切向沿 b₁−b₀。
应用直觉：字体"O"的外轮廓 = 若干段三次 Bézier 拼接，控制点在描字软件里就是那些"手柄"。

## Key Takeaways
1. 超平面语言把约束写成几何：n·x=b 与两侧半空间。
2. 多面体的极小表示决定它的"真实形状"；顶点=极值点是优化定理的锚点。
3. 混合多项式的权全非负且和为 1（凸组合）→ 凸包性质是贝塞尔曲线一切可控性的来源。
4. 曲线拼接时保持"位置+切向"连续（C¹），是 CAD 建模的基本功。
