# Chapter 9: 向量空间、零空间/列空间与基（教材 4.1–4.3）

> 章首介绍性实例：离散时间信号与数字信号处理（DSP）——信号 {yₖ} 是向量空间 𝕊 的元素（Alexa 语音识别场景，详见 ch11）。本章把 ℝⁿ 的子空间理论推广到任意向量空间。

## Core Idea
**向量空间公理只要求"加法+数乘封闭"**——于是 ℝⁿ、多项式空间、信号空间、矩阵空间同台竞争；H 是 V 的子空间时，"H 里的方程组"也能用基与坐标求解。零空间/列空间是矩阵的两个内置子空间，基与维数全部机械化。

## 框架与定理

### 子空间（4.1）
**向量空间**：非空集合 V + 加法/数乘，满足 10 条公理（交换、结合、零元、负元、分配等）。元素统称"向量"（可以真是向量、多项式、函数…）。
**子空间 H**：V 的子集且 (i) 0∈H (ii) u+v∈H (iii) cu∈H。
- {0} 与 V 本身是平凡子空间
- Span{v₁,…,vₚ} 是最小的包含这些向量的子空间
- **A·H**：若 H 是 ℝⁿ 子空间，则 {Ax : x∈H} 是 ℝᵐ 子空间（变换像）
- **同构**：任何 p 维子空间都"行为上"等同于 ℝᵖ——这就是坐标系合法性的根据

### 零空间与列空间（4.2）
- **Nul A** = {x : Ax=0}（ℝⁿ 的子空间）：隐式描述（用方程定义）；显式描述 = 参数化生成集
- **Col A** = Span{列}（ℝᵐ 的子空间）：天生显式；基 = **A 的主元列**
- **Row A** = Col Aᵀ（ℝⁿ 的子空间）：基 = 阶梯形（或 RREF）的**非零行**——行变换不改行空间，可直接取
- **核（kernel）与值域（range）**：线性变换 T(x)=Ax 的核 = Nul A，值域 = Col A——把子空间语言翻译到变换
- Nul A 之基的求法：解 Ax=0 → 自由变量参数化（ch03 的流程）；Col A 基：主元列（原矩阵！）

### 线性无关集与基（4.3）
- **基**：H 中线性无关的生成集；唯一表示每个 H 的元素
- **基定理（Basis Theorem）**：若 H 中有 p 个线性无关的向量组成生成集（p = dim H），它们自动是基——"无关 + 个数对 = 基"
- Nul A 基：参数化向量（个数 = 自由变量数）；Col A 基：主元列；Row A 基：阶梯形非零行
- 求生成集内无关子集：把生成向量排成矩阵行化简，看哪些是主元列

## Mental Models
- **基 = 坐标系的出厂设置**：有了基，抽象空间的元素就有"地址"（坐标）。
- **Nul A 是"隐形方向"集合，Col A 是"可达输出"集合**：解方程 = 问 b 是否可达； uniqueness = 隐形方向是否只有 0。
- **子空间三查表**（0、+、×）是所有"是不是子空间"题的答题模板。

## Anti-patterns
- **把 Span{v₁,v₂} 说成"必是平面"**：若两向量共线则是一维的；维度取决于无关个数，不是向量个数。
- **把 Row A 的基取成"主元行"却说成主元列**：行空间基从阶梯形取非零行（数值上用原行的阶梯形）。
- **验证子空间只查加法**：三条都要查；特别当心 0 是否在集合中（常见反例：仿射集、非齐次解集）。
- **把"生成集"当"基"**：多了相关向量就不叫基；先化无关（行化简挑主元列）。

## Worked Example
$A=\left[\begin{smallmatrix}1&-2&0&3\\2&-4&1&5\\1&-2&2&8\end{smallmatrix}\right]$（RREF: 主元列 1、3）：
- Col A 基 = $\left[\begin{smallmatrix}1\\2\\1\end{smallmatrix}\right],\left[\begin{smallmatrix}0\\1\\2\end{smallmatrix}\right]$；rank A = 2
- 解 Ax=0（RREF $\left[\begin{smallmatrix}1&-2&0&3\\0&0&1&-1\\0&0&0&0\end{smallmatrix}\right]$）→ x₂,x₄ 自由 → Nul A 基 = $\left[\begin{smallmatrix}2\\1\\0\\0\end{smallmatrix}\right],\left[\begin{smallmatrix}-3\\0\\1\\1\end{smallmatrix}\right]$；dim Nul = 2
- 秩定理验算：2 + 2 = 4 = n ✓

子空间判定实例：W = {(a,b,c): a+b+c=0} 是 ℝ³ 子空间（含 0、封闭）；{(a,b,c): a+b+c=1} 不是（0 不在）。

## Reference Tables

| 子空间 | 隐式/显式 | 基 | 维数 |
|---|---|---|---|
| Nul A | 隐式（方程） | 参数化向量 | 自由变量数 |
| Col A | 显式（列生成） | 原矩阵主元列 | rank A |
| Row A | 显式（行生成） | 阶梯形非零行 | rank A |

## Key Takeaways
1. 一切"是不是子空间"题：三查表 + 若是则求基；基的个数即维数。
2. 三个子空间的基都有流水线做法，秩定理自动成立。
3. 同构思想：p 维子空间 = ℝᵖ 的"换皮"，坐标由此而来（ch10）。
4. 核与值域把矩阵语言与变换语言焊死：核=Nul，值域=Col。
