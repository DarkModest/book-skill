# Chapter 11: 数字信号处理与差分方程应用（教材 4.7–4.8）

> 第 6 版第 4 章的收尾专门给了信号：4.7 数字信号处理（DSP，第 6 版新增节），4.8 差分方程。信号空间 𝕊 是"无穷维向量空间"的正规军，LTI 变换、滤波、递推全在其中。

## Core Idea
**离散时间信号 {yₖ}（k∈ℤ）是向量空间 𝕊 的元素**；滤波 = 把信号投影/分解到基信号（单位脉冲移位）上处理。**差分方程 = 𝕊 中的线性方程组**：解的结构与 Ax=b 完全同构（通解 = 特解 + 齐次解）。

## 框架与定理

### 信号空间 𝕊（4.7）
- **信号**：定义在全体整数上的数列 {yₖ}；加法/数乘逐项进行 → 向量空间 𝕊（无穷维，定理18：移位脉冲 {Sʲ(δ)} 构成 𝕊 的基）
- **基信号家族**（表 4-2）：
  - δ（单位脉冲/kronecker delta）：dₖ = 1 if k=0 else 0
  - ν（单位阶跃）：uₖ = 1 if k≥0 else 0
  - χ（常数）：cₖ=1；α（交替/方波）：aₖ=(−1)ᵏ
  - F（斐波那契信号）：fₖ 递推 fₖ₊₁=fₖ+fₖ₋₁
  - ℯ_c（指数信号）：eₖ=cᵏ
  - 周期信号：pₖ = p_{k+q}；正弦信号 σ_{f,θ} = {cos(fkπ+θ)}
- **移位**：S{yₖ} = {y_{k−1}}（线性变换）；**信号合成**：{yₖ} = Σ yₖ·δ_k（用移位脉冲"读出"任意信号）

### 线性时不变变换（LTI）
- **滤波器**：线性 + 时不变；**定理 16**：LTI 变换是线性变换
- **定理 17**：截断信号空间 Sₙ（前 n+1 项非零）同构于 ℝ^{n+1}，Bₙ = {δ, S(δ), …, Sⁿ(δ)} 是其基——"移位脉冲作基"
- LTI 由**脉冲响应**（filter 对 δ 的输出）完全决定：输出 = 输入与脉冲响应的卷积
- **信号处理三步**：记录 → LTI 滤波（去噪）→ 比较/识别（Alexa 的"是/否"声音特征）

### 差分方程（4.8）
k 阶**线性差分方程**：y_{k+K} = a₁y_{k+K−1} + … + a_K yₖ + wₖ；右端为 0 时**齐次**。
- **定理 19**：给定初值 y₀,…,y_{K−1}，满足递推的信号存在且唯一
- **定理 20**：K 阶齐次线性差分方程的解集是 𝕊 的 **K 维子空间**
- **特征值方法**：试 yₖ = λᵏ → **辅助方程（特征方程）** λ^K − a₁λ^{K−1} − … − a_K = 0
- 特征根互异：齐次通解 = Σ cᵢλᵢᵏ（指数基）；重根时补 kᵏλᵏ
- 非齐次：特解 + 齐次通解（与 Ax=b 同构）
- 应用：**单种群模型** y_{k+1} = c·yₖ（Malthus/指数增长）；**二阶**斐波那契/信号递推；k 阶递推的"移位矩阵"实现：把 yₖ..y_{k+K−1} 排成状态向量 xₖ，递推变 x_{k+1} = A xₖ

## Mental Models
- **𝕊 是"无穷长向量"的空间**：ℝⁿ 的所有语言（无关、基、维数、坐标）都在，只是基无穷。
- **滤波 = 卷积 = 用脉冲响应配方**：LTI 只需要"看它对 δ 的反应"。
- **递推 → 状态向量 → x_{k+1}=Axₖ**：把高阶差分降到一阶矩阵递推，特征值接管一切（ch14）。

## Anti-patterns
- **把 {yₖ} 当成有限向量**：𝕊 无穷维，"有限 n 个基"不再成立；讨论子空间（如差分方程解空间）时才有有限维。
- **忽略"时不变"**：只线性不及时不变的滤波器不是 LTI，卷积结构破坏。
- **重根情形仍写 Σcᵢλᵢᵏ**：重根要乘 kᵏ；判重根前先解特征方程。
- **初值与通解脱节**：通解常数 cᵢ 由初值联立求出，缺一步就不是"满足初条件的解"。

## Worked Example
解 y_{k+2} − 5y_{k+1} + 6yₖ = 0，y₀=3, y₁=8。

特征方程：λ² − 5λ + 6 = 0 → λ = 2, 3（互异）。
通解：yₖ = c₁2ᵏ + c₂3ᵏ。
初值：c₁ + c₂ = 3；2c₁ + 3c₂ = 8 → c₁ = 1, c₂ = 2。
**yₖ = 2ᵏ + 2·3ᵏ**。
状态向量版：xₖ = (yₖ, y_{k+1})ᵀ，x_{k+1} = $\left[\begin{smallmatrix}0&1\\6&-5\end{smallmatrix}\right]$xₖ，特征值同为 2、3——两条路径汇合。

## Key Takeaways
1. 𝕊 把"向量空间"推到无穷维：信号处理的所有操作都是其上的线性变换。
2. LTI 滤波器由脉冲响应唯一决定——卷积是滤波的代数表达。
3. 齐次差分方程解空间是有限维子空间，特征方程给出指数基。
4. 状态向量化 x_{k+1}=Axₖ 把递推问题交给特征值理论（第 5 章正式登场）。
