# Chapter 19: 奇异值分解与图像/统计应用（教材 7.4–7.5）

> 全书数值理论的顶点：**任何矩阵都有 SVD**。7.5 用 SVD 讲主成分分析（PCA）—— Landsat 多波段图像压缩（章首实例）与统计学的协方差几何。

## Core Idea
**SVD A=UΣVᵀ 给每个矩阵装上两组正交基**：定义域用 V（右奇异向量），值域用 U（左奇异向量），Σ 按重要性（奇异值 σᵢ=√λᵢ(AᵀA)）排序——矩阵动作 = "旋转 V→按 σ 缩放→旋转到 U"。截断 SVD = 最佳低秩近似 = 数据压缩的数学本体。

## 框架与定理

### SVD 构造（7.4）
设 rank A = r，AᵀA 特征值排序 λ₁≥…≥λᵣ>0：
- **奇异值** σᵢ = √λᵢ；**右奇异向量** vᵢ = AᵀA 的单位特征向量；**左奇异向量** uᵢ = Avᵢ/σᵢ（自动正交单位）
- **分解**：A = UΣVᵀ，U m×m、V n×n 正交，Σ m×n 对角（σ₁≥σ₂≥…>0 后补零）
- **定理（维数账本）**：rank A = r = 非零奇异值个数；Nul A = Span{v_{r+1},…,vₙ}；Col A = Span{u₁,…,uᵣ}
- **满 SVD vs 紧 SVD**：紧形式只留 r 列（ economical ）
- **伪逆（Moore-Penrose）**：A⁺ = V_r Σ_r⁻¹ U_rᵀ；**最小二乘最稳解** x̂ = A⁺b（也是最小范数解）
- **最佳 k 秩近似**：A_k = Σ_{i≤k} σᵢuᵢvᵢᵀ；误差 ‖A−A_k‖₂ = σ_{k+1}（Eckart-Young：截断 SVD 是所有 k 秩阵中最优）
- 数值秩：奇异值断崖处定 rank（容忍小奇异值为 0）

### 图像处理与统计学应用（7.5）
- **主成分分析（PCA）**：数据中心化后得矩阵 B（N 个观测按列或行），样本协方差
$$S = \tfrac{1}{N-1}B^TB$$
- B 的 SVD：主成分 = 右奇异向量方向；得分 = 投影；**总方差 = trace S = Σσᵢ²/(N−1)**；第一主成分解释方差占比 = σ₁²/Σσᵢ²
- Landsat 例：3 波段 93.5% 差异进第一成分；224 波段压到 ~15 成分
- **SVD 图像压缩**：图像=矩阵，截断 SVD 保留前 k 个奇异值：存储 k(m+n+1) 而非 mn
- 多波段图像处理、去噪（小奇异值≈噪声）、距离与相似度（潜语义索引 LSI 思想，习题）

## Mental Models
- **SVD = 矩阵的"成分表"**：σᵢ 是各成分含量，按从大到小排——最大的先写。
- **四个基的接力**：ℝⁿ --(V 旋转)--> 主轴 --(Σ 缩放)--> --(U 旋转)--> ℝᵐ；任何矩阵只有"旋转-缩放-旋转"三步。
- **PCA = 找数据云最胖的方向**：σ 大的方向=数据散得开的方向=信息多的方向。

## Anti-patterns
- **把奇异值当特征值**：σᵢ=√λᵢ(AᵀA)≥0，与 A 的特征值是两回事（除正规情形外不重合）。
- **U、V 张冠李戴**：V 来自 AᵀA（定义域），U 来自 AAᵀ（值域）；uᵢ=Avᵢ/σᵢ 而不是 Aᵀvᵢ。
- **不中心化就做 PCA**：均值没减，第一成分被均值方向霸占——协方差几何失效。
- **截断太多**：σ 曲线的"肘部"才是自然截断点；截过头=丢信息，截太少=留噪声。

## Worked Example
A = $\left[\begin{smallmatrix}4&11&14\\8&7&-2\end{smallmatrix}\right]$。
AᵀA = $\left[\begin{smallmatrix}80&100&40\\100&170&140\\40&140&200\end{smallmatrix}\right]$，特征值 λ = 360, 90, 0 → σ = 6√10, 3√10, 0（rank 2）。
v₁ = (1/3, 2/3, 2/3)ᵀ, v₂ = (−2/3, −1/3, 2/3)ᵀ, v₃ = (2/3, −2/3, 1/3)ᵀ；
u₁ = Av₁/σ₁ = (3/√10, 1/√10)ᵀ, u₂ = (−1/√10, 3/√10)ᵀ。
A = UΣVᵀ，Σ = $\left[\begin{smallmatrix}6\sqrt{10}&0&0\\0&3\sqrt{10}&0\end{smallmatrix}\right]$。
1 秩近似 A₁ = σ₁u₁v₁ᵀ：误差 ‖A−A₁‖₂ = σ₂ = 3√10 ≈ 9.49。

## Key Takeaways
1. 存在性无条件的分解只有 SVD——长方阵、退化阵都覆盖。
2. SVD 同时回答四个问题：秩、四个基本子空间的基、最小二乘最稳解、最佳低秩近似。
3. PCA 流水线：中心化 → BᵀB（或直接 SVD）→ 奇异值排序 → 方差占比定维数。
4. 截断 SVD = 压缩/去噪/推荐的共同数学内核（Eckart-Young 保证最优）。
