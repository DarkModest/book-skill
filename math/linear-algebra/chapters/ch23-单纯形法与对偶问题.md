# Chapter 23: 单纯形法与对偶问题（教材 9.3–9.4）

> 第 9 章收官：9.3 把"沿顶点走"变成可执行的表格算法（单纯形法）；9.4 给每个 max 问题配一个 min 镜像（对偶），**并用对偶理论完成矩阵博弈的完整求解**——全书应用线收束。

## Core Idea
**单纯形法 = 从一个极值点走到更优的相邻极值点**，用"松弛变量把不等式变方程 + 表格行变换"机械化；**对偶问题 = 同一份数据的两种叙述**（max 利润 ↔ min 定价），强对偶定理保证两边值相等，影子价格由此诞生。

## 框架与定理

### 单纯形法（9.3）
**规范 max 问题**：max f = cᵀx s.t. Ax ≤ b, x ≥ 0（b ≥ 0）。
- **松弛变量（slack variable）**：x_{n+j} = b_j − (Ax)_j ≥ 0 把不等式变方程 Ax + x_slack = b
- **初始单纯形表**：底行放 −c（目标行），M = cᵀx 使底行归零的技巧（−2x₁−x₂+M=0 型底行）；可行集极值点 ⟺ 表的基本可行解（非基变量=0）
- **单纯形法步骤**：
  1. 选可行集 F 一个极值点 x（初始：原点，松弛变量为基）
  2. **判优**：底行全 ≥ 0 → 当前即最优
  3. **选入基列（pivot column）**：底行最负的列（该变量入基能增 f）
  4. **选主元行（pivot row）**：该列正元素中 b/系数 比值最小者（保非负与可行）
  5. 行变换换基（主元化为 1、同列其余为 0），回到 2
- 循环即"沿棱走到更优顶点"，每步 f 增加非负 → 收敛到最优顶点
- 例（9.2 的 Shady-Lane 问题 x₁=8, x₂=0, f=16）：引入松弛变量 → 一次主元迭代到位
- 运输问题（2 仓库 4 商店）：等式约束 + 供给 ≤、需求 =，仍是 LP，单纯形法可处理

### 对偶问题（9.4）
**原始（primal）问题 P**：max f(x)=cᵀx s.t. Ax ≤ b, x ≥ 0。
**对偶（dual）问题 P***：min g(y)=bᵀy s.t. Aᵀy ≥ c, y ≥ 0。
- **弱对偶**：任何可行 x, y 满足 cᵀx ≤ bᵀy（直接由不等式链）
- **强对偶定理**：若一方有最优解，另一方也有，且**值相等** f(x*)=g(y*)
- **经济解读（影子价格）**：对偶最优 y* = 资源的边际价值——第 j 种资源每多一单位，最优利润增加 y*_j
- **矩阵博弈的 LP 化**：R 的问题 = max v s.t. Aᵀx ≥ v·1, Σx=1, x≥0（v 是保底期望）；C 的问题镜像；由 minimax=对偶值定理，**博弈的值 = 对偶 LP 的公共最优值**——任何矩阵博弈可用两个 LP 求解
- 例：max 2x₁+x₂ s.t. −x₁+2x₂≤8, 3x₁+2x₂≤24：松弛变量 x₃,x₄ 入表 → 一次主元（x₁ 入基，第二行为主元行）→ 最优 x=(8,0)，f=16；对偶 y* 读自最终表底行松弛变量位置 → 影子价格

## Mental Models
- **单纯形表 = 可行域的"地址簿"**：每张表记录一个顶点及其邻接信息；主元 = 换到更好的邻居。
- **对偶 = 老板与会计师**：原始问题问"怎么生产最赚钱"，对偶问题问"资源定价多少才不肯让别人租走工厂"；答案必相等。
- **底行符号即判决书**：底行全非负=没人能再改进=最优；最负列=最有潜力的方向。

## Anti-patterns
- **忘了松弛变量不是"真决策"**：报告答案时松弛变量值是"剩余资源"，别混进 x。
- **主元行选错导致不可行**：必须取比值 min(bⱼ/aⱼ)（aⱼ>0）；乱选会出现负分量破坏可行。
- **对偶约束方向写反**：primal (≤, max) ↔ dual (≥, min)；A 转置、c 与 b 互换。
- **影子价格当固定价格**：y* 只在当前基（资源区间）内有效，超出范围需重新求解（灵敏度分析）。

## Worked Example
max 2x₁+x₂ s.t. x₁+x₂≤4, x₁+3x₂≤6, x≥0（规范形）。

松弛：x₃, x₄。初始表：
```
        x1   x2   x3   x4 |  b
       [ 1    1    1    0 |  4 ]
       [ 1    3    0    1 |  6 ]
底行    -2   -1    0    0 |  0
```
底行最负 → x₁ 入基列；比值 4/1 vs 6/1 → 主元行 1。换基后底行 = (0, 1, 2, 0 | 8) 全非负 → 最优 **x₁=4, x₂=0, f=8**。
对偶：min 4y₁+6y₂ s.t. y₁+y₂≥2, y₁+3y₂≥1, y≥0；最优 y* = (2, 0)，g=8=f ✓。影子价格：资源 1 每多一单位利润 +2；资源 2 富余（x₄=2 未用尽）→ 影子价格 0。

## Key Takeaways
1. 单纯形法三步循环：判优（底行）→ 选列（最负）→ 选行（最小比值）；表格行变换即顶点跳跃。
2. 松弛变量把"≤世界"线性化；基本解 ↔ 顶点一一对应。
3. 强对偶 f*=g* 是线性规划的皇冠定理；对偶解 = 影子价格 = 资源边际价值。
4. 矩阵博弈归约为 LP 对偶——9.1 的悬念在此闭环（minimax 定理的构造性证明）。
