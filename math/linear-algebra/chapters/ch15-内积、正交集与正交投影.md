# Chapter 15: 内积、长度和正交性（教材 6.1–6.3）

> 章首介绍性实例：人工智能和机器学习——猫狗图像识别、邮政条码分拣、谷歌助手；核心引擎正是本章的正交性（6.2/6.3 设计矩阵识别色块，6.5/6.6/6.8 机器学习技术）。

## Core Idea
**正交 = 独立的"度量版"**：内积给出长度与角度后，"互相垂直的方向"可以无损叠加、干净分离；**正交投影 = 最好的近似**——一切"最小化"问题（最小二乘、傅里叶、PCA）都归结为它。

## 框架与定理

### 内积、长度、距离（6.1）
- **内积/点积**：u·v = uᵀv = Σuᵢvᵢ；**长度** ‖v‖=√(v·v)；**距离** dist(u,v)=‖u−v‖
- **角度**：u·v = ‖u‖‖v‖cosθ；**正交（orthogonal）**：u·v = 0（零向量与任何向量正交）
- **勾股定理**：u⊥v ⟹ ‖u+v‖² = ‖u‖²+‖v‖²

### 正交集（6.2）
- **正交集**：两两正交的非零向量集 → **必线性无关**（定理4）
- **正交分解**：若 {u₁,…,uₚ} 是子空间 W 的正交基，任意 y∈W（定理5）：
$$\boldsymbol{y} = \frac{\boldsymbol{y}\cdot\boldsymbol{u}_1}{\boldsymbol{u}_1\cdot\boldsymbol{u}_1}\boldsymbol{u}_1 + \cdots + \frac{\boldsymbol{y}\cdot\boldsymbol{u}_p}{\boldsymbol{u}_p\cdot\boldsymbol{u}_p}\boldsymbol{u}_p$$
系数 = 投影系数（不用解方程！）
- **标准正交集（orthonormal）**：再要求单位长；**标准正交列的矩阵 U**（定理6/7）：UᵀU=I、‖Ux‖=‖x‖（保长）、(Ux)·(Uv)=x·v（保角）、(Ux)·(Uv)=0 ⟺ x·v=0；方阵标准正交 = **正交矩阵** Q，Q⁻¹=Qᵀ
- 矩阵乘法视角：正交分解 = 把 y 对基做"逐列投影"

### 正交投影（6.3）
y∉W 时，把 y 分解为 y = ŷ + z，z = y−ŷ ⊥ W：
- **正交投影** ŷ = proj_W y（系数公式同上）；**z ∈ W⊥**（W 的正交补）
- **定理 8（正交分解定理）**：y = ŷ + z 唯一（ŷ∈W, z∈W⊥）
- **定理 9（最佳逼近定理）**：对一切 v∈W，‖y−ŷ‖ ≤ ‖y−v‖，等号 ⟺ v=ŷ——**投影就是 W 中离 y 最近的点**
- 常用公式（定理10）：proj_W y = UUᵀy（U 标准正交列）；对单向量 u：ŷ = (y·u/u·u)u
- 几何：投影矩阵 P = UUᵀ，P²=P、Pᵀ=P（对称幂等）

## Mental Models
- **正交基 = 已经"互相免责"的坐标轴**：系数互不干扰，一列一列独立读出。
- **投影 = 阴影**：ŷ 是 y 打在 W 上的影子；影子 + 站立方向（W⊥ 分量）拼回原向量。
- **最佳逼近定理是所有"拟合"的法源**：最小二乘（6.5）、傅里叶（6.8）、主成分（7.5）都在引用它。

## Anti-patterns
- **正交集忘了查零向量**：含零向量不构成正交集（也与"无关"结论冲突）。
- **把正交投影公式用于 y∈W 之外的整体范数比较**：逼近界只在 W 内部比较；对 W 外的点谈不上"最近"。
- **UᵀU=I 误用于方阵之外**：长方阵 U 只有左逆（UᵀU=I），UUᵀ≠I。
- **坐标算错权分母**：投影系数分母是 u·u（‖u‖²），不是 u 的长度。

## Worked Example
u₁=(2,5,−1)ᵀ, u₂=(−2,1,3)ᵀ（正交：−4+5−3=0 ✓），y=(8,0,−8)ᵀ ∈ W=Span{u₁,u₂}。求 ŷ 与 [y]_正交基。

系数：c₁ = y·u₁/u₁·u₁ = (16+0+8)/30 = 0.8；c₂ = y·u₂/u₂·u₂ = (−16+0−24)/14 = −20/7…（若给 y 使系数整齐更好）改 y=(1,1,1)ᵀ：c₁ = (2+5−1)/30 = 0.2，c₂ = (−2+1+3)/14 = 1/7。
ŷ = 0.2u₁ + (1/7)u₂；z = y−ŷ ⊥ W 可验证 z·u₁ = z·u₂ = 0。
对比传统做法：求 [y]_基 要解 3×2 方程组；正交基只需两次点积——这是"正交化"的价值。

## Key Takeaways
1. 正交集自动线性无关；正交基下坐标 = 逐列点积，零求解成本。
2. 投影 = 最佳逼近，这是"最小化"类问题的统一出口。
3. 标准正交矩阵保长保角——数值稳定性的根源（QR、SVD 的动机）。
4. 分解 ŷ+z 的唯一性给了 W⊥ 的计算入口（W⊥ = Row Aᵀ，4.2 呼应）。
