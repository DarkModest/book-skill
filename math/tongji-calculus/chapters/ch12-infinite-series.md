## 常数项级数（§1–2）
- **定义**：u₁+u₂+…+uₙ+… 的部分和 Sₙ；**收敛** ⇔ lim Sₙ 存在。几何级数 Σaqⁿ：|q|<1 收敛于 a/(1−q)，|q|≥1 发散。**调和级数 Σ1/n 发散**（部分和 ~ ln n）。
- 性质：收敛必要条件 **lim uₙ = 0**（逆否命题是判发散第一武器；lim=0 不保证收敛）；去首尾有限项、加括号不改变敛散（加括号收敛原必收敛，反之不然——发散级数加括号可能"收敛"）。
- *柯西审敛原理：收敛 ⇔ ∀ε ∃N，m,n>N 时 |S_m−S_n|<ε。
- **正项级数审敛体系**（sₙ 单调增，有界 ⟺ 收敛）：
  - **比较判别法**及极限形式：大收小收，小发大发；极限形式 lim uₙ/vₙ = c（0<c<+∞ 同敛散）。
  - **比值（达朗贝尔）判别法**：lim uₙ₊₁/uₙ = ρ，ρ<1 收敛，ρ>1 发散，ρ=1 失效。
  - **根式（柯西）判别法**：lim ⁿ√uₙ = ρ，结论同上。
  - **积分判别法思路**：p 级数 Σ1/nᵖ p>1 收敛、p≤1 发散（审敛基准）。
- **交错级数·莱布尼茨判别法**：uₙ 单调减且→0 ⟹ 收敛，且余项 |rₙ| ≤ uₙ₊₁。
- **绝对收敛与条件收敛**：Σ|uₙ| 收敛 ⟹ Σuₙ 收敛（绝对收敛更强）；|uₙ| 发散但 Σuₙ 收敛 = 条件收敛。绝对收敛级数可重排、可乘积；条件收敛不可（黎曼重排定理思想）。

## 幂级数（§3–5）
- **阿贝尔定理**：x₀≠0 收敛 ⟹ |x|<|x₀| 绝对收敛；发散 ⟹ |x|>|x₀| 发散 ⟹ 存在收敛半径 R。
- **收敛半径**：R = lim |aₙ/aₙ₊₁|（系数比）或 1/lim ⁿ√|aₙ|；R=0 只在 x=0 收敛，R=∞ 处处收敛。**收敛区间 (−R,R)；收敛域 = 区间 ∪ 逐个检验的端点**。
- 和函数性质：收敛域内连续；**可逐项求导、逐项积分**（在收敛区间内部，收敛半径不变，端点另查）——求和函数的唯一工具。
- **函数展开成幂级数**：
  - 直接法：算 f^{(n)}(0) 写泰勒系数＋证余项→0。
  - **间接法（主战场）**：从五个基本展开出发，用代换、四则、逐项求导、逐项积分合成：
    e^x = Σxⁿ/n!；sin x = Σ(−1)ⁿx^{2n+1}/(2n+1)!；cos x = Σ(−1)ⁿx^{2n}/(2n)!；1/(1−x) = Σxⁿ (|x|<1)；ln(1+x) = Σ(−1)^{n−1}xⁿ/n (−1<x≤1)；(1+x)^α 二项级数。
- 应用：近似计算（误差用余项控制）、*微分方程幂级数解法、*欧拉公式 e^{iθ} = cosθ + i sinθ。
- *一致收敛：优级数（M 判别法）、和函数连续/逐项积分求导定理。

## 傅里叶级数（§7–8）
- **三角级数正交性**：{1, cos nx, sin nx} 在 [−π,π] 上两两正交。
- **傅里叶系数**：aₙ = (1/π)∫_{−π}^{π} f(x)cos nx dx，bₙ = (1/π)∫f(x)sin nx dx（a₀=(1/π)∫f dx 单独）。
- **收敛定理（狄利克雷）**：f 周期、分段单调/分段光滑 ⟹ 级数收敛于：连续点 f(x)；**间断点 = [f(x⁻)+f(x⁺)]/2**（左右极限平均——必考）。
- **奇偶简化**：奇函数只有 bₙ（正弦级数），偶函数只有 aₙ（余弦级数）；[0,π] 上的函数**奇延拓/偶延拓**得正弦/余弦展开。
- **一般周期 2l**：变量代换 x → πx/l，系数公式换 π 为 l；*复指数形式 Σcₙe^{inx}。

## 经典型例
- 判敛：Σn!/nⁿ（比值→e^{−1}<1 收敛）；Σ1/√n（p=1/2 发散）；Σ(−1)ⁿ/n 条件收敛。
- 求 Σxⁿ/n! 的和函数：逐项求导 ⟹ e^x−1 型套路；Σn xⁿ = x/(1−x)²（先 1/(1−x) 求导）。
- 展开 f=1/(2+x) 为 x 的幂级数：1/2·1/(1+x/2) = Σ(−1)ⁿxⁿ/2ⁿ⁺¹，|x|<2。
- 展开 f(x)=x² (−π≤x<π) 为傅里叶级数并求 Σ1/n²（延拓后逐项代入 x=0, π——帕塞瓦尔思想的经典应用）。
- 分段函数傅里叶系数：分段积分。

## 常见错误
- 用 lim uₙ=0 判断收敛（只是必要条件）。
- 比值/根式=1 时仍下结论（失效，须换比较或泰勒看阶）。
- 收敛域忘查端点；逐项求导后忘收窄区间再单独验端点。
- 间断点处傅里叶和写成 f(x)（应为左右极限平均）。
- 求和函数时逐项积分/求导不写适用范围。
- 傅里叶系数 a₀ 与 2a₀ 混淆（级数中常数项是 a₀/2）。

## 要点回顾
1. 判敛决策链：必要条件 → 看符号（同号走正项体系；交错走莱布尼茨+绝对收敛）→ 选法（结构像几何/有 n!·aⁿ 用比值；ⁿ√uₙ 好算用根式；像 1/nᵖ 用比较）。
2. 幂级数一切问题归结为收敛半径＋端点；和函数问题归结为几何级数逐项微积分。
3. 五个基本展开是展开题的"母库"，间接法是唯一高效路径。
4. 傅里叶系数是公式积分，间断点收敛值是理论考点，奇偶延拓是技巧考点。
