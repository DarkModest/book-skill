# 第十章 重积分（下册 书页 130–179）

## 本章地位
多元积分学第一块：二重、三重积分。仍是"分割—近似—求和—取极限"（曲顶柱体体积 / 空间物体质量），计算总策略是**化归为多次定积分（累次积分）＋换坐标系**。

## 章节结构（节 · 书页）
1. 二重积分的概念与性质 p130　2. 二重积分的计算法 p136　3. 三重积分 p154　4. 重积分的应用 p161　*5. 含参变量的积分 p171　总习题十 p177

## 关键定义
- **二重积分**：∬_D f(x,y)dσ = lim_{λ→0} Σ f(ξ_i,η_i)Δσ_i（D 上有界；连续必可积）。几何：曲顶柱体体积（f≥0）；物理：平面薄片质量。
- **三重积分**：∭_Ω f(x,y,z)dV——空间物体质量（f 为密度）；f≡1 时为区域体积。
- 性质与定积分平行：线性、区域可加、保号、估值、**中值定理**（连续时 ∬f = f(ξ,η)·D面积）。

## 二重积分计算（核心）
- **X 型区域**（竖线穿入穿出各一条）：∬f = ∫_a^b dx ∫_{y₁(x)}^{y₂(x)} f dy；Y 型对称。**先看区域类型，次序选错就交换次序**（交换次序须先反解区域边界）。
- **极坐标**：x=r cosθ, y=r sinθ，**dxdy → r dr dθ**（雅可比因子 r 必带！）；∬f = ∫θ∫r f(rcosθ,rsinθ)·r。
  - 适用信号：区域是圆（环、扇），或被积函数含 x²+y²、y/x。
  - 常见限：圆盘 r: 0→R, θ: 0→2π；上半 θ: 0→π。
- *一般换元：x=x(u,v), y=y(u,v)，dxdy = |∂(x,y)/∂(u,v)| dudv（广义极坐标 x=a r cosθ… 时因子 abr）。

## 三重积分计算（三坐标系）
- **投影法（先一后二）**：Ω 在 xOy 投影 D，∬_D dxdy ∫_{z₁}^{z₂} f dz。
- **截面法（先二后一）**：∫_{c₁}^{c₂} dz ∬_{D_z} f dxdy——f 只含 z 或 D_z 面积易求时快（如 ∭z²dV）。
- **柱面坐标**：x=rcosθ, y=rsinθ, z=z，dV = **r** dr dθ dz（适用于含 x²+y² 或圆柱区域）。
- **球面坐标**：x=r sinφ cosθ, y=r sinφ sinθ, z=r cosφ（φ 从 z 轴正向起），dV = **r² sinφ** dr dφ dθ（适用于球域或含 x²+y²+z²）。

## 重积分应用（元素法高维版）
- **曲面面积**：z=f(x,y) 上 dS = √(1+z_x²+z_y²) dxdy。
- **质心（形心）**：x̄ = (1/M)∬_D x·μ dσ（M 为质量）；密度均匀时为形心公式。
- **转动惯量**：I_x = ∬(y²+z²)μ dV（对 x 轴）。
- **引力**：元素 dF 分解投影后积分（对称性先消分量）。

## 对称性速查（提速第一工具）
- 区域 D 关于 x 轴对称：f 是 y 的奇函数 ⟹ ∬f=0；偶函数 ⟹ =2∬_{D∩y≥0}f。三重积分同理（对每个变量分别讨论）。
- **轮换对称性**：区域关于 y=x（或 Ω 关于 x,y,z 轮换不变）时，∬x² = ∬y² 等——求 I=∬(x²+y²+z²) 时把三个相加再除三。

## 经典型例
- 交换次序：∫₀¹dy ∫_y^1 e^{−x²}dx（e^{−x²} 积不出 ⟹ 必换序：∫₀¹dx∫₀^x… = (1−e^{−1})/2）。
- ∬_{x²+y²≤R²}(x²+y²)dσ：极坐标 = πR⁴/2。
- ∭_Ω z dV，Ω 由 z=√(x²+y²) 与 z=1 围成：截面法 ∫₀¹dz ∬_{z} z dxdy = ∫₀¹ z·πz² dz = π/4。
- ∭_{x²+y²+z²≤R²}(x²+y²+z²)dV：球坐标 r⁴·4π/5·R⁵ 型。
- 求由两曲面围成体的体积：先联立求交线定限，再 ∭dV。

## 常见错误
- 极坐标忘乘 r；球面坐标忘 r²sinφ（最高频扣分点）。
- 累次积分内外限写反：外层限必须常数，内层限是外层变量的函数。
- 对称性滥用：区域不对称或函数只对另一变量对称时错用。
- 交换次序时不画区域图直接换（必须反解边界曲线）。
- 截面法用于 f 含全部变量的情形反而复杂（选错工具）。

## 要点回顾
1. 一切计算化归为定积分：次序选择看"谁积得出"，坐标系选择看"区域形状+函数结构"。
2. dxdy→r dr dθ、dV→r²sinφ drdφdθ 两个因子是肌肉记忆。
3. 先对称性瘦身，再选坐标系，最后累次——这个顺序能省一半工作量。
4. 应用题全部是元素法：写元素（面积元/质量元/力元）→ 积分。
