# 第四章 不定积分（上册 书页 180–218）

## 本章地位
求导的逆运算。技能训练章：凑微分、换元、分部三大手法＋有理函数分解，是第五章定积分、第十章重积分、第十一章线面积分计算的引擎。

## 关键定义（按教材表述）
- **原函数**：在区间 I 上可导函数 F 满足 F′(x)=f(x)（或 dF=f dx）。
- **原函数存在定理**：连续函数必有原函数（存在性在第五章用变上限积分证明）。
- **不定积分**：f 的全体原函数，∫f(x)dx = F(x)+C。线性性质两条（和差、常数倍）。

## 基本积分表（必须默写）
∫x^μ dx = x^{μ+1}/(μ+1)+C (μ≠−1)；∫dx/x = ln|x|+C；∫e^x dx = e^x+C；∫a^x dx = a^x/ln a+C；∫sin x dx = −cos x+C；∫cos x dx = sin x+C；∫sec²x dx = tan x+C；∫csc²x dx = −cot x+C；∫sec x dx = ln|sec x+tan x|+C；∫csc x dx = ln|csc x−cot x|+C；∫dx/(1+x²) = arctan x+C；∫dx/√(1−x²) = arcsin x+C。

## 方法体系
### 第一类换元（凑微分）
∫f[φ(x)]φ′(x)dx = [∫f(u)du]_{u=φ(x)}。核心是"凑"：把 dx 凑成 d(□)。高频凑法：
- x dx = ½d(x²)；dx/x = d(ln x)；e^x dx = d(e^x)；sin x dx = −d(cos x)；sec²x dx = d(tan x)；
- dx/√x = 2d(√x)；dx/(1+x²) = d(arctan x)；(1+ln x)dx = d(x ln x)；f′(x)dx = d f(x)。
### 第二类换元（令 x=φ(t)，须 φ′≠0 且反函数存在）
- **三角代换三型**：√(a²−x²) → x=a sin t；√(a²+x²) → x=a tan t；√(x²−a²) → x=a sec t。回代画**辅助直角三角形**。
- 根式代换：t=ⁿ√(ax+b)（整体无理式）；倒代换 x=1/t（分母次数高于分子时）。
### 分部积分法
∫u dv = uv − ∫v du。**选 u 口诀（反对幂三指）**：反三角、对数、幂、三角、指数，排前者选为 u；被积函数两因子相乘且"一个积不出、一个积得出"时用。循环型（如 ∫e^x sin x dx）分部两次后**解方程**。
### 有理函数积分
真分式分解为四类简单分式（1/(x−a)、1/(x−a)ⁿ、(Mx+N)/(x²+px+q)、二次因式幂次）；q²−4q<0 时配方凑。可化为有理的三类：三角有理式（**万能代换 t=tan(x/2)**：sin x=2t/(1+t²)，cos x=(1−t²)/(1+t²)，dx=2dt/(1+t²)）；简单无理式（根式代换）。
### 积分表使用
按被积函数类型查表，配合递推公式（如 ∫dx/(x²+a²)ⁿ）。

## 经典型例
- ∫sin³x dx = ∫(1−cos²x)sin x dx = −cos x + cos³x/3 + C（拆 sin²=1−cos² 凑 −d cos x）。
- ∫dx/(x²√(x²+1))：倒代换 x=1/t → −√(1+t²)+C 路；或 x=tan t。
- ∫ln x dx = x ln x − x + C（分部：u=ln x, dv=dx）。
- ∫e^x sin x dx：两次分部 → 解方程 = e^x(sin x−cos x)/2 + C。
- ∫dx/(1+x³)：部分分式 = ⅓∫dx/(1+x) − ⅓∫(x−2)/(x²−x+1)dx。

## 常见错误
- 结果忘写 +C（扣分铁律）。
- 三角代换忘记回代或回代时不画三角形直接猜。
- ∫dx/(a²+x²) 写成 arctan(ax)（系数丢 1/a）。
- 分部时 u、dv 选择导致越积越复杂（口诀不熟）。
- 幂函数积分 μ=−1 时仍用 x^{μ+1}/(μ+1)（须 ln|x|）。
- 假分式不化真分式直接套部分分式。

## 要点回顾
1. 求积分比求导难：没有统一算法，只有"识别类型—选手法"。
2. 优先级：基本公式/性质化简 → 凑微分 → 分部 → 换元（三角/根式）→ 部分分式 → 查表。
3. 分部积分的 u 选择口诀 + 循环解方程是两大高频技巧。
4. 同一积分常有多种路径，结果差一个常数是正常的（可用求导验证答案）。
