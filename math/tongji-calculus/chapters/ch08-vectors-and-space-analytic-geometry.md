# 第八章 向量代数与空间解析几何（下册 书页 1–51）

## 关键概念与运算
- **向量**：既有大小又有方向的量；自由向量。坐标表示 **a = (a_x, a_y, a_z)**；模 |a|=√(a_x²+a_y²+a_z²)；单位向量 a/|a|；**方向角** α,β,γ 与方向余弦 cos²α+cos²β+cos²γ=1。
- **线性运算**：加减（三角形/平行四边形法则）、数乘 λa；共线 ⇔ b=λa。
- **数量积（点积）**：a·b = |a||b|cosθ = a_xb_x+a_yb_y+a_zb_z。用途：求夹角 cosθ = a·b/(|a||b|)；判垂直 a·b=0；投影 Prj_a b = |b|cosθ。
- **向量积（叉积）**：a×b，方向右手规则从 a 转向 b，模 |a×b| = |a||b|sinθ = 以 a,b 为邻边的平行四边形面积。坐标：行列式 |i j k; a_x a_y a_z; b_x b_y b_z|。用途：判平行 a×b=0；求**法向量、方向向量**（两向量叉积垂直于两者——几何题万能钥匙）。
- *混合积 [a b c] = (a×b)·c = 三阶行列式；|混合积|＝平行六面体体积；=0 ⇔ 共面。

## 平面与直线（核心方程库）
- **平面**：点法式 A(x−x₀)+B(y−y₀)+C(z−z₀)=0（法向量 n=(A,B,C)）；一般式 Ax+By+Cz+D=0；截距式 x/a+y/b+z/c=1。两平面夹角 cosφ = |A₁A₂+B₁B₂+C₁C₂|/(√□√□)。
- **直线**：对称式（点向式）(x−x₀)/m = (y−y₀)/n = (z−z₀)/p（方向向量 s=(m,n,p)）；参数式；一般式（两平面交线）。方向向量取法：两平面法向量叉积 s = n₁×n₂。
- 位置关系速查：线∥面 ⇔ s·n=0 且点不在面上；线⊥面 ⇔ s∥n；线面夹角 sinφ = |s·n|/(|s||n|)；点到平面距离 d = |Ax₀+By₀+Cz₀+D|/√(A²+B²+C²)。
- **平面束**：过一般式直线的平面 π: A₁x+B₁y+C₁z+D₁+λ(A₂x+B₂y+C₂z+D₂)=0——求投影平面/特定平面的利器。

## 曲面
- **旋转曲面**：坐标面曲线绕轴旋转。yOz 面曲线 f(y,z)=0 绕 z 轴 → f(±√(x²+y²), z)=0（**同轴变量不动，另一变量换成"另两坐标平方和的平方根"**）。例：直线 y=z 绕 z 轴→锥面 z²=x²+y²；圆 (y−b)²+z²=a² 绕 z 轴→圆环面。
- **柱面**：缺一个变量的方程（如 x²+y²=1 在空间是圆柱面，母线平行缺失变量轴）。
- **二次曲面**（截痕法识别）：椭球面 x²/a²+y²/b²+z²/c²=1；椭圆抛物面 z=x²/a²+y²/b²；双曲抛物面（马鞍面）z=x²/a²−y²/b²；单叶/双叶双曲面；椭圆锥面。

## 空间曲线
- 一般式（两曲面交线）；参数式；**在坐标面上的投影**：方程组消去 z 得投影柱面，与 z=0 联立——第十章确定积分区域的基本操作。

## 经典型例
- 求过点 (1,1,1) 且垂直于两平面 x−y+z=1 和 2x+y−z=1 的平面：n = n₁×n₂ = (0,3,3)~(0,1,1)，点法式 y+z=2。
- 求点 (2,1,0) 到直线 x/2=y/2=z 的距离（投影法或叉积三角形面积法 d=|AB×s|/|s|）。
- 直线 L: {x+y−z=1, 2x−y+z=2} 化对称式（找点+叉积方向）。
- 求球面 x²+y²+z²=4 与平面 z=1 的交线在 xOy 面的投影：x²+y²=3, z=0。

## 常见错误
- 法向量与方向向量混用（平面要 n，直线要 s）。
- 叉积行列式展开符号错误（i 的余子式为正，j 为负，k 为正）。
- 旋转曲面公式把"绕 z 轴"当成"把 z 换 √"（应为不动 z，动其他）。
- 直线对称式中分量为 0 时直接约去（应按参数式理解，如 m=0 则 x=x₀）。
- 求夹角用余弦忘取绝对值（线面角要的是 sin 的绝对值）。

## 要点回顾
1. 一切位置关系（平行/垂直/夹角/距离）归结为两个向量：n 与 s。
2. 叉积是"制造垂直向量"的机器：已知两向量求法向/方向必用它。
3. 旋转曲面＋柱面＋二次曲面库是后面读题识图的词典。
4. 投影（消元）是十、十一章确定积分区域的日常操作。
