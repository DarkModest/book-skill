## 关键定义（按教材表述）
- **微分方程**：含未知函数及其导数的方程；**阶**：最高阶导数的阶数。
- **解/通解/特解**：满足方程的函数；含独立任意常数个数＝方程阶数的解为通解；满足初始条件的为特解。

## 一阶方程四大类型（识别→代换/公式）
1. **可分离变量**：g(y)dy = f(x)dx ⟹ 两边积分。
2. **齐次方程** dy/dx = φ(y/x)：令 u=y/x，化为 x·du/dx = φ(u)−u（可分离）。
3. **一阶线性** dy/dx + P(x)y = Q(x)：
   - Q≡0 齐次线性（可分离）；
   - **通解公式** y = e^{−∫P dx}[∫Q e^{∫P dx}dx + C]——记结构：积分因子 e^{∫P} 乘两边凑 (ye^{∫P})′=Qe^{∫P}。
4. ***伯努利方程** y′+P(x)y = Q(x)yⁿ (n≠0,1)：令 z=y^{1−n} 化线性。
（*可化为齐次的方程：y′=(ax+by+c)/(a₁x+b₁y+c₁) 平移原点。）

## 可降阶三型
- y^{(n)}=f(x)：连续积分 n 次。
- y″=f(x, y′)：令 p=y′，p′=f(x,p)——缺 y。
- y″=f(y, y′)：令 p=y′，y″=p·dp/dy——缺 x（注意链式：y″ = dp/dx = (dp/dy)·(dy/dx) = p dp/dy）。

## 高阶线性方程解的结构（本章理论核心）
- 齐次解集合线性空间：n 阶齐次通解＝n 个线性无关解的线性组合。
- **非齐次通解 = 对应齐次通解 Y + 非齐次任一特解 y\***。
- **叠加原理**：f = f₁+f₂ 时 y\* = y₁\*+y₂\*。
- 两个解线性无关判别：之比不为常数（朗斯基思路）。

## 常系数方程（考试主力）
### 齐次：特征方程 r²+pr+q=0
| 特征根 | 通解 |
|---|---|
| 两不等实根 r₁≠r₂ | y = C₁e^{r₁x} + C₂e^{r₂x} |
| 二重根 r | y = (C₁+C₂x)e^{rx} |
| 共轭复根 α±βi | y = e^{αx}(C₁cos βx + C₂sin βx) |

n 阶同理（k 重根乘 x^{k}，复根取对）。
### 非齐次待定系数法（设特解表，必须带 x^k 修正）
- f(x) = e^{λx}P_m(x)：设 y\* = x^k·e^{λx}·Q_m(x)，Q_m 与 P_m 同次（系数待定），**k = λ 作为特征根的重数**（不是根 k=0，单根 k=1，二重根 k=2）。
- f(x) = e^{λx}[P_l(x)cos ωx + P_n(x)sin ωx]：设 y\* = x^k·e^{λx}[R_m(x)cos ωx + S_m(x)sin ωx]，m=max(l,n)，**λ+iω 是特征根时 k=1，否则 k=0**。
- *欧拉方程 x²y″+pxy′+qy=f(x)：令 x=e^t（记 D=d/dt：x²y″=D(D−1)y…）化常系数。

## 经典型例
- y″−5y′+6y=xe^{2x}：特征根 2,3；λ=2 为单根 ⟹ y\*=x(ax+b)e^{2x}。
- y″+y = x cos x：λ+iω=i 是根 ⟹ y\*=x[(ax+b)cos x+(cx+d)sin x]。
- y′ = y/x + tan(y/x)：齐次方程代 u=y/x。
- dy/dx − y/x = x²：一阶线性，积分因子 e^{−ln x}=1/x，通解 y = x³/4 + Cx。
- 弹簧振动/RLC 电路模型：m x″ + c x′ + kx = F(t)（欠阻尼 e^{−δt}sin…）。

## 常见错误
- 非齐次特解漏乘 x^k（重根/共轭根时与齐次解线性相关，代入恒为零）。
- 伯努利代换 z=y^{1−n} 后忘了换回 y。
- y″=f(y,y′) 型令 p=y′ 后把 y″ 写成 p′（须 p·dp/dy）。
- 通解任意常数个数≠方程阶数（丢常数或常数相关）。
- cos 型特解只设 cos 项（须 cos、sin 都设——教材强调 R、S 两个多项式）。

## 要点回顾
1. 一阶方程解题＝识别类型（可分离/齐次/线性/伯努利）＋代换化归。
2. 线性结构定理（齐次通解+特解）是理解一切高阶解法的框架。
3. 特征方程把常系数齐次方程变成代数问题；待定系数表是机械操作。
4. 初始条件定常数放最后；应用题先建方程（几何/物理规律）再解。
