# 第六章 定积分的应用（上册 书页 267–288）

## 元素法（核心方法，按教材四步表述）
以曲边梯形面积为例：(1) 分割区间 [a,b] 成小区间 Δx_i；(2) 取近似 ΔA_i ≈ f(ξ_i)Δx_i；(3) 求和 A ≈ Σf(ξ_i)Δx_i；(4) 取极限 A = ∫_a^b f(x)dx。
实用写法：若所求量 U 对区间可加、且部分量 ΔU ≈ f(x)dx（差是 dx 的高阶无穷小），则 dU = f(x)dx，U = ∫_a^b f(x)dx。**关键是选对积分变量、写对元素**。

## 几何应用公式表
- **平面图形面积**：
  - 直角坐标：A = ∫_a^b |f(x)−g(x)|dx（上减下）；对 y 积分同理。
  - 参数方程 x=x(t), y=y(t)（x′≥0）：A = ∫_{t₁}^{t₂} y(t)x′(t)dt。
  - 极坐标：A = ½∫_α^β r²(θ)dθ（β≥α）。
- **体积**：
  - 旋转体（绕 x 轴，圆盘法）：V = π∫_a^b y²(x)dx；绕 y 轴（区域在右侧）V = π∫_c^d x²(y)dy。
  - **已知平行截面面积**：V = ∫_a^b A(x)dx——一切立体体积的母公式（旋转体是其特例 A=πr²）。
- **平面曲线弧长**（ds 元素）：
  - 直角坐标 y=y(x)：s = ∫_a^b √(1+y′²)dx；
  - 参数式：s = ∫_{t₁}^{t₂} √(x′²(t)+y′²(t))dt；
  - 极坐标：s = ∫_α^β √(r²+r′²) dθ。
  （圆周长 2πR 是各公式的检验器。）

## 物理应用
- **变力沿直线做功**：W = ∫_a^b F(x)dx（弹力 ½kx² 是标准例）。
- **水压力**：P = ∫ ρg·x·|2y(x)|dx——深度 x 处水平窄条，压强 ρgx 乘条面积；坐标原点常取水面或水底。
- **引力**：细棒对质点引力，元素 dF = k·(dm·M)/r²，**方向不同须分解投影后积分**（不能直接标量相加）。

## 经典型例
- y=x² 与 y=2x 围成面积 ＋ 绕 x 轴/y 轴旋转体体积（交点 0,2；V_x=16π/15 型）。
- 摆线一拱 x=a(t−sin t), y=a(1−cos t) 与 x 轴围面积 3πa²，弧长 8a，绕 x 轴旋转体积 5π²a³——三大公式一次练全。
- 心形线 r=a(1+cosθ) 全长 8a（极坐标弧长对称性减半）；面积 3πa²/2。
- 水坝闸门矩形＋半圆组合水压力；抽水做功 ∫ρg·(深度函数)·A(y)dy。

## 常见错误
- 极坐标面积忘 ½；θ 范围取错（心形线是 0~2π 或对称取 0~π）。
- 弧长公式中被积函数 √(1+y′²) 写成 1+y′² 或丢根号。
- 绕 y 轴旋转用 π∫y²dx（张冠李戴：绕 x 轴才对）。
- 引力做功/水压力中把矢量当标量相加。
- 元素法中 f(x)dx 与 dU 差高阶无穷小未验证（区域不规则时容易错切分）。

## 要点回顾
1. 元素法四步是通用模板，公式都可用它现场推导——比背公式更可靠。
2. 体积母公式是"截面面积积分"；旋转体只是截面为圆的特例。
3. 弧长三公式对应三种坐标表达，本质都是 ds。
4. 物理量先写元素（力/功/压强元），再统一积分；矢量量必须投影。
