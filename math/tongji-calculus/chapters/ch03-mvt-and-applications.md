## 核心定理（按教材表述）
- **费马引理**：f 在 x₀ 可导且取极值 ⟹ f′(x₀)=0。导数为零的点称**驻点（稳定点、临界点）**。
- **罗尔定理**：f 满足 ①在 [a,b] 连续 ②在 (a,b) 可导 ③f(a)=f(b)，则 ∃ξ∈(a,b) 使 f′(ξ)=0。（证明：闭区间连续取最值＋费马引理。）
- **拉格朗日中值定理（有限增量定理）**：①②成立（去掉③），则 ∃ξ 使 f(b)−f(a)=f′(ξ)(b−a)。推论：f′≡0 ⟹ f 为常数；f′=g′ ⟹ f=g+C。
- **柯西中值定理**：再加 F′≠0，∃ξ 使 [f(b)−f(a)]/[F(b)−F(a)] = f′(ξ)/F′(ξ)（两个函数共用一个 ξ——这是与分别用两次拉格朗日的本质区别）。
- 三定理关系：罗尔 ⊂ 拉格朗日 ⊂ 柯西（柯西中令 F(x)=x 即拉格朗日）。
- **洛必达法则**：0/0 或 ∞/∞ 型，且 lim f′/F′ 存在（或∞），则 lim f/F = lim f′/F′。**用前必须验证是未定式；分子分母分别求导，不是商法则**。
- **泰勒中值定理**：f 在 x₀ 处 n 阶可导邻域内 n+1 阶可导，则 f(x)=f(x₀)+f′(x₀)(x−x₀)+…+f^{(n)}(x₀)/n!(x−x₀)ⁿ + R_n(x)。
  - **拉格朗日余项**：R_n = f^{(n+1)}(ξ)/(n+1)!·(x−x₀)^{n+1}（介于 x₀ 与 x 之间）——定量误差；
  - **佩亚诺余项**：R_n=o((x−x₀)ⁿ)——求极限用。
  - x₀=0 时称**麦克劳林公式**。
- 常用麦克劳林展开（求极限五件套，记住阶数）：
  e^x = 1+x+x²/2!+…+xⁿ/n!+o(xⁿ)；sin x = x−x³/3!+x⁵/5!−…；cos x = 1−x²/2!+x⁴/4!−…；ln(1+x) = x−x²/2+x³/3−…； (1+x)^α = 1+αx+α(α−1)/2!·x²+…；1/(1−x) = 1+x+x²+…；tan x = x+x³/3+o(x³)。
- **极值第二充分条件**：f′(x₀)=0 且 f″(x₀)≠0 ⟹ x₀ 为极值（f″<0 极大，>0 极小；f″=0 失效，退回一阶判别）。

## 单调、凹凸与作图
- 单调性判定：区间内 f′>0 单增，f′<0 单减（个别点为零不影响）。
- **凹凸性**：f″>0 凹（concave up，定义：弦在弧上方/切线在弧下方判别相反），f″ 变号点为**拐点**（拐点是曲线上的点 (x₀,f(x₀))，不是横坐标）。
- **渐近线**：水平 lim_{x→∞} f=A；垂直 lim_{x→x₀} f=∞（x₀ 常为分母零点）；斜 k=lim f(x)/x，b=lim[f(x)−kx]（可去/斜渐近线为第八版总习题一内容，配合作图）。
- **作图程序**：定义域→奇偶周期对称→间断点→单调区间与极值（f′ 符号表）→凹凸与拐点（f″ 符号表）→渐近线→描点连线。
- **曲率**：弧微分 ds=√(1+y′²)dx；K=|y″|/(1+y′²)^{3/2}；曲率半径 ρ=1/K。*曲率中心、渐屈线与渐伸线。
- *方程近似解：二分法、切线法（牛顿）、割线法。

## 证明题构造方法（中值定理选型决策）
- 结论只含 f′(ξ)=0 且端点等值 ⟹ 罗尔。
- 结论 f(b)−f(a)=f′(ξ)(b−a) ⟹ 拉格朗日。
- 两个函数比、且同一 ξ ⟹ 柯西（选好 F）。
- 结论含 ξ 的复杂式 ⟹ **构造辅助函数用罗尔**：把等式化成"某函数在 a、b 等值"的形式。常用构造乘子：e^{kx}、xⁿ、(x−a)(x−b)；常见原函数配对：f+xf′ → (xf)′；f′/f → (ln f)′；f′g−fg′ → (f/g)′ 或 (f·g′−…)。
- 双中值 ξ、η ⟹ 分区间用两次中值定理（常用 a、c 与 c、b 两段）。
- 不等式证明三板斧：①单调性（移项构造 F，F(a)=0，看 F′）②拉格朗日（放缩 ξ）③泰勒（在极值点/端点展开）。

## 经典型例
- 设 0<a<b，证 a/b < ln b − ln a 之 (b−a)/b 形式不等式（拉格朗日＋放缩 1/ξ）。
- lim_{x→0} (tan x − sin x)/x³：等价替换失效教训——用泰勒：tan x=x+x³/3+o，sin x=x−x³/6+o，差=x³/2，答案 ½。
- lim_{x→+∞} x^{3/2}√(x−1)−… 型：提取首项＋泰勒。
- 求 y=(2x−1)e^{1/x} 的斜渐近线（k=2, b=1；见总习题一第14题渐近线判定充要条件）。
- 曲线 y=x² 在任意点的曲率与最值（K 在顶点最大 2）。

## 常见错误
- 洛必达求导后不检查仍是 0/0 或 ∞/∞；对数函数放分子而不化简；与等价替换混用出错。
- 认为柯西定理可拆成两个拉格朗日相除——两次的 ξ 未必相同。
- 极值点必须先有定义；驻点≠极值点（y=x³），极值点也可能在不可导点（y=|x|）。
- 拐点写成 x₀ 而非点 (x₀,f(x₀))；f″=0 且不变号不是拐点（y=x⁴）。
- 泰勒展开阶数不够：加减抵消后首项为 0，须展到首个非零项。

## 要点回顾
1. 中值定理是"导数信息⟹函数信息"的唯一桥梁，f′>0 ⟹ 单增正依赖于此。
2. 洛必达是未定式算法，泰勒是万能算法：泰勒能做洛必达做不动的（如 x−sinx 高阶）。
3. 作图是单调+凹凸+渐近线的系统集成。
4. 曲率把"弯的程度"量化，铁路弯道设计即其应用。
