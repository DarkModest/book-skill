# 第九章 多元函数微分法及其应用（下册 书页 52–129）

## 关键定义（按教材表述）
- **平面点集**：邻域 U(P₀,δ)、内点/边界点/聚点、开（闭）区域、有界域。
- **多元函数**：设 D⊂R²，映射 f: D→R，记 z=f(x,y)。二元函数图形是曲面。
- **二重极限**：∀ε>0，∃δ>0，P∈D∩Û(P₀,δ) 时 |f(P)−A|<ε。**P 以任何方式趋近极限唯一**——沿不同路径得不同极限 ⟹ 极限不存在（判不存在利器：沿 y=kx 代入含 k ⟹ 不存在）。
- **连续**：lim_{P→P₀} f(P)=f(P₀)；多元初等函数在定义区域内连续。有界闭区域上连续 ⟹ 有最值（+介值）。
- **偏导数**：∂z/∂x = lim_{Δx→0}[f(x₀+Δx,y₀)−f(x₀,y₀)]/Δx——**固定其余变量的一元求导**；几何意义：曲面被 x=x₀ 截出的曲线在该点的切线对 x 轴斜率。
- **全微分**：若 Δz = AΔx+BΔy + o(ρ)（ρ=√(Δx²+Δy²)），则可微，dz = z_x dx + z_y dy。
- **概念链（必须背牢）**：偏导连续 ⟹ 可微 ⟹ {偏导存在，连续}；各箭头**均不可逆**；可微 ⟹ 偏导存在但连续不保证。判可微：定义式 lim [Δz−(z_xΔx+z_yΔy)]/ρ = 0。

## 求导法则
- **多元复合链式法则**：画链路图，"沿线相乘、分线相加"。z=f(u,v), u=u(t), v=v(t)：dz/dt = z_u·u′+z_v·v′；z=f(u,v), u=u(x,y), v=v(x,y)：z_x = z_u·u_x + z_v·v_x。**全微分形式不变性**：无论 uv 是否自变量，dz = z_u du + z_v dv——复合与隐函数统一语言。
- **隐函数求导**：
  - F(x,y)=0：dy/dx = −F_x/F_y；
  - F(x,y,z)=0：∂z/∂x = −F_x/F_z，∂z/∂y = −F_y/F_z；
  - 方程组：对每个方程两边求导（视各因变量为函数），解线性方程组（或用雅可比行列式公式）。

## 几何应用
- **空间曲线 Γ: x=x(t),y=y(t),z=z(t)**：切向量 T=(x′,y′,z′)；切线 (x−x₀)/x′ = (y−y₀)/y′ = (z−z₀)/z′；法平面：以 T 为法向量。
- **曲面 F(x,y,z)=0**：法向量 n=(F_x,F_y,F_z)；切平面 F_x(x−x₀)+F_y(y−y₀)+F_z(z−z₀)=0；法线：以 n 为方向向量。z=f(x,y) 时 n=(f_x, f_y, −1)。
- **方向导数**：∂f/∂l = lim_{t→0⁺}[f(x₀+t cosα, y₀+t cosβ)−f(x₀,y₀)]/t；可微时 = f_x cosα + f_y cosβ。
- **梯度**：grad f = (f_x, f_y)（三元加 f_z）。**梯度的方向 = 方向导数最大（增长最快）的方向，模 = 最大方向导数**；与等值线（面）法向平行。方向导数 = 梯度在该方向投影。

## 极值
- **必要条件**：f_x(P₀)=f_y(P₀)=0（驻点；偏导不存在的点也可能是极值点，如 z=√(x²+y²)）。
- **充分条件**：A=f_xx, B=f_xy, C=f_yy 于 P₀：AC−B²>0 有极值（A<0 极大，A>0 极小）；<0 无极值；=0 失效（另判）。
- **条件极值（拉格朗日乘数法）**：求 f 在 φ(x,y)=0 下的极值，令 L(x,y,λ) = f(x,y) + λφ(x,y)，解 L_x=L_y=L_φ=0。多个约束加多个 λ。
- **最值**：比较内部驻点值＋边界（代入约束化一元或拉格朗日）。

## 经典型例
- 证 lim_{(x,y)→(0,0)} (x·y)/(x²+y²) 不存在（沿 y=kx 得 k/2）。
- z = x^y：∂z/∂x = y·x^{y−1}，∂z/∂y = x^y ln x（不同变量身份不同）。
- u=f(x²y, y/x) 全套链式求偏导（引入中间记号 1、2 号位置）。
- 求椭球面 x²/4+y²/4+z²=1 在点 (1,1,√(1/2)) 的切平面。
- 表面积一定（周长一定）求最大体积：拉格朗日乘数法经典（长方体变正方体）。
- 函数 f=x³+y³−3xy 驻点分类：AC−B² 判别。

## 常见错误
- 二重极限乱用洛必达/等价替换（一元工具不能整体套用；须化为固定路径的一元）。
- 把"偏导数存在"当"可微"或当"连续"。
- 链式法则漏项（f 对中间变量再对自变量——抽象函数 f(u,v) 的二阶偏导：f₁′ 与 f₂′ 仍是复合函数，再求导须再走链）。
- 隐函数公式分母张冠李戴（∂z/∂x = −F_x/F_z，分母是 F_z 不是 F_y）。
- 切平面法向量对 z=f(x,y) 写成 (f_x, f_y, 1)（正确 (f_x, f_y, −1)）。
- 拉格朗日乘数法忘写约束方程进方程组。

## 要点回顾
1. 概念链"偏导连续⟹可微⟹连续+偏导存在"是本章理论之魂，考试考反例。
2. 链式法则口诀：沿线相乘、分线相加；全微分形式不变性是隐函数求导的保险箱。
3. 几何三件套（切线/法平面、切平面/法线、方向导数/梯度）全是"向量=导数向量"。
4. 极值两步走：驻点扫雷（AC−B²）＋边界约束（拉格朗日）；应用题最后比较所有候选点。
