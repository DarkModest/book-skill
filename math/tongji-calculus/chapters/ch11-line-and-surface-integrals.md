# 第十一章 曲线积分与曲面积分（下册 书页 180–240）

## 本章地位
积分区域的最终推广：数轴区间→曲线弧→曲面片。两条主线：第一类（无向，标量密度积分：线密度/面密度质量）与第二类（有向，矢量场通量/做功）。三大公式（格林、高斯、斯托克斯）把曲线/曲面积分化归重积分——是牛顿-莱布尼茨公式的高维推广。

## 两类曲线积分
- **第一类（对弧长）∫_L f(x,y)ds**：物理原型曲线形构件质量（线密度 μ）。性质无方向（L 的方向不影响）。计算：ds = √(1+y′²)dx = √(x′²+y′²)dt（L: x=x(t),y=y(t), t 从 α 到 β，**必须 α<β**）。三维同理 ds=√(x′²+y′²+z′²)dt。
- **第二类（对坐标）∫_L P dx + Q dy**：物理原型变力沿曲线做功。**方向敏感**：∫_{L⁻} = −∫_L。计算：把 x、y 都代成路径参数化（x=φ(t), y=ψ(t), dx=φ′dt），t 从起点到终点（**起点→终点决定上下限，可 α>β**）。
- **两类联系**：∫P dx+Q dy = ∫(P cosα + Q cosβ)ds，(cosα,cosβ) 为切向量方向余弦。

## 格林公式（平面第二类积分核心）
- **格林公式**：闭区域 D 由分段光滑闭曲线 L 围成，P、Q 及其一阶偏导在 D 上连续，则
  ∮_L P dx + Q dy = ∬_D (∂Q/∂x − ∂P/∂y) dxdy，**L 取正向**（沿 L 前进 D 在左手边）。
- **路径无关四等价**（G 单连通、P Q 连续可导）：∫_L Pdx+Qdy 与路径无关 ⇔ 沿任意闭线积分为零 ⇔ ∂P/∂y = ∂Q/∂x 恒成立 ⇔ Pdx+Qdy 是某函数 u 的全微分（u 称原函数，可线积分求 u）。
- **奇点技巧**：∂P/∂y=∂Q/∂x 在挖去奇点的复连通域内成立时，绕奇点的任两闭线积分相等（经典 (−y dx + x dy)/(x²+y²)：绕原点任一周 = 2π）。
- **补线法**：非闭曲线用格林 → 补直线段成闭，减去补线上的积分。
- 计算策略排序：路径无关化简 > 格林公式 > 直接参数化。

## 两类曲面积分
- **第一类（对面积）∯_Σ f dS**：面密度质量。计算：Σ: z=z(x,y) 时 dS = √(1+z_x²+z_y²)dxdy，投影到 xOy（可投影到任两变量坐标面，选不含垂面的）。无方向。
- **第二类（对坐标）∯ P dydz + Q dzdx + R dxdy**：流量场通过曲面的通量。**方向敏感**：取上侧时 dxdy 为正，下侧为负（yOz 面前侧正…）。
- **两类联系**：∯(P cosα + Q cosβ + R cosγ)dS = 第二类（(cosα,cosβ,cosγ) 为指定侧法向量余弦）。

## 高斯公式与斯托克斯公式
- **高斯公式**：空间闭区域 Ω 由闭曲面 Σ 围成（P,Q,R 有连续偏导）：
  ∯_Σ P dydz + Q dzdx + R dxdy = ∭_Ω (∂P/∂x + ∂Q/∂y + ∂R/∂z) dV，**Σ 取外侧**。
  - **补面法**：曲面不闭时补平面片成闭，减去补面积分。奇点（如 1/(x²+y²+z²) 场）同格林要挖球。
- **斯托克斯公式**：闭曲线 Γ 张在曲面 Σ 上：
  ∮_Γ P dx + Q dy + R dz = ∬_Σ 行列式(dyd z 分量形式)…… = ∬_Σ (∂R/∂y−∂Q/∂z)dydz + (∂P/∂z−∂R/∂x)dzdx + (∂Q/∂x−∂P/∂y)dxdy，Γ 与 Σ 侧符合右手法则。平面回路常退化为格林公式。
- ***通量与散度**：div A = ∂P/∂x+∂Q/∂y+∂R/∂z（源强度）；*环流量与旋度 rot A = 行列式(i,j,k; ∂x,∂y,∂z; P,Q,R)。

## 经典型例
- ∮_L (x+y)²dx − (x²+y²)dy，L 为圆周正向（格林：被积偏导差 = 2(x+y)−(−2y) = 2x+4y，再由对称性 ∬2x=0…）。
- ∫_L 2xy dx + x² dy 从 (0,0) 到 (1,1)：验证 ∂Q/∂x=2x=∂P/∂y ⟹ 路径无关，沿折线 = 1。
- 求 I=∯_Σ x dydz+y dzdx+z dxdy，Σ 为球面外侧：高斯 ∭3dV = 4πR³（体积的速算法）。
- 曲线积分求柱面侧面积：∫(z 边界函数)ds。
- 流体穿过曲面的流量：第二类曲面积分定义题。

## 常见错误
- 格林/高斯忘记验证**闭性、方向、连续性三条件**；非闭不补线/补面直接用。
- 补面/补线后忘减去其积分；方向取反（外侧/正向）。
- 第一类曲线积分参数限写成"起点到终点"（必须小到大）与第二类混淆。
- 第二类曲面积分投影的正负号丢掉（下侧/后侧时）。
- 奇点在区域内时套公式（须挖去再对挖出的闭线用）。
- dS 写成 dxdy（丢 √(1+z_x²+z_y²) 因子）。

## 要点回顾
1. 先判"有向无向"：密度→第一类 ds/dS；做功/流量→第二类（方向敏感）。
2. 第二类积分的解题优先级：找原函数（路径无关）→ 补线/补面用格林/高斯 → 直接参数化。
3. 三大公式统一结构：线/面积分 = 内部区域上的"微分算子"积分，是高维牛顿-莱布尼茨。
4. 方向规则两句话：平面取逆时针（正向），空间取外侧（右手系）。
