## 核心框架与心智模型

### 一条主线：极限
- **全书统一模式"分割—近似—求和—取极限"**：定积分（ch5）、变力做功（ch6）、重积分（ch10）、线面积分（ch11）、级数（ch12）全是它的高维/无穷版本——认出这个模式，新定义就不再陌生。
- **ε-δ / ε-N 语言**：极限、连续、一致连续、收敛的全部严谨性基础（ch1）。
- **求极限决策**：先代入→不定式才选方法：化简/等价替换（只动乘除）/两个重要极限/夹逼/泰勒/洛必达（ch1, ch3）。

### 概念链（一元 vs 多元）
- 一元：可导 ⟹ 连续；**可微 ⟺ 可导**（ch2）。
- 多元：偏导连续 ⟹ 可微 ⟹ 连续＋偏导存在，**箭头均不可逆**；"可微"取代"可导"成为中心（ch9）。
- 二重极限"沿任何路径唯一"；沿 y=kx 代入含 k ⟹ 不存在（ch9）。

### 中值定理链：从导数回到函数
- 费马引理 → 罗尔 → 拉格朗日 → 柯西 → 泰勒（含拉格朗日余项/佩亚诺余项），条件逐层放宽、结论逐层加强（ch3）。
- 用 f′ 的符号研究 f：单调、极值（AC−B² 判别在 ch9）、凹凸拐点、渐近线、作图（符号表格法）。
- 证明题套路：凑原函数用罗尔（乘 e^{kx}、xⁿ）；不等式三板斧：单调性/中值放缩/泰勒。

### 微积分基本定理及其推广链
- 变上限积分求导 Φ′=f（连续⟹有原函数）→ 牛顿-莱布尼茨 ∫_a^b f = F(b)−F(a)（ch5）。
- 同一思想的高维推广：**格林**（线积分→二重）→ **斯托克斯**（空间线积分→曲面积分）→ **高斯**（曲面积分→三重）——右端都是"内部区域上的微分算子积分"（ch11）。
- 非闭就补线/补面，有奇点就挖去。

### 积分计算总策略：化归
- 不定积分：凑微分 → 分部（反对幂三指）→ 三角/根式代换 → 部分分式（ch4）。
- 重积分：选次序（X/Y 型、先一后二/先二后一）+ 换坐标（极坐标 r、柱坐标 r、球坐标 r²sinφ 因子）+ 对称性瘦身（ch10）。
- 应用一律**元素法**：dU = f·(微元) → 积分（面积/体积/弧长/功/压强/引力，ch6；曲面面积/质心/转动惯量，ch10）。

### 微分方程：识别即解题
- 一阶四型：可分离 → 齐次（u=y/x）→ 线性（积分因子 e^{∫P}）→ 伯努利（z=y^{1−n}）（ch7）。
- 高阶：可降阶三型（缺 y / 缺 x 用 p）；常系数 → 特征方程三情形 + 待定系数（**特解勿忘 x^k 修正**）。
- 线性结构：非齐次通解 = 齐次通解 + 一个特解；叠加原理。

### 级数判敛体系
- 必要条件 lim uₙ=0（判发散第一武器）→ 正项级数：比较/比值/根式（p 级数为基准）；交错：莱布尼茨；定性：绝对收敛 ⊃ 条件收敛（ch12）。
- 与反常积分同构（p 积分 ↔ p 级数，ch5 ↔ ch12）。
- 幂级数：收敛半径 R=lim|aₙ/aₙ₊₁|，端点逐查；和函数靠逐项求导/积分；展开靠五件套间接合成。
- 傅里叶：系数是公式积分；间断点收敛于左右极限平均；奇偶延拓得正弦/余弦级数。

### 空间的语言（ch8 工具箱）
- 一切位置关系归结为两个向量：法向量 n 与方向向量 s；**叉积是制造垂直向量的机器**。
- 旋转曲面（同轴变量不动）、柱面（缺变量）、二次曲面（截痕法）；消元求投影是十、十一章定限的日常。
