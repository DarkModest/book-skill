# 速查决策表

## 极限求解决策树
```
求 lim
├─ 能直接代入 → 代入（连续函数）
├─ 数列/含 sin、取整、n! 求和 → 夹逼准则
├─ 递推数列 → 单调有界
├─ 未定式 0/0、∞/∞
│   ├─ 乘除因子含 sin、ln、e、幂差 → 等价无穷小替换
│   ├─ 相加减且替换失效 → 泰勒展开（展到首项不消）
│   └─ 结构清晰 → 洛必达（先验证类型，可迭代）
├─ ∞−∞ → 通分 / 有理化
├─ 1^∞ → e^{lim(指数)·(底−1)}
└─ x→∞ 分式 → 同除最高次项（首项主导）
```

## 间断点分类表
| 左右极限 | 类型 | 例 |
|---|---|---|
| 存在且相等 ≠f(x₀) | 可去（第一类） | sinx/x 在 0 |
| 存在但不等 | 跳跃（第一类） | sgn x 在 0 |

## 中值定理选型
| 已知条件 | 用 | 结论 |
|---|---|---|
| 闭连续+开可导+f(a)=f(b) | 罗尔 | ∃ξ f′(ξ)=0 |
| 闭连续+开可导 | 拉格朗日 | f(b)−f(a)=f′(ξ)(b−a) |
| 两函数同上且 F′≠0 | 柯西 | 共用同一 ξ 的增量比 |
| 高阶导数信息/高阶展开 | 泰勒 | 带 Rₙ 的展开式 |
证明含 ξ 等式：凑原函数用罗尔（乘 e^{kx}、xⁿ，或 (xf)′=f+xf′ 类配对）。

## 积分方法决策树
```
∫f(x)dx
├─ 表内形状 → 基本公式（改写：拆项、三角恒等、加减项）
├─ 复合结构 f(□)·□′ → 凑微分（第一类换元）
├─ 两类函数相乘 → 分部（u 选：反、对、幂、三、指 排前者）
│   └─ 循环出现 → 两次分部后解方程
├─ 根式 √(a²−x²)/√(a²+x²)/√(x²−a²) → 三角代换 sin/tan/sec
├─ ⁿ√(ax+b) → 根式代换 t=ⁿ√
├─ 有理分式 → 部分分式（假分式先除）
└─ 三角有理式卡壳 → 万能代换 t=tan(x/2)
```

## 微分方程类型识别表（一阶）
| 形状 | 类型 | 解法 |
|---|---|---|
| g(y)dy=f(x)dx | 可分离 | 两边积分 |
| y′=φ(y/x) | 齐次 | u=y/x |
| y′+P(x)y=Q(x) | 一阶线性 | e^{∫P} 积分因子 / 通解公式 |
| y′+P(x)y=Q(x)yⁿ (n≠0,1) | 伯努利 | z=y^{1−n} |
高阶：可降阶三型（缺 y / 缺 x 用 p）；常系数→特征方程+待定系数（特解勿忘 x^k）。

## 特解形式速查（y″+py′+qy=f(x)）
| f(x) | 设 y\* |
|---|---|
| e^{λx}Pₘ(x) | x^k·e^{λx}·Qₘ(x) |
| e^{λx}[P cosωx + Q sinωx] | x^k·e^{λx}[R cosωx + S sinωx] |
k = λ（或 λ+iω）作为特征根的重数：非根 0，单根 1，重根 2。

## 级数审敛决策链
```
Σuₙ
├─ lim uₙ ≠ 0 → 发散（必要条件）
├─ 交错 Σ(−1)ⁿuₙ
│   ├─ uₙ 单调减→0 → 莱布尼茨收敛；再判 Σ|uₙ| 定"绝对/条件"
│   └─ 否则 拆项/绝对值级数判敛
└─ 正项
    ├─ 几何/等比形状 → 公式 |q|<1
    ├─ 含 n!、nⁿ、aⁿ → 比值判别
    ├─ ⁿ√uₙ 好算 → 根式判别
    ├─ 像 1/nᵖ → 比较判别（极限形式）：p>1 收敛
    └─ ρ=1 失效 → 泰勒看阶/比较改造
幂级数：R=lim|aₙ/aₙ₊₁| → 内部绝对收敛 → 端点逐查
```

## 多元积分坐标系选择
| 信号 | 坐标 | 微元 |
|---|---|---|
| 圆/环/扇域；含 x²+y² | 极坐标 | r dr dθ |
| 圆柱域；含 x²+y²（三维） | 柱坐标 | r dr dθ dz |
| 球域；含 x²+y²+z² | 球坐标 | r² sinφ dr dφ dθ |
| f 只含 z | 截面法 | ∫dz ∬_{D_z} |

## 三大公式使用条件
| 公式 | 把什么化成什么 | 前提 |
|---|---|---|
| 格林 | 闭曲线线积分 → 二重积分 | 闭路正向、P Q 一阶偏导连续 |

## 常用结论速记
- 等价无穷小：sinx~tanx~arcsinx~x；1−cosx~x²/2；e^x−1~x；ln(1+x)~x；(1+x)^α−1~αx
- p 基准：∫₁^∞/Σ：p>1 收敛；∫₀¹：p<1 收敛（方向相反）
- Wallis：∫₀^{π/2}sinⁿx dx = (n−1)!!/n!!（n 偶再乘 π/2）
- 麦克劳林：e^x、sin x、cos x、ln(1+x)、(1+x)^α、1/(1−x)（五章展开）
- 两个重要极限：sinx/x→1（x→0）；(1+1/x)^x→e（x→∞）
- 收敛域端点必查；间断点傅里叶和 = 左右极限平均
- 欧拉公式：e^{iθ}=cosθ+i sinθ
