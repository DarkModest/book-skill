# 方法库（何时用 / 怎么做 / 注意）

## 极限类
**首项主导** — 何时：∞/∞ 多项式比值。怎么做：同除最高次项。注意：含根号除以 x 时分情况 x→±∞（|x|）。
**有理化** — 何时：∞−∞ 含根式。怎么做：乘共轭因式。注意：通分也是有理化替代。
**等价无穷小替换** — 何时：0/0 乘除因子。怎么做：替换表（sinx~x, 1−cosx~x²/2, e^x−1~x, ln(1+x)~x, (1+x)^α−1~αx）。注意：**加减项禁用**。
**重要极限凑形** — 何时：sin(□)/□ 或 (1+□)^{◇}。怎么做：把 □ 整体看成 x。注意：1^∞ 用 e^{lim ◇·ln(1+□)}，等价于 ◇·□ 取极限。
**夹逼准则** — 何时：n!、sin、取整、求和式极限。怎么做：放缩两侧到同极限。注意：放缩适度，勿把目标夹丢。
**泰勒求极限** — 何时：加减抵消后仍 0/0、等价替换失效。怎么做：各函数展到使相减后首项非零的阶。注意：常用 tan x = x+x³/3+o(x³)。
**洛必达化归链** — 何时：未定式。怎么做：0·∞ → 商式；1^∞,0⁰,∞⁰ → 取对数 e^□。注意：先验证类型；可导性要求；比值的极限必须存在。

## 导数应用类
**符号表格作图法** — 何时：描绘函数图形。怎么做：f′ 零点分区标号得单调极值，f″ 分区得凹凸拐点，加渐近线。注意：不可导点也是分区点。
**渐近线三查** — 怎么做：垂直查分母零点（左右极限∞）；水平/斜查 x→±∞（有水平无斜）。注意：k=lim f/x、b=lim(f−kx) 两步都要算。
**中值证明构造表** — 何时：证存在 ξ 的等式。怎么做：目标式凑成某函数导数零点——f+xf′→(xf)′，f′g−fg′→(f/g)′，f′/f→(ln f)′，含 e^{kx} 乘子对应移项系数。注意：条件选罗尔/拉格朗日/柯西。
**双中值分段法** — 何时：结论含 ξ、η 两点。怎么做：插入分点分两区间各用一次中值定理。注意：分点常取中点或区间比。
**不等式三板斧** — 何时：函数/积分不等式。怎么做：①移项构造 F 用单调性 ②拉格朗日放缩 ξ ③泰勒在端点/极值点展开。注意：定积分不等式可再用估值/中值定理。
**曲率速算** — 怎么做：K=|y″|/(1+y′²)^{3/2}。注意：参数式先化 d²y/dx²。

## 积分类
**凑微分表** — 何时：被积函数有复合结构。怎么做：x dx=½d(x²)、dx/x=d(lnx)、e^x dx=de^x、sinx dx=−d cosx、sec²x dx=d tanx、dx/√x=2d√x、f′dx=df。注意：凑后变量替换要还原。
**三角代换三型** — 何时：根式。√(a²−x²)→x=asint；√(a²+x²)→x=atant；√(x²−a²)→x=asect。注意：回代画辅助三角形；定积分则换限。
**分部选 u（反对幂三指）** — 何时：两类不同函数相乘。怎么做：反三角/对数选 u，指数/三角选 dv。注意：循环型（e^x·sinx、e^x·cosx）两次分部后解方程。
**部分分式流程** — 何时：有理函数。怎么做：假分式→多项式+真分式→分母因式分解→设 A/(x−a)、B/(x−a)ⁿ、(Mx+N)/(x²+px+q)→待定系数。注意：二次因式幂次逐层设。
**万能代换** — 何时：三角有理式卡壳。怎么做：t=tan(x/2)，sin x=2t/(1+t²)，cos x=(1−t²)/(1+t²)，dx=2dt/(1+t²)。注意：优先找对称/恒等变形，万能代换是兜底。
**定积分对称性** — 何时：±a 区间、周期函数。怎么做：奇函数=0，偶函数减半；周期 ∫_a^{a+T}=∫_0^T。注意：被积函数必须整体对相应变量有奇偶性。
**Wallis 公式** — 何时：sinⁿ/cosⁿ 在 [0,π/2]。怎么做：(n−1)!!/n!! ×（n 奇补 1，n 偶补 π/2）。注意：tanⁿ 转化为 sinⁿ/cosⁿ 处理。
**变限积分求导** — 何时：被积函数积分不出或含上限变量。怎么做：d/dx∫_{φ}^{ψ}f = f(ψ)ψ′−f(φ)φ′。注意：上限变量出现在被积函数里先换元分离。

## 应用类
**元素法四步** — 何时：几何/物理量。怎么做：选变量定区间→写元素 dU→定上下限→积分。注意：元素是"均匀近似"。
**求交点定限** — 何时：面积/体积题。怎么做：联立曲线方程解交点得积分限。注意：画草图永远第一步。
**旋转体选轴** — 绕 x 轴 V=π∫y²dx；绕 y 轴 V=π∫x²dy（或 2π∫x·y dx 柱壳思想）。注意：区域在轴哪一侧、叠减空心部分。

## 微分方程类
**类型识别顺序（一阶）** — 可分离 → 齐次(y/x) → 线性 → 伯努利。注意：线性方程万能性最强，可代换转化。
**积分因子法** — 一阶线性 y′+Py=Q：乘 e^{∫P} 后 (ye^{∫P})′=Qe^{∫P}。注意：P 只看 dy 系数；通解公式可直接背用。
**可降阶三型** — y^{(n)}=f(x) 连续积分；缺 y 令 p=y′；缺 x 令 p=y′ 且 y″=p·dp/dy。注意：缺 x 型最易错。
**特征方程法** — r²+pr+q=0 → 三情形通解表。注意：n 阶同理，重根乘 xᵏ。
**待定系数修正因子 x^k** — f=e^{λx}Pₘ(x)：设 y\*=x^k e^{λx}Qₘ(x)；f=e^{λx}(Pcos+Qsin)：设 y\*=x^k e^{λx}(Rcos+Ssin)；k=λ(或 λ+iω) 是特征根的重数（0、1、2）。注意：cos/sin 都要设。

## 多元类
**链路图求偏导** — 复合函数画变量树：沿线相乘、分线相加。注意：抽象函数 f₁′、f₂′ 仍是复合函数，二阶偏导须再走链。
**隐函数公式** — F=0：∂z/∂x=−F_x/F_z（分母是"因变量对应"的偏导）。方程组逐个求导解线性组。
**求切平面/法线** — F 型 n=(F_x,F_y,F_z)；z=f(x,y) 型 n=(f_x,f_y,−1)。注意：先验证点在曲面上。
**二重积分换序** — 何时：先积的变量积不出。怎么做：由累次限反写区域不等式→画图→换序重写。注意：必须画图。
**极坐标信号** — 区域圆/环/扇，或函数含 x²+y²、y/x。怎么做：dxdy→r dr dθ。注意：r 因子。
**三重积分坐标系选择** — 球/含 x²+y²+z²→球坐标 r²sinφ；柱/含 x²+y²→柱坐标 r；长方体→直角。f 只含 z→截面法（先二后一）。
**对称性瘦身** — 区域对称+函数奇偶→消零或减半；区域轮换不变→I=⅓∭(x²+y²+z²)·…。注意：两个条件缺一不可。

## 线面积分类
**第一类/第二类判别** — 密度（质量/面积）→第一类无向；做功/流量→第二类有向。
**格林公式补线法** — 何时：非闭曲线第二类积分。怎么做：补直线段成闭→格林→减补线段积分。注意：闭路取正向。
**挖奇点** — 何时：P,Q 在区域内有奇点（如 /r² 场）。怎么做：挖去小圆/小球，对挖出的边界用公式。注意：小圆上直接参数化求积分。
**高斯补面法** — 何时：非闭曲面通量。怎么做：补平面片封口→高斯→减补面。注意：补面法向量取外侧一致。
**dS 投影因子** — z=z(x,y) 面：dS=√(1+z_x²+z_y²)dxdy。第二类：dxdy 带投影正负号（上侧正）。

## 级数类
**审敛决策链** — lim uₙ≠0→发散。正项：有 n!/aⁿ 结构→比值；ⁿ√ 好算→根式；像 1/nᵖ→比较/极限比较；ρ=1→改比较或看阶。交错：莱布尼茨（单调减→0）；同时判绝对收敛定性。
**收敛域三步** — 求 R（系数比）→ 内部绝对收敛 → 端点逐个用数项级数判敛。注意：答案写区间并集。
**逐项求导/积分求和函数** — 何时：Σxⁿ、Σxⁿ/n、Σn·xⁿ 类。怎么做：化为几何级数，导/积分还原，注意收敛半径不变、端点另验。
**间接展开四操作** — 从五个母展开出发：代换、四则、逐项求导、逐项积分。注意：写出收敛域。
**傅里叶奇偶延拓** — [0,π] 上函数：奇延拓→正弦级数；偶延拓→余弦级数。注意：系数只算半区间×2。
