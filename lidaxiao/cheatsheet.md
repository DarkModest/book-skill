# Cheatsheet

## 决策规则（When X → do Y, because Z）
| 当… | 就… | 因为… |
|---|---|---|
| 入市前 | 只用余钱（30–50年无安排）、先基金后个股、不碰杠杆 | 生活钱与股市钱相连必心态失衡 |
| 6124式顶部 | 淡泊、减仓、敢离场 | 86倍PE/0.27%股息需370年回本 |
| 1664式底部 | 勇气、买入并锁定筹码 | 上证50 PE8.5/股息3.66%有安全边际 |
| 股债差历史高位 | 买股（多数人在低位买债） | 股票相对债券吸引力最大 |
| 舆论一边倒/饭局9–10人买 | 反向卖出；都不买则悄悄买 | 正确信息往往不被选择 |
| 判断失误 | 第一时间认错止损 | 保住本金才有翻本本钱 |
| 面对海量股评 | 先选人（医德>医术）再听观点 | 评论员立场由盈利模式决定 |
| 低位选股 | 先全球最好→全国第一→全国第二 | 倒着选是小盘亏损的根源 |
| 遇到高估小/new/差/题材/伪成长 | 坚决远离 | 击鼓传花、财富消耗器 |
| 卖出兑现 | 留一截（不赚尽） | 卖在最高点不可求 |
| 持有中 | 长期持有但≠持有不动，远超价值则抛 | 企业有生命周期（6–7年） |

## 决策树（简化）
```
准备入市?
├─ 钱是余钱吗? 否→停止 | 是↓
├─ 用杠杆吗? 是→停止（红线）| 否↓
├─ 先基金后个股? 否→按六级品种匹配承受力
└─ 选股顺序: 全球最好→全国第一→全国第二（绝不倒着选）

市场相位?
├─ 顶部信号(估值极端+扩容+杠杆+政策降温)→减仓离场
├─ 底部信号(估值到位+杠杆出清+政策发力)→勇气买入
└─ 震荡(3000式)→坚持，抓优质低估筹码
```

##  Trade-off 矩阵
| 策略 | 牺牲 | 换来 |
|---|---|---|
| 余钱+价值投资 | 短期暴利 | 心态稳定、长期存活 |
| 逆向操作 | 短期与大众对立 | 长期胜率 |
| 少交易 | 波段刺激 | 复利、低成本 |
| 抓大放小 | 小盘暴富机会 | 本金安全 |
| 留一截 | 最后一段涨幅 | 纪律与心安 |

## 阈值与默认
- 余钱：30–50年无使用安排；股市钱与生活钱分离。
- 杠杆：外汇≤400倍、股指期货6–12倍——普通人一律远离。
- 顶部估值参照：主板PE 86倍 / 创业板150倍 / 股息率0.27%（5178地球顶）。
- 底部估值参照：上证50 PE 8.5倍 / 股息率3.66%（2850婴儿底）。
- 重大事件提前量：8–12个月，最晚半年。
- 盈亏分布：一赚二平七亏（70/20/10）；目标"考前5名"。
- 历史大底：325/998/1664/1849/2440（+2635/2689）；高位：1558/2245/6124/5178/3731。
- 反向饭局指标：10人中9–10人买→卖；都不买→悄悄买。

## Tells & Smells（危险信号）
- 人人谈股、股评大会爆满、招聘火热的"婚礼式狂热" → 顶部。
- 遇利好不涨 → 熊市特征；遇利空不跌 → 牛市特征。
- 高位怕踏空、低位怕套牢 → 心理相位错配，即将犯错。
- 高估五类（小、新、差、题材、伪成长）被热炒 → 火场，远离。
- 幸存者偏差论证（"特斯拉也是从小盘来"） → 炒作辩护，警惕。
- "正确的信息不被选择"、市场迷雾 → 逆向机会临近。
