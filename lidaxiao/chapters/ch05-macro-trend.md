# Chapter 5: 我眼中的大势（2007—2024）（Reading the Macro Trend: Bottoms, Tops & Core Assets）

## Core Idea
大势可判——用估值、杠杆、供求、政策等多维信号识别历史大底与顶部；在悲观中拥抱最低估最优质的蓝筹龙头，远离高估五类，坚守"余钱好股"。

## Frameworks Introduced
- **"地球顶"五大逻辑（顶部识别）**：
  - When to use: 市场估值极端偏高、杠杆与新股供给变化时判断顶部。
  - How: 以5178.19点为例——①估值偏高（主板PE中位数约86倍、创业板约150倍，主板股息率0.27%需370年回本、创业板0.13%需769年回本）②注册制序幕（从月发10家到30/50家，供求由失衡转平衡）③双向交易工具完善④杠杆过高⑤监管降温信号叠加。作者2015年5月5日称"4572地球顶"、6月9日"5147.45地球顶"、6月15日"5178.19地球顶，用烙铁烙定了"。
- **"婴儿底"五理由（底部识别）**：
  - When to use: 市场急跌后判断底部是否成立。
  - How: 以2850点为例——①主要蓝筹估值到位（上证50 PE 8.5倍、股息率3.66%）②杠杆水平基本正常（融资余额从2.27万亿降到1.1万亿，场外配资清理近80%）③做空机制暂停（融券、股指期货、分级基金、期权暂停或减弱）④限制减持及暂停IPO⑤救市政策渐发挥作用（央行双降、证金护盘、社保入市、大股东增持、减免红利税）。
- **五个历史大底/高位与"超级历史大底"**：
  - When to use: 用历史坐标定位当前点位所处位置。
  - How: 前五个历史大底=上证325、998、1664、1849、2440点；五个历史高位=1558、2245、6124、5178、3731点；恒生指数14597.31点为"超级历史大底"（2022年10月31日，从低位升超4000点、创24年最大单月涨幅）。
- **"火场论"辨析（对小盘股炒作的系统反驳）**：
  - When to use: 有人以"特斯拉也是从小股票长成"为小盘题材炒作辩护时。
  - How: 逐一拆解六大理由——①"大股票都由小股票发展"是幸存者偏差②围攻源于持有者的利益（盈利模式=卖给更冲动的接盘者）③供求关系已根本改变（封闭→开放、供不应求→供求平衡）④盈利来源是不明就里的接盘者，保护投资者力度加强将改变规则⑤市场条件已变⑥远离击鼓传花。
- **"钻石底"框架**：在别人不敢买入的区域（如钻石底）忍住诱惑、耐住寂寞；"地球顶"时泰山压顶面不改色。
- **核心资产率先进入牛市十大原因**：以中概股（纳斯达克中国金龙指数单月涨42.13%）为先锋，按中概股→在港中概股→港股→A股顺序反攻；中国资产深度价值、全球低配转重视。
- **慢牛格局框架**：2024年9月26日上证指数上穿3000点"地平线"，在互换便利、再贷款、长期资金入市、分红提升、股债差收缩、居民储蓄转移等推动下，有望形成"缓慢而悠长的慢牛"——但"仅限于余钱好股，仅限于中国最低估最核心最优质的资产"。


- **股债差择时框架（逆向）**：
  - When to use: 判断股票相对债券的吸引力、选择入场时机。
  - How: 核心规则——"买股最佳时机在股债差历史高位而非低位，多数人恰好相反"。2024年10年国债收益率2.4002%创新低、公募28万亿中股票型仅2.63万亿，是"重债轻股"的极致，往往对应股票低位。
- **新股破发五族论**：打新/吹新/炒新/追新/接新——"前四族割第五族韭菜"；注册制带来降维打击，终结无风险套利。
- **高息牛（中国首轮）框架**：资产荒+超低利率下高股息价值重估；套利模型——上证50股息3.65%−回购贷成本2.25%≈1.4%的套利空间。
- **耐心资本框架**：社保、汇金、保险等长期资金以"拥抱优质资产而非割韭菜"为盈利模式（社保持仓4275亿创历史新高、汇金3500亿）。
- **九个重要变化（2024.2）**：银行央企红利+12% vs 微盘股−29.92%、外资180度转变、3500亿借道ETF、筹码大转移——用结构变化确认核心资产转向。

## Key Concepts
- **钻石底/地球顶/婴儿底**：作者标志性的三次大势判断——钻石底别人不敢买、地球顶疯狂时烙定、婴儿底绝望时提出。
- **火场论**：善意提醒"火场里不要冲进去抢钱"，却遭大面积围攻；揭示小盘股炒作的接盘者本质。
- **余钱好股**：全书落脚点——用余钱（30至50年无使用安排的好股资金），买最低估最优质的蓝筹龙头。
- **高估五类**：高估的小、新、差、题材、伪成长——明确远离的对象。
- **核心资产**：最低估、最优质、最具竞争力的蓝筹龙头；银行指数曾5.0倍PE。
- **3000点地平线**：上证指数长期争夺的心理与技术关口；"3000点保卫战"。

## Mental Models
- Think of 市场顶部 as 一场需要提前离席的宴席——股息率370年回本时，你买的是"希望"不是"价值"。
- Think of 市场底部 as 婴儿——脆弱但生命力强；2850点时蓝筹PE 8.5倍、股息率3.66%已给出安全边际。
- Think of 小盘题材炒作 as 火场——冲进去"抢钱"的人，盈利来源是下一个更冲动的接盘者。
- Think of 慢牛 as 一条缓缓上升的地平线——只有余钱好股才能走完全程，杠杆资金和题材股会在半途消失。
- Think of 大势坐标 as 一张历史地图——325/998/1664/1849/2440是底，1558/2245/6124/5178/3731是顶。

## Anti-patterns
- **在地球顶追高**：86倍PE、0.27%股息率仍需买入，是把"希望"当"价值"。
- **幸存者偏差**：以特斯拉为例论证小股票值得投，忽略无数失败者。
- **追高估五类**：高估的小、新、差、题材、伪成长，是财富消耗器。
- **婴儿底恐惧踏空**：2850点该勇敢时却恐惧，错过低位筹码。
- **用杠杆抄底**：慢牛"仅限于余钱好股"，杠杆资金会在波动中被清洗。

## Worked Example
**从5178到2850——作者大势判断的完整闭环**：2015年6月12日至8月26日，53个交易日沪指从5178点跌到2850点，跌幅45%，市场从过热转入极寒。在顶部区域，作者以五大逻辑（估值86/150倍PE、注册制、双向工具、杠杆、监管）连续在4572/5147/5178点标记"地球顶"；在2850点绝望中，又以五大理由（蓝筹PE 8.5倍、杠杆回落至1.1万亿、做空暂停、限制减持与IPO、救市政策）提出"婴儿底"成立。8月27日晚22时发出看多观点，国庆后市场上行、婴儿底初步成型。这个案例把"顶部的勇敢（卖出/不追）"与"底部的勇敢（买入/持有）"串成一条线——作者自评的成立标准，正是"钻石底别人不敢买入时买、地球顶别人疯狂时抛"的逆向执行。

## Key Takeaways
1. 顶部看估值与供求（5178地球顶五大逻辑），底部看蓝筹估值与杠杆出清（2850婴儿底五理由）。
2. 用五个历史大底/高位定位当前坐标；恒生14597.31为超级历史大底。
3. 火场论揭穿小盘题材炒作的接盘者本质与幸存者偏差。
4. 核心资产（最低估最优质蓝筹）率先反攻；慢牛"仅限于余钱好股"。
5. 远离高估五类（高估的小、新、差、题材、伪成长）——全书最终落到"余钱投资、理性投资、价值投资"。
